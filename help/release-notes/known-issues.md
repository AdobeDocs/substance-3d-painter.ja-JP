# 既知の問題

このページでは、Substance 3D Painter v12.2.0で発生するアクティブな既知の問題をすべて一覧で示します。

* mes再読み込み後、`[Baking]`個のUv シームが表示されません
* `[Baking]`個のグリッドのようなアーティファクトで、いくつかの設定があります

## 安定度

* `[Crash]`プロジェクトの作成に失敗した後にテクスチャセット一覧をクリックすると、クラッシュが発生します
* `[Crash]`同じプロジェクトを2回開くと、重大なエラークラッシュが発生する
* `[Crash]` メッシュの読み込みに失敗した場合は、[メッシュのエクスポート]を選択します
* `[Crash]`古いプロジェクトを開こうとした後、「ペイント開始」をクリックします
* `[Crash]`リボン缶クラッシュで非常に長いテキストを作成しています
* `[Crash]`デバイスがベイクで失われた後、ペイントモードに戻ります
* `[Crash]`マップの書き出しをキャンセルした後、Painterを終了します
* `[Crash]` カメラ名に特殊記号が含まれているメッシュをエクスポートしています
