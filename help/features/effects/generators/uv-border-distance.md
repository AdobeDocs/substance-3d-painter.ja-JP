# UV境界距離

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_uv_border_distance.png" alt=""/><br><strong>イン：</strong>メッシュ、UV、距離</td>
    <td style="border: 0;" valign="top"><strong>説明</strong><br>UV境界線距離生成機能は、UV アイランドの境界にグレースケールマスクを作成するので、UVの境界に沿ったさまざまな効果を簡単に加えることができます。<br><br>UV境界線距離生成機能は、モノクロ（白黒）テクスチャを出力します。 このため、UV境界近くの領域をハイライトするマスクを生成するのに便利です。</td>
  </tr>
</table>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| **反転** | ジェネレータの出力を反転します。 |
| **残高** | 明るさコントロールのように、中間点を黒または白にシフトしてエフェクトのバランスを調整します。 |
| **コントラスト** | 効果のコントラスト/フォールオフを調整します。 |
| **Smoothness** | 効果の丸みを調整します。 これは、**Smoothness**&#x200B;の低い値が使用されている場合に最も顕著になります。 |
| **距離** | UV境界からエフェクトを拡張する距離を調整します。 |
