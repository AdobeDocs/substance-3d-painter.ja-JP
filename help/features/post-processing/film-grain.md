# 粒状フィルム

![](../../assets/v12_post_grain.jpg)

画像に粒状フィルムのノイズパターンを追加し、アナログ写真フィルムの有機的なテクスチャをシミュレートします。

| <b>パラメーター</b> | <b>説明</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>金額</b> | 粒子の可視性と強度を制御します。 値が大きいほど、目立って目立つノイズが発生します。 |
| <b>半径</b> | 個々の粒子のサイズをピクセル単位で設定します。 小さい値を指定するほど、粒子が細かくなり、繊細になります。大きい値を指定するほど、粗く目に見えるテクスチャになります。 |
| <b>型</b> | グレーノイズまたはカラーノイズを選択します。 |

>[!NOTE]
>
> このエフェクトで生成されたノイズは、ビューポートを更新するたびに再生成されます。 そのため、シャドウの生成時やカメラの回転時に、ノイズが更新されることがあります。
