# 高度な検索クエリ

高度な検索クエリを使用すると、複雑な検索を作成し、[保存された検索](saved-searches.md)として再利用できます。

高度なクエリは検索バーで使用でき、次を含むことができます：

1. **パス** ：フォルダー/フォルダー構造によって検索結果を絞り込むことができます。
1. **使用法** :アプリケーションで使用可能なすべての使用法を一覧表示します
1. **テキストクエリ** ：他の種類のクエリ（カスタムキーワードなど）を自由に追加できます

新しい検索クエリを定義する場合は、複数の選択が可能です。

## パス

パスクエリを使用すると、パスに基づいてクエリを絞り込むことができます。 **パスでフィルター**&#x200B;パネルには、使用可能なすべてのライブラリが一覧表示されます（このライブラリは、編集/設定/ライブラリを使用して自分で追加できます）。\
パス定義を使用して、カスタムライブラリパスまたは階層内の特定のサブフォルダーでフィルタリングすることができます。

## 使用状況

使用状況は、リソースの概要とSubstance 3D Painterでリソースを使用する方法を定義します。 リソースのファイルタイプによって定義できるものもあります。\
例 – 

* **pbr.glsl**:シェーダーファイル – シェーダーとしてのみ使用でき、それ以外のファイルは使用できません。
* **effect.sbsar**:サブスタンスファイル – ジェネレーター、フィルター、またはマテリアルの場合があります。元のグラフ(Designer)で使用状況が設定されていない場合は、読み込み時にPainterでユーザーが示す必要があります。

## テキスト

テキストクエリは複数のタイプのフィルタリングをサポートしています。一部のフィルタリングは、通常のインターフェイスよりも高度です。\
適切なキーワードを入力することで、有効にすることができます。

* **利用可能な検索の種類** :
  * &quot; **n:** &quot; ：名前
  * &quot; **s:** &quot; :シェルフ/ライブラリ（「セッション」と「プロジェクト」を含む）
  * &quot; **p:** &quot; :パス
  * &quot; **u:** &quot; ：使用方法
* **エスケープ** ：エスケープする必要がある文字の前に&quot; **\** &quot;を使用することも、代わりに引用符を使用することもできます。例：
  * **a\ name\ with\ spaces**
  * **&quot;スペースを含む名前&quot;**
* **特定の属性（またはグループ）** ：特定の属性を検索するには、&#39;またはグループ&#39;の前に型指定子を付加します。 例：
  * **n:a,b,c,d** ：名前はa、b、cまたはdです
* **検索動作** :
  * 特定の用途をフィルターするには、特定の&#x200B;**キーワード**&#x200B;を検索に追加します。例：「**画像**&#x200B;環境」
  * 複数のリクエストを追加するには、コンマ「 **,** 」を使用します。例： &quot;cobalt **,** gold&quot; （コンマを使用した場合、検索では両方のキーワードに同時に一致するリソースのみが表示されます）
  * 正確な名前を検索するには、感嘆符「!」を使用します。 最後の例： **di!**  （**Dirt**&#x200B;が返されますが、**滴**&#x200B;は返されません。このキーワードを指定すると、あいまい一致が無効になります）
  * 検索からパターンを除外するには、ハイフン「 **-** 」を使用します。例： **u:image n:-normal** （「normal」を含まない画像が返されます）
* **一致する関数（パターンサフィックス） :**
  * **default** ：近似一致（ファジー）
  * **次を含む** : !
  * **正規表現** : #
  * **等しい** : =
  * **次で始まる** : ^
  * **次で終わる** : &amp;
