## 説明

MatFX水彩フィルターは、水彩画のような外観でソースをスタイライズします。

このフィルターをテクスチャレイヤーに使用すると、水彩画のにじみ、紙との相互作用、ソフトペイントされたエッジが生まれます。

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>ペイントの不透明度：</b> | ペイントの不透明度を調整します。 |
| <b>紙の吸収:</b> | 用紙がペイントを吸収する強さを調整します。 |
| <b>累積の種類：</b> | 累積方法を選択します。 |
| <b>境界線スプレッド:</b> | ペイントの境界線の間隔を調整します。 |
| <b>境界線の密度：</b> | ペイントの境界線の濃度を調整します。 |
| <b>クロスペイントエッジを表示：</b> | クロスペイントエッジの表示を切り替えます。 |
| <b>用紙を隠す：</b> | 用紙テクスチャの表示/非表示を切り替えます。 |
| <b>カスタム用紙：</b> | カスタム用紙テクスチャの使用を切り替えます。 |
