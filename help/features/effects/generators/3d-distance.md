# 3D距離

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_3d_distance.webp" alt=""/><br><strong>内部：</strong>マスク、ジェネレータ</td>
    <td style="border: 0;" valign="top"><strong>説明</strong><br>3D距離ジェネレーターは、3D空間の点（基点）を定義し、その点からの距離をモノクログラデーションで表示します。 ポイントに近いメッシュサーフェスの領域は暗く、ポイントから遠い領域は明るくなります（既定）。<br><br>イメージ入力には、ベイク処理された位置マップが必要です。 <a href="../../../baking/baking.md">ベイク処理について詳しくは、こちらを参照してください</a>。<br><br>3D距離は、白黒のテクスチャを出力します。 そのため、特定の位置から離れてグラデーションを作成するマスクを生成する場合に便利です。<br><br></td>
  </tr>
</table>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| **位置** | ベイク処理された位置マップを使用して距離を計算します。 |

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| **反転** | グラデーションを反転します。 |
| **位置X** | ソースポイントをX軸に沿って変形します。 |
| **位置Y** | ソースポイントをY軸に沿って変形します。 |
| **位置Z** | Z軸に沿ってソースポイントを変形します。 |
| **半径** | 距離フォールオフのサイズを調整します。 |
| **オフセット** | グラデーションの開始位置と終了位置を、ソースポイントに近づけるか、ソースポイントから遠ざけます。 ソースポイントから離れると（オフセットを増やして）、ソースポイントの近くの暗い領域が大きくなります。 ソースポイントに近づくとグラデーションが明るくなり、**オフセット**&#x200B;が0に設定されている場合は、グラデーションが完全に削除される可能性があります。 |
| **コントラスト** | 球状グラデーションのコントラストを調整します。 |
