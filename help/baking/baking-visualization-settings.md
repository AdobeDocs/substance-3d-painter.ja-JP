# ビジュアライゼーション設定のベイク

![](../assets/viewport-vizu.png)

ベイク処理ビジュアライゼーションは、ベイクモード中のPainterのビューポート内にあるパネルです。 ビューポートのメッシュの表示に関する設定を変更できます。

## 一般設定

| 設定 | 説明 |
| --- | --- |
| **メッシュを非表示にする** | 有効にすると、ビューポートの高ポリゴンおよびケージメッシュが非表示になります。 <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r1-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../assets/hide-baking-meshes.png"/></div> |
| **選択したテクスチャセットのみを表示** | 有効にすると、現在アクティブなテクスチャセットのケージメッシュと高ポリゴンノードのみがビューポートに表示されます。 |

### 高精細メッシュ (HP)

| 設定 | 説明 |
| --- | --- |
| <b>メッシュ</b> | 有効な場合は、3Dビューにハイポリゴンメッシュを表示します。 無効にすると、ハイポリゴンメッシュもメモリからアンロードされ、パフォーマンスの向上に役立ちます。 この設定の横にあるカラーオプションを使用して、ビューポートのメッシュサーフェスの色を制御します。 |
| <b>一致するエラー</b> | 有効にすると、メッシュのシェルの外側にあるハイポリゴンメッシュの領域が指定したカラーで表示されます。 この設定は、ベイクプロセス中に見落とされて、詳細や情報が失われる可能性がある領域を特定するのに役立ちます。 この設定の横にあるカラーオプションを使用して、ビューポートで交差する領域のカラーを制御します。 |

### ケージ

| 設定 | 説明 |
| --- | --- |
| <b>ケージ面</b> | 有効にすると、ケージメッシュサーフェスが3Dビューに表示されます。 ケージのサーフェスは、設定の横にあるカラーボタンで定義されます。 |
| <b>ケージ面の不透明度</b> | メッシュの透明度を増減させて、基礎となるメッシュの詳細の可視性を管理します。 |
| <b>ワイヤーフレーム</b> | 有効にすると、メッシュのワイヤーフレームがビューポートに表示されます。 ワイヤーフレームの色は、この設定の横にある色ボタンで調整できます。 |
| <b>ワイヤーフレームの不透明度</b> | ワイヤーフレームの透明度を増減します。 |

### UV シーム

| 設定 | 説明 |
| --- | --- |
| <b>ハードエッジ上にシームがありません</b> | 有効にすると、シームではないメッシュのサーフェス上のハードエッジが、設定の横のボタンによって定義されたカラーでハイライトされます。 ハイライト表示されたエッジは、ケージとローポリゴンメッシュにのみ表示されます。 2Dビューと3Dビューの両方でエッジを表示できます。 この設定は、ラップ解除シームのない分割頂点法線を持つエッジの特定に役立ちます。この場合、後でベイクの問題が発生する可能性があります。 |
