</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

変形フィルターは、レイヤーの変形（拡大・縮小、回転、オフセット）に使用されます。

パターンやシェイプなどを変形するために、テクスチャレイヤーまたはマスクの内側（白黒出力）に使用されます。

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>繰り返しモード：</b> | リピートモードを選択します。 |
| <b>反転モード：</b> | 反転モードを選択します。 |
| <b>スケールX:</b> | 結果のXスケールを調整します。 |
| <b>スケールY:</b> | 結果のYスケールを調整します。 |
| <b>オフセットX:</b> | 結果のXオフセットを調整します。 |
| <b>オフセットY:</b> | 結果のYオフセットを調整します。 |
| <b>タイルセーフ回転：</b> | タイルセーフの回転を切り替えます。 |
| <b>回転：</b> | 回転を調整します。 |
| <b>スケール：</b> | 全体のスケールを調整します。 |
| <b>オフセット：</b> | 全体のオフセットを調整します。 |
