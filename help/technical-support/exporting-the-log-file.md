# ログファイルをエクスポートしています

このページでは、アプリケーションログファイルを検索する方法と、共有してサポートを依頼する方法について説明します。

## ログファイルを取得しています

ログファイルを取得するには、次の2つの方法があります。

### アプリケーションからのログ・ファイルのエクスポート

ログファイルは、**ヘルプ**&#x200B;メニューに移動して、**ログのエクスポート**&#x200B;アクションを選択することで、アプリケーションから直接エクスポートできます。

![](../assets/screenshot-20210622-195334.png)

### ディスク上のログファイルを手動で取得しています

アプリケーションが起動しない場合は、ログファイルをエクスポートできません。 幸いなことに、ログファイルはディスク上に手動で配置することができます。 以下のオペレーティングシステムに一致するフォルダーに移動し、**log.txt**&#x200B;ファイルを手動で取得します。

メッセージを書く場合は、添付ファイル領域を使用してログファイルを挿入します。
