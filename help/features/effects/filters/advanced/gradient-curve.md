# グラデーションカーブ

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![グラデーションカーブアイコン](./Resources/icon_gradient_curve.png "グラデーションカーブ")

<b>イン:</b>エフェクト/プリセット、再マップ、範囲

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

グラデーションカーブフィルターは、カスタマイズ可能なグラデーション曲線を使用して値を再マップします。

このエフェクトは、テクスチャレイヤー上またはマスク内（白黒出力）で、プリセットのトーンカーブのシェイプを使用してグレースケール値を再マップするときに使用します。

</td>
</tr>
</table>

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>プリセット：</b> | カーブプリセットを選択します。 |
| <b>反転：</b> | 結果の反転を切り替えます。 |
| <b>残高：</b> | 明るさの調整と同様に、結果の黒と白のバランスを調整します。 |
| <b>コントラスト：</b> | 結果のコントラストまたは減衰を調整します。 |
