# 粒状フィルム

![](../../assets/v12_post_grain.jpg)

粒状フィルムのノイズパターンを画像に追加し、アナログ写真フィルムの有機的なテクスチャをシミュレートします。

| <b>パラメーター</b> | <b>説明</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>金額</b> | 粒子の可視性と強度を制御します。 値が大きいほど、ノイズがより目立って目立ちます。 |
| <b>半径</b> | 個々の粒子パーティクルのサイズをピクセル単位で設定します。 値を小さくすると、粒子が細かく目立つようになります。値を大きくすると、テクスチャが粗く目立つようになります。 |
| <b>型</b> | グレーノイズまたはカラーノイズを選択します。 |

>[!NOTE]
>
> このエフェクトで生成されたノイズは、ビューポートが更新されるたびに再生成されます。 そのため、シャドウを生成したり、カメラを回転させたりすると、ノイズを更新できます。
