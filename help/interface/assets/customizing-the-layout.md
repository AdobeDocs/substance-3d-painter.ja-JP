# レイアウトのカスタマイズ

サブライブラリ、幅の縮小、サムネールサイズなどのインターフェイスオプションを使用すると、必要に応じてアセットパネルのレイアウトを変更できます。

>[!NOTE]
>
> アセットは、マウスホイールを使用するか、スクロールバーを操作してスクロールできます。または、Painterウィンドウでスクロールする別の方法として、**Ctrl + Altを押したまま、目的のパネル内にドラッグ**&#x200B;することもできます。

ドッキングと向き

インストール後に初めてPainterを開くと、アプリの左側にアセットウィンドウが縦にドッキングされています。 ただし、ドッキングを解除したり、水平方向に配置することはできます。 また、追加の[サブライブラリ](sub-library-tab.md)のウィンドウを使用する場合は、このウィンドウもドッキングとドッキング解除を自由に行うことができます。

![](../../assets/00-02-docking.gif){width="600px"}

## 幅を縮小

サイズを小さくすることができます。その場合、アセットタイプは1つまたは複数のオプションを選択できる単一のメニューに折りたたまれます。

![](../../assets/00-03-reduced.jpg)

## サムネールサイズ

アセットのサムネールサイズは、左端のアイコンを使用して調整できます。このアイコンには、「小」、「中」（デフォルト）、「大」、「リスト」の各オプションがあります。

![](../../assets/00-04-thumbs.jpg){width="600px"}
