# 書き出しウィンドウ

![](../../assets/export-textures-window.png){width="500px"}

<b>ファイル/テクスチャの書き出し</b>またはキーボードショートカット<b>Ctrl + Shift + E</b>を使用して、<b>書き出しウィンドウ</b>を開きます。

<b>書き出しウィンドウ</b>は、次の3つのタブに分かれています。

* [書き出し設定](export-settings.md)
* [出力テンプレート](output-templates.md)
* [書き出しのリスト](list-of-exports.md)

ウィンドウの下部には次のボタンがあります。

* <b>すべてリセット</b> （<b>設定タブ</b>のみ）:プロジェクトのエクスポート構成をリセットします。
* <b>キャンセル</b>：変更を保存せずにウィンドウを閉じます。
* <b>設定の保存</b>：現在の書き出し設定をプロジェクトに保存します。
* <b>書き出し</b>：現在の書き出し設定で書き出しを開始し、自動的に<b>書き出しのリスト</b>セクションに切り替えて、書き出しの進行状況を追跡します。
