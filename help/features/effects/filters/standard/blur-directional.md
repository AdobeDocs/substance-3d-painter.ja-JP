# ブラー（方向）

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![方向のぼかしアイコン](./Resources/icon_blur_directional.png "方向のぼかし")

<b>イン:</b>効果/ぼかし、グレースケール

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

ぼかしフィルターは、特定の方向にマップまたはマスクをぼかすための非常に簡単なフィルターです。

テクスチャレイヤー上で直接使用し、マテリアル全体や特定のテクスチャをぼかします。 マスクにぼかすために使用することもできます。

</tr>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>ぼかしの強さ：</b> | ブラーエフェクトの強さを調整します。 |
| <b>角度：</b> | ぼかしの角度を調整します。 |
| <b>強度：</b> | 方向の強さを調整します。 |
