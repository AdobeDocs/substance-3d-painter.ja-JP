# バージョン12.0

<b>Substance 3D Painter 12.0</b>では、レイヤースタック内でのテクスチャの統合、ワープ投影の新しい自動モード、後処理エフェクトのセットの改良、およびプロジェクトの作成と設定のワークフローの改善が行われています。

リリース日： <b>9 2026年3月</b>

>[!NOTE]
>
> このバージョンでは、<b>統合/共有メモリ</b>を備えた<b>統合GPU</b>のサポートが改善されました。 ビデオメモリの検出が向上し、パフォーマンスが向上し、グラフィックの問題が少なくなることが予想されます。

## 主な機能

### レイヤーの新しい統合

![](../assets/v12_banner_flatten.jpg)

レイヤースタックの右クリックコンテキストメニューで、新しい<b>平坦化</b>アクションが使用できるようになりました。 複数のレイヤーをグループ化し(<b>Ctrl/Cmd + G</b>)、統合されたコピーを作成して(<b>Ctrl/Cmd + M</b>)、すばやく結合できます。 ソースグループは自動的に無効になり、後で編集するために削除するか、<b>スマートマテリアル</b>として保存するかを選択できます。

レイヤースタックを統合したオブジェクトを直接ディスクに書き出して、他のアプリケーションですばやく反復することもできます。 グループ、レイヤー、マスクは、レイヤースタックの右クリックメニューを使用して個別にまたはバッチで書き出すことができます。

* <b>レイヤースタック内のテクスチャを直接統合する</b>\
  任意のグループを統合するには、<b>Ctrl/Cmd + M</b>を押すか、右クリックして表示されるコンテキストメニューの<b>グループの統合</b>項目を選択します。 これにより、選択したコンテンツの結合コピーが生成され、ソースグループは自動的に無効になります。削除または復元の決定が行われるまで、元のレイヤーをそのままの状態で保ちます。

  ![](../assets/v12_flatten_menu.jpg)
* <b>テクスチャを統合してディスクにエクスポートする</b>\
  右クリックメニューにある専用の書き出し操作では、レイヤー、マスク、またはグループの統合結果がベイクされ、ディスクに直接保存されます。 これは、アプリケーションの完全な書き出しパイプラインを経由せずに、ベイクされたコンテンツを他のテクスチャに転送する場合に便利です。
* <b>バッチ操作</b>\
  複数のレイヤー、グループ、マスクを一度に選択し、1回の操作で個別に統合または書き出すことができるので、レイヤースタックの大部分を1ステップで処理するのが効率的です。

  ![](../assets/v12_flatten_batch.jpg)

>[!NOTE]
>
> レイヤーの統合の詳細については、[専用のドキュメントページ](../interface/layer-stack/flatten-layers.md)を参照してください。

### 投影の新しいジオメトリへのワープモード

![](../assets/v12_banner_warp_auto.jpg)

デカールは複雑なサーフェスに自動的に適応するようになり、手動調整の必要性が減りました。 ワープ投影がアクティブな間、コンテキストツールバーで「<b>ジオメトリにワープ</b>」トグルを使用できます。

* <b>コンテキストツールバーの新しいパラメーター</b>\
  ワープ投影モードがアクティブな場合は常に、コンテキストツールバーで新しい<b>ジオメトリにワープ</b>の切り替えが使用できます。 現在の投影設定をリセットすることなく、いつでもオフにできます。

  ![](../assets/v12_warp_toolbar.png)
* <b>メッシュサーフェスへの自動折り返し</b>\
  有効にすると、ワープ投影は基になるメッシュの曲率とトポロジに自動的に従います。 投影をサーフェス上にドラッグすると、ジオメトリにスムーズに適合させることができます。これにより、複雑な形状や曲線の形状にデカールを配置する際に必要となる、手動での微調整を大幅に減らすことができます。

  ![](../assets/v12_warp_to_geometry.gif)
* <b>ローカルの変形の保持</b>\
  ワープグリッドの頂点を変更すると、ワープからジオメトリへのモードは、同じ形状が常に投影されるように、事前に定義された変形を維持しようとします。

  ![](../assets/v12_warp_to_geometry_deformed.gif)

>[!NOTE]
>
> ワープ投影の詳細については、[専用のドキュメントページ](../painting/fill-projections/warp-projection.md)を参照してください。

### 新しいポストエフェクト

![](../assets/v12_banner_post_effects2.jpg)

Painter内のレンダリングは、<b>ディスプレイ設定</b>ウィンドウで利用できる新しい後処理エフェクトセットで強化できます。 <b>レンズフレア</b>や<b>粒状フィルム</b>などの新しい機能が追加され、フィールドの<b>深度</b>や<b>グレア</b>などの効果が向上しました。

新しいエフェクトを使用して得られる結果の例を次に示します。

![](../assets/v12_render_withpost.jpg)

* <b>新しい後処理エフェクト</b>\
  すべての後処理エフェクトは、<b>ディスプレイ設定</b>ウィンドウから個別に有効化および設定できます。 エフェクトはスタック順に適用され、各エフェクトを個別にオンまたはオフに切り替えることができるため、簡単に組み合わせたり、様々な結果を試したりできます。

  ![](../assets/v12_display_settings_post_effects.png)
* <b>効果の新しいリスト：</b>

  * <b>視野の深度</b>：焦点範囲外のオブジェクトをぼかして、カメラのレンズフォーカスをシミュレートします。
  * <b>ブルーム</b> ：画像の明るい領域から発する柔らかい光彩を追加します。
  * <b>グレア</b> ：光源の周囲に光の筋を作ります。
  * <b>レンズフレア</b> :カメラ内で明るい光が当たっているときに、レンズの光学的な反射をシミュレートします。
  * <b>横収差</b>:レンズのレンズのずれによって生じる画像のエッジのカラーフリンジをシミュレートします。
  * <b>周辺光量補正</b>:フレームの四隅とエッジを暗くして、中心に焦点を当てます。
  * <b>シャープ</b>:エッジのコントラストを上げて、レンダリングされた画像をより鮮明にします。
  * <b>粒状フィルム</b> :アナログフィルムのテクスチャを再現するために、繊細なノイズをオーバーレイします。
  * <b>トーンマッピング</b>: HDRの輝度値を表示可能な範囲に再マップして、映画のような外観にします。
  * <b>カラー補正</b> :コントラスト、彩度、明るさ、温度を調整して、全体的なカラーバランスを微調整します。

>[!NOTE]
>
> 新しいエフェクトについて詳しくは、[専用のドキュメント](../features/post-processing/post-processing.md)を参照してください。

### 新しいプロジェクトと設定ウィンドウの改善

![](../assets/v12_banner_project_window.jpg)

新しいプロジェクトウィンドウとプロジェクト設定ダイアログが再設計され、移動しやすくなりました。 読みやすさを向上させるためにパラメーターの並べ替えとグループ化を行い、メッシュの再読み込みワークフローを改善して、プロジェクトを繰り返し処理する際の繰り返し手順を減らしました。

* <b>新しいプロジェクトウィンドウの改善</b>\
  新しいプロジェクトウィンドウのパラメーターは、最もよく使用される設定がより目立つように再編成および並べ替えられました。 レイアウト全体がスキャンしやすくなり、新しいプロジェクトの設定に必要な時間が短縮されました。
* <b>プロジェクト設定でメッシュを再読み込みするための新しいワークフロー</b>\
  プロジェクト設定の新しいチェックボックス<b>メッシュを再読み込み</b>では、以前に読み込んだファイルのファイルパスが保存され、自動的に事前入力されるため、プロジェクトメッシュをより簡単に再読み込みできます。

  ![](../assets/v12_project_settings.png)
