# レベル

レベルは、画像のカラー範囲を調整するために使用する効果です。 これにより、カラーやグレースケール値のバランスと階調を調整できます。 効果メニューを開いて追加することができます。

![](../../assets/level-menu.png)

メインインターフェイスには、ヒストグラム（インターフェイスの中央にあるカラーの山）が表示されます。これは、各カラーの適用度レベルにおける画像内のピクセルの分布方法を表します。 ヒストグラムは、シャドウ（左部分）、中間調（中央部分）、ハイライト（右部分）のディテールを表示します。 ヒストグラムでは、カラーの階調範囲もすばやく確認できるため、画像の暗さや明るさを判断できます。

![](../../assets/image2015-3-20-11-24-24.png)

画像のカラー範囲を調整するには、ヒストグラムの上部と下部に2セットのコントロールがあります。

* 上にある3つのボタンは、シャドウ、中間調、ハイライトを制御します。このボタンを使用すると、階調範囲を再分散して、画像全体のコントラストを向上できます。
* 下の2つのボタンは、画像の黒と白色点（通常は0と255）を制御します。 これは、画像のカラーを反転する場合などに便利です。

>[!NOTE]
>
> レベル補正エフェクトは、*影響を受けるチャンネル*&#x200B;のオプションで選択したチャンネルにのみ適用できます。 複数のチャンネルにレベルを適用するには、複数のレベルエフェクトを作成する必要があります。

* 右上のカラードロップダウンボックスを使用すると、RGB画像全体または赤、緑、青のチャンネルの1つのみに対してレベルを変更できます。
* 右下の[クランプ]オプションを使用すると、レベルの値を0 ～ 1(0 ～ 255)の範囲でクランプできます。 HDR以外のチャンネル（**ベースカラー**&#x200B;など）を操作する場合は、常にこのオプションをオンにする必要があります。

[レベルについてさらに詳しく知るには、このトピックに特化したSubstanceアカデミーのコースをご覧ください。](https://academy.substance3d.com/courses/Mastering-Levels-Histogram)
