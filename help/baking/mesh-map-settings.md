# メッシュマップ設定

<b>メッシュマップ設定パネル</b>は、ベイクモードで使用でき、ベイク処理のためにメッシュを準備するためのコントロールがあります。 特定のマップのメッシュマップ設定を調整するには、<b>メッシュマップベイカーパネル</b>でマップを選択します。 各メッシュマップには、異なる設定を使用できます。 すべてのメッシュマップで共有されている<b>共通の設定</b>のコレクションは、[メッシュマップベイカー]パネルの上部で使用できます。

メッシュマップ間で共有される設定は、個々のメッシュマップではなく、共通の設定ページに表示されます。

## 共通設定

[共通設定]ページには、すべてのメッシュマップをベイク処理する方法に影響するコントロールがあります。

### 出力設定

| 設定 | 関数 |
| --- | --- |
| 出力サイズ | 生成されたメッシュマップのXおよびY解像度を定義します。 非正方形の解像度を許可するには、ロックをクリックします。 |
| 拡張幅 | 焼き付けたUV アイランドが文字の境界線を越えて広がる範囲を調整します。 |
| 拡散を適用 | このボックスを有効にすると、生成された情報のエッジに拡散が適用されます。 |

### ハイポリパラメーター

| 設定 | 関数 |
| --- | --- |
| 低ポリメッシュを高ポリメッシュとして使用 | この設定を有効にすると、プロジェクトメッシュに基づいてマップがベイクされます。 |
| ハイポリメッシュ | プロジェクトにハイポリメッシュを追加し、ハイポリメッシュからプロジェクトのローポリメッシュに作成します。 複数のメッシュをインポートできます。 |
| ケージ | ベーキングケージの生成方法を決定します。<ul data-preserve-html="true"> <li data-preserve-html="true">[距離に基づく]:メッシュから離れた頂点をモデル全体で一定の距離だけ膨張させて、ケージを作成します。</li> <li data-preserve-html="true">自動（実験的）:Painterはメッシュを分析し、最適な結果を得るために交点を作成せずにケージをサーフェスに近い状態に保とうとします。</li> <li data-preserve-html="true">カスタムファイル：ケージとして使用するために作成したファイルを読み込みます。 読み込んだファイルが正しく動作するためには、ベースメッシュと同じ数の頂点が必要であることに注意してください。</li> </ul> |
| 背面を無視 | ベイク処理時に背面を無視するかどうかを選択します。 これはアーチファクトを減らすのに役立ちますが、特定のエッジケースではエラーが発生する可能性もあります。 |
| ハイ / ローメッシュのマッチング | ベイク処理時にオブジェクトを含めるかどうかをベイカーが決定する方法を変更します。<ul data-preserve-html="true"> <li data-preserve-html="true">常に：ベイク処理時にケージ内にヒットしたすべての高ポリゴンメッシュを含めます。</li> <li data-preserve-html="true">メッシュ名：各ケージで、対応するメッシュ接尾辞を持つメッシュのみをベイクします。</li> </ul> |
| ローポリメッシュサフィックス | [メッシュ名で一致]を使用する場合、この接尾辞を使用してローポリゴンメッシュを定義します。 |
| ハイポリメッシュサフィックス | [メッシュ名で一致]を使用する場合、この接尾辞を使用してハイポリゴンメッシュを定義し、対応するローポリゴンメッシュと一致させます。 |
| アンチエイリアス | 生成されたマップのアンチエイリアスの量を調整します。 |

#### ゆがみ補正

| 設定 | 説明 |
| --- | --- |
| **スキュー補正のペイント** | スキュー補正ペイントモードに移行します。 |
| **エッジ保護** | エッジ保護を切り替えて、ハードエッジに近いペイントされたスキュー補正値をマスクします。 |
| **エッジの距離** | ハードエッジからエッジ保護までの距離を制御 |
| **エッジのコントラスト** | エッジ保護のグラデーションを完全保護から非保護に切り替える度合いを制御します。 |

## IDマップの設定

| 設定 | 関数 |
| --- | --- |
| カラーソース | IDマップのベイク処理されたカラーの決定方法を変更します。<ul data-preserve-html="true"> <li data-preserve-html="true">頂点カラー</li> <li data-preserve-html="true">マテリアルカラー</li> <li data-preserve-html="true">ファイル ID</li> <li data-preserve-html="true">メッシュID/ポリグループ</li> </ul> |
| カラージェネレーター | ファイルIDまたはメッシュID/ポリグループをカラーソースとして使用する場合は、カラーの生成方法を指定します。<ul data-preserve-html="true"> <li data-preserve-html="true">ランダム</li> <li data-preserve-html="true">色相シフト</li> <li data-preserve-html="true">グレースケール</li> </ul> |

## 環境オクルージョンマップの設定

| 設定 | 関数 |
| --- | --- |
| セカンダリレイ | セカンダリレイ数を変更します。 レイ数を増やすと結果は良くなりますが、処理時間が長くなります。 |
| 最小オクルーダー距離 | 高ポリゴンジオメトリに当たって結果のAOマップに影響を与える光線の最小距離を調整します。 |
| 最大オクルーダー距離 | 高ポリゴンメッシュに当たらずにこの距離を超えて伸びるレイは、遮蔽されていないと見なされ、AOマップに影響しません。 |
| バウンディングボックスに相対的 | このボックスをオンにすると、距離を参照する他の設定がプロジェクトメッシュのバウンディングボックスに基づきます。 したがって、1の距離はバウンディングボックスのサイズと同じです。 |
| 広がり角度 | 生成されるレイのangular範囲を調整します。 広がり角度を大きくすると、サーフェスから垂直に離れて配置されていないジオメトリによって、サーフェスが簡単に閉塞されます。 |
| 分布方法 | 光線の分布方法を選択します。 |
| 背面を無視 | 背面がオブジェクトを隠しているとみなすかどうかを変更します。 |
| セルフオクルージョン | 現在のメッシュの環境オクルージョンに影響を与えるメッシュを選択します。 |
| 減少 | オクルーダーの距離によるオクルージョンの減衰方法を変更します。 |
| グランドプレーン | これを有効にすると、オクルーダとして動作するグリッドが作成されます。 |
| グランドプレーンオフセット | グリッドの位置を変更します。 |

## 曲線マップ設定

| 設定 | 関数 |
| --- | --- |
| 方法 | 曲線マップの生成方法を選択します。 |
| セカンダリレイ | 曲線マップの作成に使用するセカンダリレイ数を調整します。 セカンダリレイが多いほど結果は良くなりますが、処理時間が長くなります。 |
| サンプリング半径 | 現在のポイントの曲率を計算するためにベイカーが検索する距離を調整します。 |
| バウンディングボックスを基準 | このチェックボックスをオンにすると、すべての距離がメッシュのバウンディングボックスのサイズに基づきます。 |
| セルフ積集合 | 曲線を決定するときに考慮するオブジェクトを選択します。 |
| 自動トーンマッピング (UV タイル単位) | トンマップの曲率マップをUVタイルごとに自動的に調整するには、このチェックボックスをオンのままにします。 |
| トーンマッピング最小 | 自動トーン補正が無効な場合、トーン補正の最小値を調整します。 |
| トーンマッピング最大 | 自動トーン補正が無効な場合、トーン補正の最大値を調整します。 |

## 位置マップ設定

| 設定 | 関数 |
| --- | --- |
| モード | すべての軸の位置マップを生成するか、選択した軸の位置のみを計算するかを選択します。 |
| 軸 | [単一軸]モードが選択されている場合は、この設定を使用して計算する軸を選択します。 |
| 正規化タイプ | 位置の値の正規化の方法を、バウンディングボックスまたはバウンディングボックスを使用して変更するか、正規化を無効にします。 |
| スケールの正規化 | 位置スペースの最大境界と見なされる値を変更します。 |

## Thicknessマップの設定

| 設定 | 関数 |
| --- | --- |
| セカンダリレイ | セカンダリレイ数を変更します。 レイ数を増やすと結果は良くなりますが、処理時間が長くなります。 |
| 最小オクルーダー距離 | 高ポリゴンジオメトリに当たり、結果のThicknessマップに影響を与える光線の最小距離を調整します。 |
| 最大オクルーダー距離 | 高ポリゴンメッシュに当たらずにこの距離以上に伸びるレイは、遮蔽されていないと見なされ、Thicknessマップに影響しません。 |
| バウンディングボックスに相対的 | このボックスをオンにすると、距離を参照する他の設定がプロジェクトメッシュのバウンディングボックスに基づきます。 したがって、1の距離はバウンディングボックスのサイズと同じです。 |
| 広がり角度 | 生成されるレイのangular範囲を調整します。 広がり角度を大きくすると、サーフェスから垂直に離れて配置されていないジオメトリによって、サーフェスが簡単に閉塞されます。 |
| 分布方法 | 光線の分布方法を選択します。 |
| セルフオクルージョン | 現在のメッシュのThicknessに影響を与えるメッシュを選択します。 |
| 正規化 | Thickness値の正規化の方法を変更します。 |

## Heightマップの設定

| 設定 | 関数 |
| --- | --- |
| 正規化 | Height値の正規化の方法を変更します。 |
| スケーリング除数 | NormalizationがManualに設定されている場合は、このスライダを使用してスケール係数を調整し、Heightマップの正規化を調整します。 |

## 曲げ法線マップの設定

| 設定 | 関数 |
| --- | --- |
| セカンダリレイ | セカンダリレイ数を変更します。 レイ数を増やすと結果は良くなりますが、処理時間が長くなります。 |
| 最小オクルーダー距離 | 高ポリゴンジオメトリに当たって結果の曲げ法線マップに影響を与える光線の移動距離の最小値を調整します。 |
| 最大オクルーダー距離 | 高ポリゴンメッシュに当たらずにこの距離より遠くまで伸びているレイは、遮蔽されていないと見なされ、曲がった法線マップには影響を与えません。 |
| バウンディングボックスに相対的 | このボックスをオンにすると、距離を参照するその他の設定はプロジェクトメッシュのバウンディングボックスに基づきます。 したがって、1の距離はバウンディングボックスのサイズと同じです。 |
| 広がり角度 | 生成されるレイのangular範囲を調整します。 広がり角度を大きくすると、サーフェスから垂直に離れて配置されていないジオメトリによって、サーフェスが簡単に閉塞されます。 |
| 分布方法 | 光線の分布方法を選択します。 |
| 背面を無視 | 背面を隠線として扱うかどうかを選択します。 |
| セルフオクルージョン | 現在のメッシュの曲がった法線に影響を与えるメッシュを選択します。 |
