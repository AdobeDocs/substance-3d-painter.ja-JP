# 投影

![](../../assets/image2015-3-19-17-56-54.png){width="50px"}

投影は、マテリアルをスクリーン/ビューポート空間に投影してペイントできるツールです。 ステンシルと同様のコントロールが共有されます。

**ショートカットS**&#x200B;を押すと、プロジェクション変換を編集できます。

* **Sキーを押しながら左クリック**&#x200B;して、ステンシルを回転します。
* **S +左クリック+ Shift**&#x200B;を使用して、ステンシルの回転にスナップまたは制限します。
* **Sキーを押しながら右クリック**&#x200B;して、ステンシルをズームまたはズーム解除します。
* **S +中マウス**&#x200B;を使用して、ステンシルを変換します。
