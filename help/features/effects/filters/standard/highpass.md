## 説明

ハイパスフィルターは、同じ名前を持つ「Photoshop」アクションと同様に、ハイパス効果を実行します。 タイリング用にテクスチャをクリーニングする場合など、画像の大きな輝度差を取り除くのに便利です。

大きな輝度差を取り除くために、テクスチャレイヤーまたはマスクレイヤーで使用されます。

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>カラースペース：</b> | フィルターで使用するカラースペースを選択します。 |
| <b>半径：</b> | ハイパスの半径を調整します。 |
| <b>Alphaに適用：</b> | フィルターがアルファチャンネルに影響するかどうかを切り替えます。 |
