# ミラー

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![ミラーアイコン](./Resources/icon_mirror.png "ミラー")

<b>イン：</b>エフェクト/ミラー、サイド、コピー、対称、リフレクト

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

ミラーフィルターは、入力の一部をコピーする対称フィルターです。

テクスチャレイヤー（カラー）またはマスクで使用され、ミラー軸に基づいて、マテリアル、マスク、シェイプなどを完全にミラーします。

</td>
</tr>
</table>

>[!NOTE]
>
> ミラーフィルターはUV領域で機能するため、**ビューポート**&#x200B;で2D ビューを開くと便利な場合があります。

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>デバッグの表示：</b> | デバッグビューの表示を切り替えます。 |
| <b>モード：</b> | ミラーモードを選択します。 |
| <b>軸 Xオフセット：</b> | X軸のオフセットを調整します。 |
| <b>軸 Yオフセット：</b> | Y軸のオフセットを調整します。 |
| <b>軸Xを反転：</b> | X軸の反転を切り替えます。 |
| <b>軸Yを反転：</b> | Y軸の反転を切り替えます。 |
| <b>コーナーの種類：</b> | ミラーコーナーの処理方法を選択します。 |
