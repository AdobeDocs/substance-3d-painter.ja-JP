# メッシュマップ設定パネル

[**ベイクモード**](../../baking/baking.md)&#x200B;で、**メッシュマップ設定パネル**&#x200B;に、**メッシュマップベイカーパネル**&#x200B;で現在選択されているメッシュマップの種類のパラメーターが表示されます。

[**共通設定**](common-mesh-map-settings.md)&#x200B;と&#x200B;**メッシュマップ設定パネル**&#x200B;で利用可能なすべてのメッシュマップ設定のリストは、ドキュメントのベイクセクション[で入手できます](../../baking/mesh-map-settings.md)。
