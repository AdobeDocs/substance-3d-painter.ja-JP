# Mac OSの最新バージョンでのNvidia GPUの問題

Mac OSでは、Appleは、GPUコンストラクターによってGPUドライバーが提供された後にそれらを検証することでGPUドライバーを提供します。 Mac OS Mojave以降、Appleでは最新のNvidia GPU用の新しいドライバーがまだ検証されていません。 残念ながら、Substance 3D Painterが正しく動作するには、最新のGPUドライバーが必要です。

詳細については、次のページを参照してください。

* [Mac OSでサポートされているGPUのリスト](https://support.apple.com/en-us/HT208898) 。
* [Mac OSでの外部GPUの使用](https://support.apple.com/en-us/HT208544) 。
