# 編集メニュー

![](../../assets/edit-menu.png)\
編集メニューから、取り消し/やり直し操作にすばやくアクセスできるだけでなく、プロジェクト設定およびグローバル設定にもアクセスできます。

| アクション | 説明 |
| --- | --- |
| **取り消し** | [履歴](../history.md)スタックに戻ります。 |
| **やり直し** | [履歴](../history.md)スタックで一歩進んでください。 |
| **プロジェクト構成** | 現在のプロジェクトの[プロジェクト設定](../project-configuration.md)ウィンドウを開きます。 |
| **設定** | 全般[アプリケーションの設定](../settings/settings.md)ウィンドウを開きます。 |
| **メッシュマップのベイク** | [ベイク](../../baking/baking.md)ウィンドウを開きます。 |
