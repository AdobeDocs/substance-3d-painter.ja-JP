## 説明

光彩フィルターは、入力の表示部分の周りに光彩を作成します。

テクスチャレイヤー上またはマスク内（白黒出力）で、シェイプとマテリアルの周囲にソフトで正確な光彩を加えるために使用されます。

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>マスクで使用：</b> | 光彩をマスクに使用するかどうかを切り替えます。 |
| <b>モード：</b> | 光彩でソフトモードと精細モードのどちらを使用するかを選択します。 |
| <b>幅：</b> | 光彩の幅を調整します。 |
| <b>スプレッド：</b> | 光彩の広がりを調整します。 |
| <b>不透明度：</b> | 光彩の不透明度を調整します。 |
| <b>色：</b> | グローのカラーを調整します。 |
