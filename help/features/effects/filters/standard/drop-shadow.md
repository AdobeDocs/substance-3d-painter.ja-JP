## 説明

「ドロップシャドウ」フィルターは、ドロップシャドウを作成します。

ペイントレイヤー上で使用され、ペイントしたストロークに基づいてドロップシャドウを作成します。

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>角度：</b> | シャドウの角度を調整 |
| <b>距離：</b> | シャドウの距離を調整します。 |
| <b>サイズ：</b> | シャドウのサイズを調整します。 |
| <b>スプレッド：</b> | シャドウの広がりを調整します。 |
| <b>不透明度：</b> | シャドウの不透明度を調整する |
| <b>色：</b> | シャドウのカラーを調整します。 |
