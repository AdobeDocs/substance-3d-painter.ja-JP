# UVテクスチャ密度

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_uv_texel_density.png" alt=""/><br><strong>イン：</strong> UV、サイズ、ユーティリティ</td>
    <td style="border: 0;" valign="top"><strong>説明</strong><br>UVテクセル密度ジェネレーターは、色付きのグラデーションを低から高に適用して、メッシュのテクセル密度を視覚化します。<br>UVテクスチャ密度ジェネレーターは、フルカラーテクスチャを出力します。これは、塗りつぶしレイヤーで一貫性のないUVスケールを識別し、モデル全体でテクスチャの詳細を均一にするために使用するのが最適です。</td>
  </tr>
</table>

>[!NOTE]
>
> テクスチャ密度とは、モデルの特定の表面積に含まれるテクスチャ（テクスチャピクセル）の数です。 テクセル密度が高いと、モデルの小さな領域に多くのディテールを詰め込むことができます。テクセル密度が低いとディテールの量が制限されますが、パフォーマンスは向上します。 一般に、マテリアルの解像度に関係なく、メッシュ全体でテクスチャ密度を一定に保つことをお勧めします。これは、テクスチャ密度に大きな違いがあると目に見える場合が多く、アセットが低品質に感じられたり、リアルさに欠ける場合があるためです。

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| **低色** | テクスチャ密度が&#x200B;**低**&#x200B;の領域に使用する色を設定します。 |
| **カラーメディア** | テクスチャ密度が&#x200B;**中**&#x200B;の領域に使用する色を設定します。 |
| **カラー（高）** | テクスチャ密度が&#x200B;**高**&#x200B;の領域に使用する色を設定します。 |
