# マスクエディター

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_mask_editor_dark.png" alt=""/><strong>内部：</strong>マスク、ジェネレータ</td>
    <td style="border: 0;" valign="top"><strong>説明</strong><br>マスクエディタジェネレータは、テクスチャ、環境オクルージョン、曲率、ワールド空間法線、グラデーション、Thickness、およびマイクロディテールを1つのマスクに結合できる多目的マスクジェネレータです。<br>マスクビルダジェネレータは非常に柔軟ですが、複雑なため、ほとんどのジェネレータよりもパフォーマンスに影響を与える可能性があります。<br><br>マスクエディタジェネレータは、白黒テクスチャを出力します。 したがって、様々なベイク済みマップに基づいてマスクを作成する場合に便利です。 <br><br>イメージ入力には、ベイク処理された位置、Thickness、曲率、周囲オクルージョン、およびワールド空間の法線マップが必要です。 <a href="../../../baking/baking.md">ベーキングの詳細については、こちらを参照してください</a>。</td>
  </tr>
</table>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| **テクスチャ**&#x200B;の色 | カスタムテクスチャまたはアンカーポイントを使用します。 |
| **テクスチャ（セカンダリ）**&#x200B;カラー | カスタムテクスチャまたはアンカーポイントを使用します。 |
| **ワールド空間法線**&#x200B;カラー | ベイクワールド空間法線マップを使用します。 |
| **グラデーションの配置**&#x200B;カラー | ベイク処理された位置マップを使用します。 |
| **Thickness**&#x200B;グレースケール | ベイクThicknessマップを使用します。 |
| **曲線**&#x200B;グレースケール | ベイク処理された曲率マップを使用します。 |
| **環境オクルージョン**&#x200B;グレースケール | ベイク処理されたアンビエントオクルージョンマップを使用します。 |
| **マイクロ法線**&#x200B;カラー | カスタムの法線テクスチャまたはアンカーポイントを使用します。 |
| **マイクロHeight**&#x200B;の色 | カスタムテクスチャまたはアンカーポイントを使用します。 |

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| **グローバル反転** | すべてのレイヤーを結合した後で、最終結果を反転します。 |
| **グローバルぼかし** | すべてのレイヤーを結合した後に、最終的なマスクを均一にぼかします。 |
| **グローバル残高** | 明るさの調整のように、黒と白の間ですべてのレイヤーを結合した後で、最終的なマスクのバランスを調整します。 |
| **全体のコントラスト** | すべてのレイヤーを結合した後で、最終的なマスクのコントラストを調整します。 |
| **テクスチャの不透明度** | カスタムテクスチャの表示/非表示を調整します。 |
| **テクスチャ2の不透明度** | 2番目のカスタムテクスチャの可視性を調整します。 |
| **環境オクルージョンの不透明度** | 周囲オクルージョンのディテールの可視性を調整します。 |
| **曲線の不透明度** | 曲線のディテールの可視性を調整します。 |
| **ワールド空間の標準の不透明度** | ワールド空間の法線の詳細の可視性を調整します。 |
| **位置グラデーションの不透明度** | 位置の詳細の表示/非表示を調整します。 |
| **Thicknessの不透明度** | Thicknessのディテールの表示/非表示を調整します。 |

### 位置のグラデーション

| パラメーター名 | 説明 |
| --- | --- |
| **反転** | 位置グラデーションレイヤーを反転します。 |
| **残高** | グラデーションレイヤーの位置のバランスを調整し、中間点を明るさコントロールのように黒または白にシフトします。 |
| **コントラスト** | 位置グラデーションレイヤーのコントラスト/フォールオフを調整します。 |
| **明るさ** | 位置グラデーションレイヤーの輝度を調整します。 |
| **描画モード** | 現在のレイヤーに使用する[描画モード](../../../interface/layer-stack/blending-modes.md)を選択します。 |
| **右から左** | メッシュ上でエフェクトを左から右に適用する方法を調整します。 |
| **上から下** | メッシュ上で効果を上から下に適用する方法を調整します。 |
| **前後** | メッシュを横切ってエフェクトを前から後ろにどのように適用するかを調整します。 |

>[!TIP]
>
> 位置グラデーションは、右から左、上から下、前から後という最大3つのグラデーションで構成されます。 各サブグラデーションには独自の描画モードがあります。このモードを使用して、異なる効果を作成したり、モデルの異なる領域をマスクしたりできます。 これらのグラデーションの描画モードは、最終的な位置グラデーションレイヤーを作成するために相互に作用し合うだけで、位置グラデーション外のジェネレーターの他のレイヤーとは直接作用しません。
