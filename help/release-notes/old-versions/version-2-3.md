# バージョン2.3

**Substance Painter 2.3**&#x200B;では、最初の公式プラグイン（完全なレイヤースタックを使用したPhotoshop書き出し）をリリースするために、スクリプトAPIが改善されています。

リリース日： *15 September 2016*

## 主な機能

### 新しいPhotoshop書き出しプラグイン

![](../../assets/ps-230.jpg)

このリリースでは、**Photoshopの高度なエクスポーター**&#x200B;を実装するために、スクリプティングAPIに新しい可能性を加えることに焦点を当てています。 この新しい書き出しにアクセスするには、メインツールバーにある「Photoshop」アイコンをクリックします（プラグインがアクティブになっている場合。デフォルトではアクティブになっています）。 このプラグインを使用すると、テクスチャセットで使用可能な完全なレイヤースタックを書き出して、PSDファイル内に同様の構造を作成できます。 この機能&#x200B;**は、PSDファイルを作成するために、Photoshopがコンピューターにインストールされている**&#x200B;必要があります。

プラグインメニューの「設定」ボタンから、いくつかのオプションを使用できます。

![](../../assets/configure-ps.png)

## チュートリアル

最新のチュートリアルでは、新しいプラグインを使用した書き出しプロセスについて説明します。

## リリースノート

### 2.3.1

（2016年10月7日リリース）

**追加：**

* [プラグイン][Photoshop]書き出すマテリアル/スタック/チャンネルを指定できます
* [スクリプト]関数名に不整合がある

**修正済み：**

* [書き出し] Alphaは、カスタム書き出しプリセットで破棄できます
* [書き出し] sRGBチャンネルでAlphaのガンマ変換が正しく行われない
* [書き出し]非正方形のドキュメントは四角形で書き出されます
* [書き出し]追加のマップが見つからない場合、追加のマップを書き出すことができない
* [Ray]一部のパラメータ（放射強度など）は影響しません
* [NVIDIA] NVIDIA Quadro K2200/GTX 750/760で起動時にクラッシュする
* [AMD]サムネールとプレビューのカラーセットが正しくない
* [AMD]新しいファイルを開くとフリーズし、ドライバが失敗する
* [ログ]ログファイルに「software-version」がありません

### 2.3.0

（2016年9月15日リリース）

**追加：**

* [プラグイン]新しい「Photoshopに書き出し」プラグイン（完全なレイヤースタックの書き出し）
* [書き出し]パディングの幅をピクセル単位または無限単位で指定できます
* [書き出し] UVの外側の背景のタイプを設定できます
* [Shelf] 10種類のマテリアルをブレンドする新しいマテリアルレイヤシェーダ
* [Shelf] Height/法線チャンネルでディテールを表示する新しいクレイシェーダ
* [シェルフ]環境入力を備えた新しいベイクライティングフィルタ
* [Shelf]非正方形の変形を追加するいくつかのマスクジェネレータを更新しました
* [ビューポート]合成された法線マップ（法線+Height+ベイク）をソロモードに追加
* [スクリプト]追加のマップをエクスポートできます
* [スクリプト]テクスチャセットごとに使用可能な追加マップをクエリーできるようにします
* [スクリプト]チャネル形式の取得を許可する
* [スクリプティング]ベイクドキュメントに例を追加する
* [スクリプト]レイヤーの表示/非表示を照会できます
* [スクリプト]レイヤーの描画モードと不透明度を照会できます
* [スクリプト]変換されたマップ（最終的な法線マップ、混合AOなど）を書き出すことができます
* [Substance]カスタム使用状況の読み取りと接続
* [ショートカット]ソロモードを逆方向に切り替えるには修飾キー(Shift)を押します
* [書き出し]アルファを無効にするデフォルトの書き出しプリセットの更新
* [UI]エンジンが使用可能な場合にのみサムネールが計算されるようになりました
* [UI]サムネールの計算中にメンションを表示する

**修正済み：**

* 古いプロジェクトを開くとクラッシュする
* 破損したテクスチャチャチャチャネルキャッシュによるクラッシュ
* マテリアルレイヤーワークフローで4つ以上のマテリアルをブレンドするとクラッシュする
* [UI]ツールバーが非表示の場合にツールショートカットが機能しない
* [UI]表示メニューでIレイツールバーに「名称未設定」というラベルが付いている
* [UI]プラグインツールバーが表示メニューで「Untlanked」と表示される
* [Baker]ベイク設定の編集中にEnterを押すと、ベイク処理が開始する
* [Baker]一部のパラメータの範囲が正しくありません
* [読み込み] OBJメッシュを読み込むことができません（非常に大きな数が原因）
* [読み込み]読み込まれるOBJファイルのサブオブジェクトが多すぎます
* [書き出し]書き出し時にチャンネル背景がデフォルトカラーではなく黒で塗りつぶされる
* [ツール]視野が低すぎると、パーティクルが正しく動作しません
* [ツール]サブスタックのマスクでブラシプレビューの色が正しくない
* [ビューポート] 2Dビューでブラシが何もない領域に入ると、巨大になります
* [ビューポート]標準テクスチャをペイントする際に空白のブラシのプレビューが表示される
* [スクリプト]誤ったドキュメント: 「ambientocclusion」ではなく「ao」が表示される
* [スクリプティング] Painterを閉じると、subprocess()で開始したプロセスが終了する
* [シェルフ]ベイク処理されたライティングフィルタが誤ったAO入力を使用する
* [MacOS]削除された消火栓プロジェクト（非互換）
* \*.sppファイルを読み込むときに（\*.sppファイルではなく）既定のプロジェクトが開く
