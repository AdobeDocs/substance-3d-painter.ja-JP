# 位置

  <tr style="border: 0;">

    <td style="border: 0;" valign="top"><strong>説明</strong><br>位置ジェネレーターは、ベイク処理された位置とワールド空間の法線マップを使用して、3D空間でのマテリアルの位置（上から下、横から横など）に基づいてグラデーションマスクを作成します。<br><br>位置ジェネレーターは、モノクロ（白黒）テクスチャを出力します。 したがって、ワールド空間での位置に基づいてグラデーションマスクを生成する場合に便利です。<br><br>イメージ入力には、ベイク処理された位置とワールド空間の法線マップが必要です。 <a href="../../../baking/baking.md">ベーキングの詳細については、こちらを参照してください</a>。</td>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| **テクスチャ**&#x200B;の色 | カスタムテクスチャまたはアンカーポイントを使用します。 |
| **グラデーションの配置**&#x200B;カラー | ベイク処理された位置マップを使用します。 |
| **ワールド空間法線**&#x200B;カラー | ベイクワールド空間法線マップを使用します。 |

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| **グローバル反転** | すべてのエフェクトを合成した後で、最終的な結果を反転します。 |
| **グローバルぼかし** | すべてのグラデーションを結合した後に、最終的なマスクを均一にぼかします。 |
| **グローバル残高** | 明るさの調整のように、すべてのグラデーションを黒と白で合成した後で、最終的なマスクのバランスを調整します。 |
| **全体のコントラスト** | すべてのグラデーションを結合した後で、最終的なマスクのコントラストを調整します。 |
| **テクスチャの使用** | カスタムテクスチャマップの使用のオンとオフを切り替えます。 |

### 位置のグラデーション

| パラメーター名 | 説明 |
| --- | --- |
| **反転** | 位置のグラデーションのみを反転します。 |
| **残高** | 明るさコントロールのように、中間点を黒または白にシフトして、位置グラデーションのみのバランスを調整します。 |
| **コントラスト** | 位置グラデーションのみのコントラスト/フォールオフを調整します。 |
| **明るさ** | 位置グラデーションのみの輝度を調整します。 |
| **右から左** | メッシュ上でエフェクトを左から右に適用する方法を調整します。 |
| **上から下** | メッシュ上で効果を上から下に適用する方法を調整します。 |
| **前後** | メッシュを横切ってエフェクトを前から後ろにどのように適用するかを調整します。 |

#### グラデーションの位置/右から左

| パラメーター名 | 説明 |
| --- | --- |
| **反転** | 右から左のグラデーション方向を反転します。 |
| **描画モード** | 右から左へのグラデーションに使用する[描画モード](../../../interface/layer-stack/blending-modes.md)を選択します。 |

#### グラデーションの位置 / 上から下

| パラメーター名 | 説明 |
| --- | --- |
| **反転** | 上から下にグラデーションを反転します。 |
| **描画モード** | 上から下へのグラデーションに使用する[描画モード](../../../interface/layer-stack/blending-modes.md)を選択します。 |

#### グラデーションの位置 / 前から後ろ

| パラメーター名 | 説明 |
| --- | --- |
| **反転** | 前から後へのグラデーション方向を反転します。 |
| **描画モード** | 前面から背面へのグラデーションに使用する[描画モード](../../../interface/layer-stack/blending-modes.md)を選択します。 |
