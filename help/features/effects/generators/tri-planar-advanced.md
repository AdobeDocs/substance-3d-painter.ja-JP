# 3-平面上級

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_tri_planar_advanced.png" alt=""/><br><strong>内部：</strong>マスク、ジェネレータ</td>
    <td style="border: 0;" valign="top"><strong>説明</strong><br>三平面平面高度ジェネレータは、3平面の描画モードのスタンドアロン版で、投影全体を手動で制御できます。これには、それぞれの軸のすべての回転とオフセットの値の制御も含まれます。 通常の塗り潰し投影と比較すると、3分割平面高度ジェネレータでは、ワールド空間法線を使用して3つの投影軸をブレンドしますが、通常の実装ではローポリゴンジオメトリしか使用しません。 この結果、より制御しやすく、より正確な結果が得られます。<br><br>三平面の高度なジェネレーターは白黒テクスチャを出力します。 したがって、カスタムマスクまたはアンカーポイントを3平面ブレンドしてマスクとして使用すると便利です。<br><br>画像の入力には、ベイクされた位置マップとワールド空間法線マップが必要です。 <a href="../../../baking/baking.md">ベイク処理に関する詳細情報</a>。</td>
  </tr>
</table>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| **ワールド空間の標準**&#x200B;色 | ワールド空間法線マップを使用します。 |
| **位置**&#x200B;の色 | ベイク処理された位置マップを使用します。 |
| **マスク**&#x200B;グレースケール | カスタムテクスチャまたはアンカーポイントを使用します。 |

## パラメーター

<table>
  <tr>
    <th>パラメーター名</th>
    <th>説明</th>
  </tr>
  <tr>
    <td><strong>投影</strong></td>
    <td>すべての軸を投影するか、1つの軸のみを投影するかを選択します。</td>
  </tr>
  <tr>
    <td><strong>描画モード</strong></td>
    <td>描画モードを選択して、軸間でブレンドします。<br><ul><li><strong>リニア</strong>:リニア描画モードでは、描画トランジション線は直線です。</li><li><strong>詳細</strong>：詳細描画モードでは、指定された場所における3つの軸と標準角度の間の最大値に基づいて軸が描画されます。</li></ul></td>
  </tr>
  <tr>
    <td><strong>描画コントラスト</strong></td>
    <td>ブレンドの変化線をぼかす度合いを調整します。</td>
  </tr>
  <tr>
    <td><strong>テクスチャタイリング</strong></td>
    <td>マスクテクスチャのタイリングを調整します。</td>
  </tr>
</table>

### X 軸

| パラメーター名 | 説明 |
| --- | --- |
| **回転X** | X軸テクスチャ投影を回転します。 |
| **オフセットX X** | Xテクスチャ投影を左右に動かします。 |
| **オフセットX Y** | Xテクスチャ投影を上下に動かします。 |

### Y 軸

| パラメーター名 | 説明 |
| --- | --- |
| **回転X** | Yテクスチャ投影を回転させます。 |
| **オフセットY X** | Yテクスチャ投影を左右に動かします。 |
| **オフセットY Y** | Y軸テクスチャ投影を上下に移動します。 |

### Z 軸

| パラメーター名 | 説明 |
| --- | --- |
| **回転X** | Zテクスチャ投影を回転します。 |
| **オフセットZ X** | Zテクスチャ投影を左右に動かします。 |
| **オフセットZ Y** | Zテクスチャ投影を上下に動かします。 |
