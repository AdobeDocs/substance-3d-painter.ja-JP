# 艶消し仕上げ線形ブラシ

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

MatFinishブラシ付き線形フィルタは金属仕上げコレクションの一部であり、線形ブラシ付き金属効果を作成するために使用されます。

塗りつぶしレイヤーで使用されます。 基本塗りつぶしレイヤーの色、ラフネス、メタリック、およびその他のプロパティを調整し、最終的な表面処理に使用するフィルターを追加します。

</tr>

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>シード：</b> | ランダム値を割り当てると、全体的な設定を変更することなく、異なるバリエーションを作成できます。 |
| <b>スケール：</b> | 仕上げの全体的なスケールを調整します。 |
| <b>ブラシの適用度：</b> | ブラシ効果の適用度を調整します。 |
| <b>長さ：</b> | ブラシを適用した線の長さを調整します。 |
| <b>回転：</b> | ブラシを適用したパターンの回転を調整します。 |
