## 説明

ベベルフィルターは、グレースケールのシェイプとマスクにベベルのエッジを追加します。

シェイプのエッジに沿ってベベルのリリーフを作成するには、テクスチャレイヤー上またはマスクの内側（白黒出力）に使用します。

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>ベベルラップ：</b> | ベベルタイルを水平および垂直にラップするように切り替えます。 |
| <b>距離：</b> | ベベルサイズを調整します。 |
| <b>コーナーの種類：</b> | ベベルの角を丸くするか、angularにするかを選択します。 |
| <b>滑らかさ：</b> | ベベルに適用するスムージングの量を調整します。 スムージングを行わないと、曲線に沿ってエイリアスが発生し、曲線のベベルに線が表示されることがあります。 |
| <b>ぼかしモード：</b> | ベベルでブラー（均一）とブラー（不均一）のどちらを使用するかを選択します。 「不均一なぼかし」は、ベベルされた領域にブラーエフェクトを集中させます。これはディテールを維持するのに役立ちますが、均一なぼかしは一貫しています。 |
