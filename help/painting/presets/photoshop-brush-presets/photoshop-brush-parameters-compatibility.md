# Photoshopのブラシパラメーターの互換性

このページには、すべてのSubstance 3D Painterブラシパラメーターと、Photoshopブラシエンジンとの互換性が一覧表示されます。

## 一般的な互換性

ABRファイル内を見ると、Substance 3D Painterは以下の特定のブラシ/ツールプリセットのみを取得します。

| *プリセットの種類* | *サポート* | *説明* |
| --- | --- | --- |
| **ブラシ（ビットマップ）** | 読み込み済み | ビットマップをアルファとして基づくブラシプリセットが読み込まれます。 |
| **ブラシ(プロシージャル)** | 無視 | プロシージャルのシェイプ（円など）に基づいたブラシプリセットは読み込まれません。 |
| **ブラシ（エアブラシ）** | 無視 | エアブラシ設定のブラシプリセットは読み込まれません。 |
| **ブラシ（絵筆）** | 無視 | 絵筆が設定されているブラシプリセットは読み込まれません。 |
| **ブラシ（侵食）** | 無視 | 侵食できる設定のブラシプリセットは読み込まれません。 |
| **鉛筆** | 無視 | 鉛筆プリセットは読み込まれません。 |
| **混合ブラシ** | 無視 | ミキサーブラシプリセットが読み込まれない。 |
| **クローンスタンプ** | 無視 | クローンスタンププリセットは読み込まれません。 |
| **指先** | 無視 | 指先プリセットが読み込まれない。 |

## パラメーター

これらのパラメーターでできる操作の詳細については、[Photoshopの公式ドキュメント](https://helpx.adobe.com/photoshop/using/creating-modifying-brushes.html)を参照してください。

一部のPhotoshopブラシパラメーターはサポートされていません。 凡例を参照して、以下に示す各パラメータのステータスを確認してください。

* **正方形(■)** ：パラメーターがサポートされていることを示します。パラメーターへのアクセス方法については、説明を参照してください。
* **クロス(✖)** ：このパラメーターがサポートされていないことを示します。
