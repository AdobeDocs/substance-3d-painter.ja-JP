# MatFX詳細Edge Wear

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="./Resources/icon_matfx_detail_edge_wear.png" alt="MatFX詳細Edge Wearアイコン" title="MatFX詳細Edge Wear"/><br><strong>イン：</strong>効果/摩耗、エッジ、マテリアル</td>
    <td style="border: 0;" valign="top">説明<br>MatFX詳細Edge Wearフィルターは、マテリアルにブレンドできる損耗したエッジのディテールを作成します。<br>テクスチャレイヤーまたはマテリアルスタックで使用され、エッジの摩耗、データの分割、およびマスクと曲率 経年劣化によるマテリアル調整を加えます。</td>
  </tr>
</table>

>[!NOTE]
>
> MatFX詳細Edge Wearフィルタに目に見える効果を与えるには、フィルタの下のレイヤースタックに既存のさまざまな法線の情報が存在している必要があります。 法線チャンネルにデータがないか、変化がない場合、フィルタはダメージを受けるエッジを検出できず、目に見える効果はありません。

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| **ぼかしの強さ：** | ブラーエフェクトの強さを調整します。 |
| **ぼかしの回り込み：** | ぼかしのラップを切り替えます。 有効にすると、テクスチャの反対側からピクセルがサンプリングされます。 |
| **入力モード：** | 摩耗効果の駆動に使用する入力モードを選択します。 |
| **摩耗レベル：** | 全体的な摩耗レベルを調整します。 |
| **コントラストをつける：** | 摩耗マスクのコントラストを調整します。 |
| **エッジのSmoothness:** | 損耗したエッジのSmoothnessを調整します。 |
| **経年劣化量：** | 磨耗に加える経年劣化の量を調整します。 |
| **経年劣化スケール：** | 経年劣化パターンの尺度を調整します。 |

### マテリアル

**PBR メタリックラフネス**

|  |  |
| --- | --- |
| **Base color:** | base color量を調整します。 |
| **メタリック:** | メタリック値を調整します。 |
| **ラフネス:** | ラフネスの値を調整します。 |

**PBR Specular 光沢度**

|  |  |
| --- | --- |
| **Diffuse:** | 拡散の効果を調整します。 |
| **Specularの色：** | Specularのカラーを調整します。 |
| **光沢度:** | 光沢度の値を調整します。 |

### 設定

|  |  |
| --- | --- |
| **ジェネレーターマスクコントロール：** | ジェネレータマスクの影響を調整します。 |
| **Generatorマスクのコントラスト：** | ジェネレータマスクのコントラストを調整します。 |
| **Generatorマスクのぼかし：** | ジェネレーターマスクに適用されるぼかしを調整します。 |
| **Alphaの背景の値：** | 背景のアルファ値を調整します。 |
| **曲率の強さ：** | 曲率入力の強さを調整します。 |
| **曲率の反転：** | 曲率入力の切り替え。 |
| **曲率の組み合わせ：** | 反転された反転データと非反転曲率データの組み合わせを切り替えます。 |
| **法線の強度：** | 法線の強度を調整します。 |
| **AO展開：** | ambient occlusion効果の間隔を調整します。 |
