# バージョン2.5

**Substance Painter 2.5**&#x200B;には多くの新機能が導入されています。ブラシ設定（フローに加え）での不透明度のサポートから、8Kでの追加マップのベイク機能など、その他多くの機能があります。

リリース日： *2017年2月21日*

## 主な機能

### 新規ブラシの不透明度

![](../../assets/brush-combined.gif){width="650px"}

Substance Painterでペイントする場合の&#x200B;**ブラシパラメーター**&#x200B;に、**不透明度**&#x200B;という新しい設定が追加されました。\
**不透明度**&#x200B;は、ブラシストローク内の&#x200B;**個々のスタンプ**&#x200B;の強度を制御する&#x200B;**フロー**&#x200B;設定とは異なり、ブラシストロークの&#x200B;**全体の強度**&#x200B;を制御します。 これにより、同じ領域&#x200B;**に対して、重なり合う値**&#x200B;を作成することなく、ペイントおよび再描画ができるようになりました。 そのためには、流量を100に設定し、不透明度の値を目的の強度に設定します。 不透明度の仕組みにより、ペンの圧力にリンクできません。 このような制御を行う場合でも、フローを選択することをお勧めします。

また、この新しいパラメーターと一緒に&#x200B;**新しい修飾子**&#x200B;も追加しました。このパラメーターは、既定では&#x200B;**&quot;A&quot;**&#x200B;キーにあります。 このキーを押すと、新しいブラシストロークを作成する代わりに&#x200B;**前のブラシストロークを続行**&#x200B;できます。 つまり、カメラを動かしたくなるような不透明度を維持しながら、必要な不透明度で均一カラーにペイントを付けることができます。 別の例として、クローン・ツールで行っていたコピーを続行できます。

![](../../assets/stroke-opacity-parameter.png)

### 8Kおよび非正方形の解像度での新しいベイク処理

![](../../assets/baking-250-8k.png)

ベイカーが改善され、最大&#x200B;**8192x8192** （8K +アンチエイリアス）の解像度がサポートされました。これにより、追加のマップを使用して、1:1の比率で8Kで書き出すことができます。\
**非正方形**&#x200B;解像度のサポートも追加されました。 **4096x2048**&#x200B;などのテクスチャをベイクできるようになりました。 これを行うには、ドロップダウンの横にある「**ロック**」アイコンをクリックして解像度を選択します。

### ビューポートでのカラープロファイルの新しいサポート

![](../../assets/lut-example.jpg)

Substance Painterーで&#x200B;**ビューポート**&#x200B;のレンダリングを制御するために、**LUT** (テクスチャ)のサポートが追加されました。 プロファイルを適用するには、「**ディスプレイ設定**」ウィンドウで「**カラープロファイル**」設定を有効にし、専用スロットにLUTを読み込みます。 **OpenGL** ビューポート （ペイント）と&#x200B;**Iray**&#x200B;レンダラーの両方で使用できます。 一般的な&#x200B;**カメラプリセット**&#x200B;から多くの&#x200B;**アート効果**&#x200B;まで、初期設定でいくつかの例が利用できます。 詳細については、ドキュメントの専用ページを参照してください： [カラープロファイル](../../features/post-processing/color-profile.md)

### Substance Designer 6と互換性のある新しいSubstanceエンジン

![](../../assets/font-shelf.png)

**Substance Designer 6**&#x200B;のサポートが追加されました。**SD6**&#x200B;で作成されたリソースは、**Substance Painter 2.5**&#x200B;で開いて使用できます。\
たとえば、SD6の&#x200B;**新しいテキストノード**&#x200B;を使用して、それを物質に統合することができます。 これにより、アプリケーションを離れることなく、**ダイナミックテキスト**&#x200B;を作成し、直接ペイントすることができます。 **最も一般的な用途に対応するために、デフォルトでそれぞれ異なるスタイルの10個のフォント**&#x200B;を含めました。 **シェルフ**&#x200B;の「**プロシージャル**」セクションで確認できます。

![](../../assets/text-sp250-optim.gif){width="400px"}

### シェルフの新しいコンテンツ

![](../../assets/new-filters.jpg)

新しいシェルフの修正と機能強化に加え、ペインティングとテクスチャリングを改善するための&#x200B;**新しいフィルター**&#x200B;もいくつか追加されました。 また、既存のフィルターの動作も&#x200B;**改善**&#x200B;しました（「**HSL**」など）。 **新しいプロジェクト** （**Unity 5**&#x200B;や&#x200B;**アンリアルエンジン 4**&#x200B;など）を作成するときに、新しい&#x200B;**テンプレート**&#x200B;も追加されました。

### カスタムシェーダー UIのサポートによる新しいスクリプトの改善

![](../../assets/ui-shader.jpg)

このリリースでは、**シェーダーパラメーター**&#x200B;を&#x200B;**スクリプトおよび制御**&#x200B;する方法が追加されました。 また、既定のUIの代わりに&#x200B;**カスタムUI**&#x200B;を使用できるようになりました。これにより、**アニメーションシェーダー**&#x200B;など、多くの新しい可能性が開かれました。\
詳しくは、アプリケーションのヘルプメニューからアクセスできるスクリプト言語のドキュメントを参照してください。
