# ワールド空間法線

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_world_space_normals.png" alt=""/><br><strong>イン：</strong>マスク、ジェネレーター、グレースケール、ブレンド</td>
    <td style="border: 0;" valign="top"><strong>説明</strong><br>ワールド空間法線ジェネレータは、ベイクされたワールド空間法線マップを使用して、モデルに色を付けたり、3D空間で各サーフェスが向いている方向に基づいて効果を適用したりします。 例えば、上から下に表示されます。<br><br>ワールド空間法線ジェネレータは、白黒テクスチャを出力します。 これにより、マスクを作成して、顔の向きに基づいてDirt、Dust、雪、錆などの様々なエフェクトを適用するのに便利です。<br><br>画像の入力には、ベイクされた位置マップとワールド空間法線マップが必要です。 <a href="../../../baking/baking.md">ベイク処理に関する詳細情報</a>。</td>
  </tr>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| **テクスチャ**&#x200B;の色 | カスタムテクスチャまたはアンカーポイントを使用します。 |
| **ワールド空間法線**&#x200B;カラー | ワールド空間法線マップを使用します。 |
| **グラデーションの配置**&#x200B;カラー | ベイク処理された位置マップを使用します。 |

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| **グローバル反転** | すべてのエフェクトを合成した後で、最終的な結果を反転します。 |
| **グローバルぼかし** | すべての効果を組み合わせた後に、最終的なマスクを均一にソフトにします。 |
| **グローバル残高** | 明るさの調整のように、すべての効果を黒と白で合成した後に、最終的なマスクのバランスをシフトします。 |
| **全体のコントラスト** | すべての効果を組み合わせた後に、最終的なマスクのコントラストを調整します。 |
| **テクスチャを使用** | カスタムテクスチャマップの使用のオンとオフを切り替えます。 |

### ワールド空間法線

| パラメーター名 | 説明 |
| --- | --- |
| **反転** | ワールド空間法線だけを反転します。 |
| **ぼかし** | ワールド空間法線のみを滑らかにします。 |
| **残高** | ワールド空間法線のバランスのみを調整し、明るさコントロールのように、中心点を黒または白にシフトします。 |
| **コントラスト** | ワールド空間法線のコントラスト/フォールオフのみを調整します。 |
| **明るさ** | ワールド空間法線のみの輝度を調整します。 |
| **右から左** | メッシュ上でエフェクトを左から右に適用する方法を調整します。 |
| **上から下** | メッシュ全体で効果を上から下に適用する方法を調整します。 |
| **前後** | メッシュを横切ってエフェクトを前から後ろにどのように適用するかを調整します。 |

#### ワールド空間法線 / 右から左

| パラメーター名 | 説明 |
| --- | --- |
| **反転** | 右から左のグラデーション方向を反転します。 |
| **描画モード** | 現在のレイヤーに使用する[描画モード](../../../interface/layer-stack/blending-modes.md)を選択します。 |

#### ワールド空間法線 / 上から下

| パラメーター名 | 説明 |
| --- | --- |
| **反転** | 上から下のグラデーション方向を反転します。 |
| **描画モード** | 現在のレイヤーに使用する[描画モード](../../../interface/layer-stack/blending-modes.md)を選択します。 |

#### ワールド空間法線 / 前から後ろ

| パラメーター名 | 説明 |
| --- | --- |
| **反転** | 前から後へのグラデーション方向を反転します。 |
| **描画モード** | 現在のレイヤーに使用する[描画モード](../../../interface/layer-stack/blending-modes.md)を選択します。 |
