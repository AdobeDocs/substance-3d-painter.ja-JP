# UVテクセル密度

    <td style="border: 0;" valign="top"><strong>説明</strong><br>UVテクセル密度ジェネレーターは、色付きのグラデーションを低から高に適用して、メッシュのテクセル密度を視覚化します。<br>UVテクセル密度ジェネレーターは、フルカラーテクスチャを出力します。一貫性のないUVスケーリングを特定し、モデル全体でテクスチャの詳細を均一にするために、塗りつぶしレイヤーで使用するのが最適です。</td>

>[!NOTE]
>
> Texel densityは、モデルの特定のサーフェス領域のテクスチャ（テクスチャピクセル）の数を示します。 テクセル密度が高いと、モデルの小さな領域に多くのディテールを詰め込むことができます。テクセル密度が低いとディテールの量が制限されますが、パフォーマンスは向上します。 一般に、マテリアルの解像度に関係なく、メッシュ全体でテクスチャの密度を一定に保つことをお勧めします。テクスチャの密度が大きく異なることは多くの場合目に見え、アセットが低品質または非現実的に感じられる場合があるためです。

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| **低色** | テクスチャ密度が&#x200B;**低**&#x200B;の領域に使用する色を設定します。 |
| **カラーメディア** | テクスチャ密度が&#x200B;**中**&#x200B;の領域に使用する色を設定します。 |
| **カラー（高）** | テクスチャ密度が&#x200B;**高**&#x200B;の領域に使用する色を設定します。 |
