# バージョン2017.1

新しいバージョン指定に従って、Substance PainterのSubstance番号が変更されます。 詳細については、<https://www.allegorithmic.com/welcome-to-substance>を参照してください。\
今回の新しいバージョンでは、Substance Sourceを参照して素材を直接棚に読み込むことができる新しいプラグインを提供することで、コンテンツに焦点を当てたいと考えました。 また、クリエイティブの可能性を広げるために、多くの新しいアセットが追加されました。

リリース日： *20 June 2017*

## 主な機能

### 新しいプラグイン:Substance Source

![](../../assets/source-optim.gif)

この新しいプラグインを使用すると、**Substance Source**&#x200B;と呼ばれる資料のデータベースを&#x200B;**直接参照**&#x200B;し、**シェルフに直接**&#x200B;ダウンロードして、すぐに使用してプロジェクトで使用することができます。\
Substance Sourceを開くには、アプリケーションのメインツールバー&#x200B;**にあるSubstance Sourceロゴ**&#x200B;をクリックします。 これにより、ライブラリを参照できる新しいウィンドウが開きます。

![](../../assets/source-overview.jpg){width="650px"}

### 新しいコンテンツ:Alpha、手続き、フィルターなど

![](../../assets/new-alphas-gif.gif)

この新しいバージョンでは、**300以上の新しいアセット**&#x200B;を追加しています。 **SF**、**幾何学的**、**中世**、さらには&#x200B;**ケルト語**&#x200B;をテーマにしたコンテンツをアルファに追加しました。 また、多数の&#x200B;**新しいブラシ**&#x200B;と&#x200B;**スキャンされた指紋/指紋**&#x200B;も含まれています。 また、メッシュにペイントした通常のEdge Wear **から**&#x200B;傷&#x200B;**を直接**&#x200B;生成できる&#x200B;**MatFX詳細情報**&#x200B;などの便利な新しいフィルターも提供しています。

新しいコンテンツのリストは次のとおりです。

* **4つの新しいフォント** （日本語、簡体字中国語、タイプライター、セグメント）
* **230件の新しいAlpha** （パターンとスキャンした画像の組み合わせ）
* **50件の新しい手順** （主に中世と現代の衣料品に使用される生地のパターン）
* **2つの新しい環境マップ** （モンダレインとヴィラノヴァストリート）
* **9新しいフィルター** （MatFX詳細Edge Wear、クランプ、HBAOなど）

![](../../assets/alpha-content.jpg)![](../../assets/alpha-demo-image.jpg)

また、既存のアセットの一部も更新して作業を改善しました。たとえば、**既定の環境マップ**&#x200B;は、**黄色が抑えられるように見えるようになりました。**

![](../../assets/new-env-map.gif)
