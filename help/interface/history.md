# ヒストリー

![](../assets/history-list.png)\
ヒストリーウィンドウには、現在開いているプロジェクトで行われたすべてのアクションと変更が一覧表示されます。

* リストの各要素をクリックすると、アクションが作成/適用された時点のプロジェクトの状態に戻ることができます。
* リストの最後の要素にない場合に新しいアクションを作成すると、既存の今後のアクションは消去され、代わりに新しいアクションに置き換えられます。
* 操作はプロジェクトに対してグローバルであるため、2つの異なるテクスチャセットでレイヤーを作成すると、同じリストに表示されます。

すべてのテクスチャはプロジェクトに保存され（すべての情報を再ペイント/再保存できるようにする）、プロジェクトを閉じて再び開くと、履歴リストにアクセスできなくなります。 履歴リストは、現在のセッションでのみ使用できます。
