# 塗りつぶし（UVタイルごとに一致）

**塗りつぶし（UVタイルごとに一致）**&#x200B;は、[UVタイル](../../features/uv-tiles/uv-tiles.md)のプロジェクトに役立つ特別な2D投影法です。 これにより、各UVタイルのシーケンスからUDIMテクスチャを割り当てることができます。

この投影には専用の設定はありません。1つ以上のイメージが各UVタイルを塗りつぶすように割り当てられます。 設定がないので、このモードはパフォーマンスにも優れています。

| モード | 説明 |
| --- | --- |
| **UV 投影** | 単一の画像またはシーケンスから最初に取得した画像が、すべてのUVタイルに適用されます。 これにより、変形コントロールも提供されます。詳細については、[UV 投影](uv-projection.md)を参照してください。 <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r1-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/uv-3.jpg" width="700px"/></div> |
| **塗りつぶし（UVタイルごとに一致）** | シーケンスの各イメージは、専用のUVタイルに割り当てられます。 変形コントロールはありません。 <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r2-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/fill-match.jpg" width="700px"/></div> |
