## 入力

| 名前を入力 | 説明 |
| --- | --- |
| **ワールド空間の標準**&#x200B;色 | ベイクワールド空間法線マップを使用します。 |
| **位置**&#x200B;の色 | ベイク処理された位置マップを使用します。 |

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| **反転** | 出力カラーマップを反転します。 |
| **水平角度** | フェイクライトの水平角度を設定します。 |
| **頂角** | フェイクライトの頂角を設定します。 |
| **光沢の強調** | ハイライト表示された領域のフォールオフの広がりを調整します。 |
| **ハイライトレベル** | ハイライトのコントラストを調整します。 |
| **光の減衰** | 光の減衰を調整します。 |
