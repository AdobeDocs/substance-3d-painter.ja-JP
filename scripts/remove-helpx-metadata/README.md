# 従来のHelpXメタデータの削除

Python 3.10以降では、リポジトリルートから次のコマンドを実行します。

```shell
python remove_helpx_metadta.py 1 <path>
python remove_helpx_metadta.py 2 <path>
```

モード`1`はドライランです。一致するファイルが一覧表示され、ファイルの数が報告されます
スキャンされたファイル、一致するファイル、一致するメタデータフィールドが、ファイルを変更せずにスキャンされます。
モード`2`はこれらのフィールドを削除し、削除数を報告します。 `<path>`を省略して
現在のフォルダーをスキャンします。 スペースを含む引用パス。

スクリプトは`.md`ファイルを再帰的にスキャンし（大文字と小文字は区別されません）、最上位のファイルを削除します
名前が`helpx`で始まるYAML前付けフィールド（複数行も含む）
の値を返します。 他のメタデータ、コメント、空行、マークダウンコンテンツ、
エンコーディングと行末。 本文内の`helpx`参照は削除されません。
モード`2`を使用する前にドライ配管を確認してください。削除すると、次の操作なしでファイルが編集されます：
バックアップの作成 ファイルエラーと未完了の前付が報告され、
ゼロ以外の終了ステータス。 クローズされていない前付を持つファイルは変更されません。
