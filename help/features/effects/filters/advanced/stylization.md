## 説明

「スタイル設定」フィルターを使用すると、マテリアルを手描きのようなスタイルに仕上げることができます。

テクスチャレイヤー上で使用され、ブラシストローク、Smoothnessのバリエーション、カラーリマップ、ベイク照明効果を追加します。

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>スタイル化：</b> | フィルターの全体的な適用度を調整します。 |
| <b>ブラシストローク：</b> | ブラシストローク効果の適用度を全体的に調整します。 |
| <b>Smoothness:</b> | Smoothnessエフェクトの適用度を全体的に調整します。 |
| <b>色付け：</b> | カラー化エフェクトの全体的な適用度を調整します。 |
| <b>グラデーション：</b> | グラデーション効果の全体的な強度を調整します。 |
| <b>ベイクした明るさ：</b> | ベイクする照明効果の全体的な強さを調整します。 |
| <b>エッジとキャビティ：</b> | エッジとキャビティエフェクトの全体的な強度を調整します。 |

### ブラシストローク

| パラメーター名 | 説明 |
| --- | --- |
| <b>ストロークの量：</b> | フィルターによって使用されるブラシストロークの量を調整します。 |
| <b>ストロークモード：</b> | フィルターで使用するブラシストロークの種類を選択します。 |
| <b>ストロークの選択：</b> | 複数のストロークを使用するときに投影するブラシストロークのシェイプを選択します。 |
| <b>ストロークの選択：</b> | 1つのストロークを使用するときに、投影するブラシストロークのシェイプを選択します。 |
| <b>ストロークのスケール：</b> | ブラシストロークのスケールを調整します。 |
| <b>均一でないサイズ：</b> | 投影されたブラシストロークの不均等なスケーリングを切り替えます。 |
| <b>ストロークのサイズ：</b> | 投影されたブラシストロークの縦横比を調整します。 |
| <b>ストロークのスケール（ランダム）:</b> | ブラシストロークに適用されるランダムスケールの変化量を調整します。 |
| <b>ストロークはサーフェスに従う：</b> | ブラシストロークのアラインメントをメッシュ方向に切り替えます。 |
| <b>ストロークの回転：</b> | ブラシストロークの回転角度を調整する |
| <b>ストロークのランダムな回転：</b> | ブラシストロークに適用されるランダムな回転の量を調整します。 |
| <b>硬さ:</b> | スタンプ投影の硬さを調整します。 |
| <b>標準しきい値：</b> | ストロークの投影に使用する標準のしきい値を調整します。 |
