# 設定

![](../../assets/settings-general.png){width="400px"}

<b>編集メニュー</b>の<b>設定</b>を開いて、Painterの操作方法に関する環境設定を調整します。

<b>設定</b>は、次の3つのセクションに分かれています：

* [一般環境設定](general-preferences.md)
* [ショートカット](shortcuts.md)
* [ライブラリ設定](libraries-configuration.md)
