# Universal Scene Description（米ドル）

![](../assets/banner-usd.jpg)

USDワークフローは、Painter 8.3で利用できます。 [USD](https://graphics.pixar.com/usd/release/intro.html)は、Pixarが開発した、多くの異なる種類のデータを伝送できる、コラボレーションに適した交換可能な形式です。

Painterでは、次のことが可能になりました。

* [プロジェクトを作成する](../getting-started/project-creation.md)。スコープとバリアントの選択、サブディビジョンレベル、アニメーションフレームなど、米ドル固有の機能を使用します。
* USD形式を使用して、[書き出し](../export/export-window/export-settings.md)のマテリアルとテクスチャ。
* また、メッシュのみの書き出し用の新しいファイル形式としてUSDが追加されました。
