# ミラー対称

ミラーシンメトリは軸ベースのシンメトリで、コンテキストツールバーで有効にできます。

![](../../assets/symmetry-mirror.png)

## マニピュレータを使用して対称軸を配置します

対称表示設定には、3Dビューの上部にあるコンテキストツールバーの<b>対称設定ボタン</b>からアクセスできます。 表示設定では、マニピュレータを有効にしてカスタマイズできます。 3Dビューでマニピュレータハンドルをドラッグして、対称軸の位置を変更します。

![](../../assets/MirrorSymmetryManip.png)

## 対称パラメータのミラー

![ミラー対称設定のスクリーンショット](../../assets/MirrorSymmetry-2.png){width="300px"}

| *パラメーター* | *説明* |
| --- | --- |
| <b>軸</b> | シンメトリの実行に使用するシーンの軸を定義します。 |
| <b>軸の位置</b> | プロジェクトの軸のオフセットを定義します。 この値は、スライダまたはマニピュレータ（上記を参照）を使用して編集できます。 |
| <b>平面の表示</b> | 有効にすると、ミラーされたシンメトリの両側を区切る透明な平面がビューポートに表示されます。 |
| <b>交差点を表示</b> | 有効にすると、ビューポート内のメッシュ上に線が描画され、ミラーされたシンメトリの両側が区切られます。 |
| <b>カーソルの表示</b> | 有効にすると、2番目のカーソルがシンメトリの反対側に表示され、ペイントが実行されるタイミングが示されます。 |
| <b>描画中に非表示にする</b> | このオプションを有効にすると、ペイントの実行中（マウスクリックを放すまで）に2番目のカーソルが非表示になります。 |
| <b>マニピュレータのサイズ</b> | ビューポートのマニピュレータのサイズを制御します。 |
