# 曲率

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_curvature.webp" alt=""/><br><strong>イン：</strong>マスク、ジェネレーター、グレースケール、ブレンド</td>
    <td style="border: 0;" valign="top"><strong>説明</strong><br>曲線ジェネレーターは、ベイク処理された曲線マップに基づいてマスクを作成します。マスクにテクスチャまたは微細なディテールをブレンドするオプションもあります。<br><br>曲線ジェネレーターは、白黒のテクスチャを出力します。 そのため、レイヤーに直接適用するのではなく、マスクを生成するのに便利です。<br><br>ベイク処理された位置マップは、入力として必要です。 <a href="../../../baking/baking.md">ベーキングの詳細については、こちらを参照してください</a>。</td>
  </tr>
</table>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| **テクスチャ**&#x200B;の色 | カスタムテクスチャまたはアンカーポイントを使用します。 |
| **マイクロ法線**&#x200B;カラー | カスタムの法線テクスチャまたはアンカーポイントを使用します。 |
| **マイクロHeight**&#x200B;の色 | カスタムテクスチャまたはアンカーポイントを使用します。 |
| **曲線**&#x200B;グレースケール | ベイク処理された曲率マップを使用します。 |
| **ワールド空間法線**&#x200B;カラー | ベイクワールド空間法線マップを使用します。 |
| **グラデーションの配置**&#x200B;カラー | ベイク処理された位置マップを使用します。 |

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| **グローバル反転** | すべてのエフェクトを合成した後で、最終結果を反転します。 |
| **グローバルぼかし** | すべての効果を組み合わせた後に、最終的なマスクを均一にソフトにします。 |
| **グローバル残高** | 明るさの調整のように、すべての効果を黒と白で合成した後に、最終的なマスクのバランスをシフトします。 |
| **全体のコントラスト** | すべての効果を組み合わせた後に、最終的なマスクのコントラストを調整します。 |
| **テクスチャの使用** | カスタムテクスチャマップの使用のオンとオフを切り替えます。 |
| **マイクロディテールを使用** | カスタムマイクロ詳細マップの使用のオンとオフを切り替えます。 |

### テクスチャ

<table>
  <tr>
    <th>パラメーター名</th>
    <th>説明</th>
  </tr>
  <tr>
    <td><strong>テクスチャの不透明度</strong></td>
    <td>カスタムテクスチャの表示を制御します。</td>
  </tr>
  <tr>
    <td><strong>反転</strong></td>
    <td>カスタムテクスチャのみを反転します。</td>
  </tr>
  <tr>
    <td><strong>グレースケール変換</strong></td>
    <td>カラー入力を白黒に変換する方法を選択します。 </td>
  </tr>
  <tr>
    <td><strong>描画モード</strong></td>
    <td>カスタムテクスチャの描画モードを設定します。</td>
  </tr>
  <tr>
    <td><strong>拡大・縮小</strong></td>
    <td>カスタムテクスチャのサイズを調整します。</td>
  </tr>
  <tr>
    <td><strong>コントラスト</strong></td>
    <td>カスタムテクスチャのコントラスト/フォールオフを設定します。</td>
  </tr>
  <tr>
    <td><strong>明度</strong></td>
    <td>カスタムテクスチャの輝度を設定します。</td>
  </tr>
  <tr>
    <td><strong>Triplanar</strong></td>
    <td>Triplanarを有効にすると、テクスチャはUVのみに依存するのではなく、3方向（X、Y、Z軸）から投影されます。 <br><ul><li>Triplanarを有効にしていない場合、テクスチャはUVレイアウトに従います。</li><li>三角形を有効にすると、テクスチャは複数の角度から投影され、ブレンドされます。</li></ul></td>
  </tr>
  <tr>
    <td><strong>Triplanar のコントラスト</strong></td>
    <td>三平面マッピングを使用して、投影時にテクスチャがブレンドされる滑らかさを調整します。 これにより、各方向からの投影間のブレンドの柔らかさが調整されます。</td>
  </tr>
</table>

### マイクロ詳細

<table>
  <tr>
    <th>パラメーター名</th>
    <th>説明</th>
  </tr>
  <tr>
    <td><strong>マイクロ高さ</strong></td>
    <td>カスタムマイクロHeightマップの使用のオンとオフを切り替えます。</td>
  </tr>
  <tr>
    <td><strong>マイクロ法線</strong></td>
    <td>カスタムマイクロ法線マップの使用のオン/オフを切り替えます。</td>
  </tr>
  <tr>
    <td><strong>曲率の種類</strong></td>
    <td>曲線のタイプを設定します。 <br><ul><li><strong>標準</strong>：通常、非常にシャープな結果が得られますが、詳細の幅が狭くなる場合があります。</li><li><strong>Sobel</strong>: Sobelフィルターを使用して法線マップを評価するため、標準と比較して同様の結果が得られますが、やや不鮮明です。</li><li><strong>滑らか</strong>：情報を累積するために、さまざまなレベルのぼかし（ミップマップなど）を作成します。 これにより通常はより滑らかなカーブになりますが、ディテールが失われる可能性があります。</li></ul></td>
  </tr>
  <tr>
    <td><strong>曲率の強度</strong></td>
    <td><strong>標準</strong>および<strong>ソベル</strong>曲線モードで曲線の強さを調整します。</td>
  </tr>
  <tr>
    <td><strong>高さの詳細の強度</strong></td>
    <td>マイクロHeightディテールの強度を調整します。</td>
  </tr>
</table>
