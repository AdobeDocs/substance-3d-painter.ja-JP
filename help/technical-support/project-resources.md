# プロジェクトのリソースと設定

プロジェクトリソースを管理することで、Painterでのプロジェクトのパフォーマンスに適した基盤を構築できます。

+++ベイク済みマップを縮小
すべてのベイク済みマップが2Kまたは4K解像度である必要がない場合もあります。 2Kでバッチをベイクし、低い分解能で再ベイクして視覚的な違いがあるかどうかを確認してください。

+++

+++読み込まれたビットマップの管理
読み込まれた画像はパフォーマンスに大きな影響を与える可能性があるため、読み込まれる画像に注意することが重要です。 テクスチャセットが2Kに設定されていて、これより高い解像度で書き出されない場合、8K画像を使用しても良い影響はありません。テクスチャセットの解像度であるため、画質は2Kに制限されます。

フォーマットも重要です。EXR、HDR、PNGでさえ、JPGよりもはるかに重く、すべての画像にEXRの画質のレベルが必要になるわけではありません（Base colorやHeightの詳細など）。

+++

+++シェーダー設定の調整
UltraでのSpecular品質により、より正確な結果が得られますが、この設定にはコストがかかります。 シェーダーで一度に有効にしたエフェクトが多いほど、演算は重くなります。 可能な限り、複雑なマテリアルを別のシェーダーを持つ別のテクスチャセットに分割してください。 ディスプレイスメントが有効になっている場合は、テセレーションパラメーターに注意してください。

+++

+++ファイルオプションを調整
<b>ファイル/保存/保存してファイルを減らす</b>を使用 <b>不要なデータをフラッシュし、<b>未使用のリソースを削除</b>して、プロジェクト内で使用されていないファイルをプロジェクトにインポートして削除します。</b>

+++
