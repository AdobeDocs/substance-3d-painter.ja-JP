# バージョン2.6

**Substance Painter 2.6**&#x200B;では、新しいプロジェクトを作成したり、マテリアル名を更新してメッシュを再読み込みしたりする必要なく、Substance Painter内で直接テクスチャセットを管理することに重点を置いていました。 また、プロジェクトで使用されているリソースを更新する方法を提供したいと考えていました。これは、以前から多くの要求を受けていました。

リリース日： *2017年4月27日*

## 主な機能

### 新しいサンプルプロジェクト「Meet Mat」

![](../../assets/meetmat-render.jpg)

この新しいサンプルプロジェクトでは、「**マット**」という名前の新しい輝いてかわいらしいキャラクターが使用されています。 3つのテクスチャセットをペイントする準備が整っています。\
**Meet Mat**&#x200B;コンテストに参加して、素敵な賞をいくつか獲得しましょう。<https://www.allegorithmic.com/contest/meet-mat-2017-substance-3d-painting-contest>

### プロジェクトのリソースを更新する機能を備えた新しいスクリプトAPI

![](../../assets/resources-updater-ui.jpg)

Substance PainterのスクリプトAPIが改善され、プロジェクト内の&#x200B;**リソース**&#x200B;を他のバージョンで置き換えることができる新しい関数が追加されました。 この新機能を説明するために、スクリプトAPIを使用して作成された新しい&#x200B;**プラグイン**&#x200B;が追加され、特定のプロジェクトに含まれるすべてのリソースを参照できるようになりました。 赤とマークされたリソースは、「古い」ものとして検出され、自動的に置き換えることができます。 この機能は「古い」リソースに限定されるものではありません。アセットを他のアセットに置き換えることができます。 これは多くの新しい可能性を提供し、Substance Painterが&#x200B;**非破壊的なペイントツール**&#x200B;である方法をさらに示しています。

**プラグイン**&#x200B;はGitHubで利用可能です。改善の可能性がある場合は、お気軽にお問い合わせください。<https://github.com/AllegorithmicSAS/painter-plugin-resources-updater>

![](../../assets/resource-update-demo.gif)

### テクスチャセットの名前を変更して再割り当てする新しい機能

![](../../assets/texture-set-rename-description.png)

Substance Painter内でテクスチャセットの名前を直接変更できるようになりました。 テクスチャセットの名前を変更すると、ディスクに書き出されるテクスチャの名前に影響します（使用されている書き出しプリセットによって異なります）。\
テクスチャセットの名前を変更するには、名前をダブルクリックするか、右クリックしてコンテキストメニューを開きます。 また、テクスチャセットの機能の詳細を説明するカスタムの説明を追加することもできます。 これは、[UDIMプロジェクト](https://helpx.adobe.com/substance-3d/unlisted/documentation/spdoc/uv-tile-udim-legacy-144310352.html)で作業する場合に非常に便利です。 [**設定**]ボタンを使用して、一覧に説明を表示する方法を構成します。

![](../../assets/reasign-texture-set.png)

テクスチャセットを別のメッシュマテリアルに再割り当てできるようになりました。 つまり、以前に無効にしたテクスチャセットを&#x200B;**復元**&#x200B;したり（メッシュに見つからなかったため）、さらに&#x200B;**スワップ**&#x200B;したりできます。 テクスチャセットリストウィンドウの新しい「**設定**」ボタンをクリックし、「**テクスチャセットの再割り当て**」エントリをクリックします。 これにより、テクスチャセットの管理と、メッシュマテリアルへのリンク方法に特化した新しいウィンドウが開きます。 テクスチャセット名を&#x200B;**ドラッグアンドドロップ**&#x200B;して、必要な場所に移動できます。

## リリースノート

### 2.6.2

（2017年10月20日リリース）

**追加：**

* [テクスチャセット]無効なテクスチャセットを削除できます
* [シェルフ]複数のユーザーが同じシェルフフォルダーに書き込めるようにします
* [スクリプティング]プラグインフォルダーを再読み込みできる
* [スクリプト]互換性を確保するために、必要な最小限のAPIバージョンをプラグインメタデータに追加します
* [IRay]イメージの書き出しダイアログの改善

**修正済み：**

* [エンジン]解像度を変更すると、ストロークが消える問題(4K>2K)
* [ベイカー] [名前で一致]が有効な場合、IDマップのベイク処理に失敗する
* [ベイカー]エラーメッセージが明確ではありません
* [3Dビュー]接線空間はベイカーと同期されません
* [ツール]指先ツールを使用すると黒い斑点が表示される
* [シェーダ]非PBRシェーダが機能しない
* [シェーダ] 「pbr-coated」が壊れています
* [シェーダ] 「pbr-coated」シェーダのコーティングの粗さには影響がありません
* [シェーダ] Spec glossシェーダがIrayとSDと一致しません
* [シェルフ]同じ名前で拡張子の異なる2つのファイルを読み込むとクラッシュする
* [シェルフ] シェルフでプリセットを編集できなくなりました
* [シェルフ] シェルフに読み込まれたアセットのカスタムプレビューを設定できない
* キャッシュから読み込まれたリソースは使用を失います
* テンプレートを作成する前にプロジェクトを保存すると、書き込み権限エラーが返される
* ファイル名に2つのピリオドが含まれていると、プロジェクトが正しく保存されない。
* 複数のドット(.)を含むファイルの読み込み ファイル名に問題がある

### 2.6.1

（2017年5月12日リリース）

**追加：**

* [TextureSet] マテリアルをNothingに再割り当てできません

**修正済み：**

* ベイク済みマップの交換後にTextureSetを切り替えるとクラッシュが発生する
* レイヤーの描画モードを変更した後、「取り消しとやり直し」を行うとクラッシュが発生する
* 大きなID マップで「カラー選択」エフェクトを使用するとクラッシュまたはフリーズする
* [エクスポート]名前を変更したテクスチャセットが、エクスポートウィンドウでアルファベット順に並べ替えられない
* [TextureSet]デフォルト名にリセットしても、一貫性がチェックされない
* [TextureSet]プロジェクトを再度開くと、名前を変更したテクスチャセットーが無効になる
* [シェルフ]デフォルトテンプレートコンテンツがありません
* [シェルフ]非正方形テクスチャは正方形として表示されます
* [シェーダー] テクスチャセットが無効になると、関連するシェーダーが破棄されます
* [スクリプティング] alg.ベイク.setTextureSetBakingParameters()が機能しない
* [スクリプティング] websocketチュートリアルでの誤字
* [スクリプティング] AlgWidgetsの様々な問題
* [ログ]使用可能な仮想メモリが正しく検出されない場合がある

### 2.6.0

（2017年4月27日リリース）

**追加済み** :

* 新しいサンプルプロジェクト「Meet Mat」を追加
* [プラグイン]新しい「Resources Updater」プラグイン
* [TextureSet] テクスチャセットに名前を変更して説明を追加できます
* [TextureSet] マテリアルの再割り当てを許可する
* [TextureSet] テクスチャセットリストウィンドウに設定ボタンを追加します
* [TextureSet]リストの一番下に「無効」テクスチャセットを表示します
* [Substance]現在のテクスチャセットの解像度で追加のマップを使用して、パフォーマンスを向上させます
* [スクリプト]プロジェクトで使用するリソース（マテリアル、ジェネレータなど）を更新できるようにします
* [スクリプティング] シェルフの追加/削除方法を追加する
* [スクリプト]プロジェクト内のリソースからの情報のクエリを許可する
* [スクリプト]利用可能なシェルフのリストを取得できるようにします
* [スクリプティング] AlgWidgetのサムネールチュートリアルの改善
* [書き出し]ファイルフォーマットのサポートに基づいて、ビット深度を無効/有効にします
* [ログ]コンソールに印刷するプラグイン名を追加する
* [ログ]非表示のテクスチャセットに関するエラーを削除します
* サンプルの新しいアイコンとテキストで「ようこそ画面」を更新

**修正済み** :

* 特定のプロジェクトでメッシュを更新するとクラッシュする
* [ビューポート]対称面の内側の色が表示されない
* [ビューポート]ソロビューを使用すると、一部の後処理エフェクトが有効になる
* [シェーダ] &quot;over\_premult&quot;ブレンドが正しく動作しない
* [シェーダ]デフォルトシェーダーを使用したアルファテストに関する警告
* [シェルフ] Substanceからのタグの解析が正しくありません
* [シェルフ] MatFX 錆の風化が正しく機能しない
* [Shelf] HSLフィルターは初期設定で、不適切なチャンネルで有効になっています
* [シェルフ] Height/通常チャンネルでは、デフォルトでシャープが有効になっています
* [書き出し] Vray書き出しプリセットでOpenGL法線マップが使用されない
* [ツール]コピー/指先ツールで斑点を作成すると、精度が上がらない問題が発生する
