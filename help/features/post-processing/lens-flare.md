# レンズフレア

![](../../assets/v12_post_flare.jpg)

明るい光源がカメラレンズの要素と相互作用して、ハロー、縞、およびゴースト反射が生じるときに生じる光アーティファクトをシミュレートします。

| <b>パラメーター</b> | <b>説明</b> |
| --- | --- |
| <b>解決策</b> | レンズフレアエフェクトの内部レンダリング解像度を設定します。 値を大きくすると、線がよりシャープになりますが、パフォーマンスに影響を与える可能性があります。 |
| <b>カメラ</b> | フレアのシミュレーションに使用するカメラモデルを選択します。 指定可能な値は次のとおりです。<ul data-preserve-html="true"> <li data-preserve-html="true"><b>パノラマレンズ</b> （短い焦点距離） </li> <li data-preserve-html="true"><b>望遠レンズ</b> （長焦点距離）。</li> </ul> |
| <b>金額</b> | フレアエフェクトの全体的な強度を制御します。 値は1.0を超えて強度を上げることができます。 |
| <b>しきい値</b> | フレアの生成に必要な画像の最小輝度を指定します。 値を小さくすると、フレアを生成する領域が多くなり、値を大きくすると効果が非常に明るい光源に限定されます。 |
| <b>絞りスケール</b> | フレアの計算に使用する絞りの形状のサイズをスケールします。フレア要素全体のサイズに影響します。 |
| <b>コートの厚み</b> | レンズ要素上の反射防止コーティングをシミュレートします。 コーティングのThicknessは光の散乱に影響し、フレアのカラーも変化します。 |
| <b>コートIOR</b> | レンズの屈折率をシミュレートします。つまり、光がThicknessを通過する様子を表現します。 値が小さいほど、ゴーストがより濃くなります。 |
| <b>オクルージョンスケール</b> | 影響を受ける中央領域のサイズを設定します。 |
| <b>Smoothness</b> | レンズフレアのフェードの度合いをコントロールします。 値が大きいほど、変化が緩やかになります。 |
| <b>ユニークなゴースト</b> | フレアシェイプの変化の度合いを定義します。 値を大きくすると、パフォーマンスに大きな影響を与える可能性があります。 |
| <b>ゴースト位置スケール</b> | フレアゴーストの広がりとサイズを制御します。 |
| <b>絞りテクスチャ</b> | フレアパターンの生成に使用するレンズ絞りの形状を定義します。 テクスチャは、回折とゴーストのシェイプを制御します。 |
