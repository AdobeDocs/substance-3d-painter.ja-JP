# デフォルト出力テンプレート

以下は、デフォルトで提供される追加の出力テンプレートのリストです。  既定の出力テンプレートは、<b>書き出しウィンドウ</b>の<b>[出力テンプレート]タブ</b>でコピーおよび変更できます。

>[!NOTE]
>
> ここに記載されていない他のソフトウェアもサポートされている場合があります（**Octane**&#x200B;など）。 詳細については、[エコシステムとプラグイン](https://experienceleague.adobe.com/en/docs/substance-3d/ecosystem/home)を参照してください。

| *プリセット* | *説明* |
| --- | --- |
| <b> Amazon操業所</b> | Amazon Lumberyardで読み込んで使用する名前とパックテクスチャ。 |
| <b>アーノルド(AiStandard) </b> | Arnoldのプリセット（AiStandardシェーダ）。 |
| <b> Arnold UDIMレガシー(AiStandard)</b> | Arnold UDIM Legacy(AiStandard)のプリセット。 |
| <b>ブレンダー(Principled BSDF)</b> | ブレンダー(Principled BSDF)用のプリセット。 |
| <b>コロナ</b> | コロナレンダラーのプリセット。 |
| <b> CryEngine 3 </b> | Cry Engine 3で読み込んで使用する名前とパックテクスチャ。 |
| <b>土田2 </b> | ゲームDota 2のプリセット（関連するテンプレートで使用可能）。 |
| <b>キーショット</b> | キーショットレンダラーのプリセット。 |
| <b>キーショット9+</b> | バージョン9以降のキーショットレンダラーのプリセット。 |
| <b>レンズスタジオ</b> | Lens Studioのプリセット（Snapchat用のアセットを作成） |
| <b>マックスウェル（メタリックの粗さ）</b> | メタリックの粗さワークフローを使用したMaxwellレンダラーのプリセット。 |
| <b>Maxwell （Specular光沢度）</b> | Specular光沢ワークフローを使用したMaxwellレンダラーのプリセット。 |
| <b>メッシュマップ</b> | テクスチャセットのベイク処理されたメッシュマップスロットを個別に書き出します（テクスチャセットと同じ解像度で書き出します）。 |
| <b>非PBR Specular光沢度</b> | 非PBR Specular光沢ワークフローのテクスチャに名前を付けて書き出します。 |
| <b> PBRメタリックの粗さ</b> | 通常のメタリック/ラフネスPBRワークフローに必要な名前と書き出しテクスチャ。 |
| <b> PBRメタリックの粗さ（フォルダーグループまたはPSDグループ） </b> | PBR MetalRoughに似ていますが、追加のフォルダーを作成します。 このプリセットは、PSDファイルフォーマットでの使用に最も適しています。 |
| <b> PBR Specular光沢度</b> | 通常のSpecular/光沢PBRワークフローに必要なテクスチャの名前を付けて書き出します。 （テクスチャはBaseColor/Metallicワークフローから変換されます）。 |
| <b> PBR Specular光沢(メタリックの粗さから変換</b> | ベースカラー、メタリック、ラフネスの各チャンネルを変換して、Specular/光沢ワークフローと互換性を持たせます。 |
| <b> Redshift </b> | Redshiftレンダラーのプリセット。 |
| <b>Renderman (pxrDisney)</b> | メタリックマップとループマップを使用したRenderman用のプリセット。 |
| <b>Renderman (pxrSurface)</b> | 拡散反射光マップとSpecularマップを使用したRenderman用のプリセット。 |
| <b>Roblox (MaterialVariant)</b> | アルファをサポートしていないアルベドを使用したRobloxのプリセット。 |
| <b>Roblox (SurfaceAppearance)</b> | アルファチャンネル付きのカラーマップを使用したRoblox用のプリセット。 |
| <b>シェード3D </b> | Shade 3Dのプリセット。 |
| <b>Spark AR Studio</b> | Spark AR Studioのプリセット。 |
| <b>Unity HDレンダーパイプライン（メタリック標準）</b> | メタリックと光沢マップを使用したUnityのHDレンダリングパイプライン用のプリセット。 |
| <b>Unity HDレンダリングパイプライン(Specular)</b> | 追加されたSpecularマップを使用したUnityのHDレンダリングパイプラインのプリセット。 |
| <b>Unityユニバーサルレンダリングパイプライン（メタリック標準）</b> | メタリックとSmoothnessマップを使用したUnityのユニバーサルレンダリングパイプライン用のプリセット。 |
| <b>Unityユニバーサルレンダリングパイプライン(Specular)</b> | SpecularマップとSmoothnessマップを備えたUnityのユニバーサルレンダリングパイプライン用のプリセット。 |
| <b>アンリアルエンジン（パック済み） </b> | メモリ使用量を最小限に抑えたアンリアルエンジンで使用する名前とパックのテクスチャ。 |
| <b>アンリアルエンジンSSS （パック）</b> | Unreal Engineで使用する名前とパックのテクスチャです。メモリのフットプリントは最小限に抑えられ、不透明度マップはサブサーフェススキャタリングに置き換えられます。 |
| <b>次のVray （メタリックの粗さ）</b> | PBRワークフローを使用したVrayレンダラーのプリセット。 |
| <b>次のVray （Specular光沢度）</b> | 非PBRワークフローを使用したVrayレンダラーのプリセット。 |
| <b> Vray UDIMレガシー（メタリックの粗さ）</b> | Vrayレンダラーのプリセット（UDIM命名規則）。 |
