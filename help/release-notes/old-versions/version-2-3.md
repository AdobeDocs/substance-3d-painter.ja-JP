# バージョン2.3

**Substance Painter 2.3**&#x200B;では、最初の公式プラグイン（完全なレイヤースタックを利用可能なPhotoshopの書き出し）をリリースするために、スクリプトAPIが改善されています。

リリース日： *15 September 2016*

## 主な機能

### 新しいPhotoshop書き出しプラグイン

![](../../assets/ps-230.jpg)

このリリースでは、**Photoshopの高度なエクスポーター**&#x200B;を実装するために、スクリプティングAPIに新しい可能性を加えることに焦点を当てました。 この新しい書き出しにアクセスするには、メインツールバーにある「Photoshop」アイコンをクリックします（プラグインがアクティブになっている場合。デフォルトではアクティブになっています）。 プラグインを使用すると、テクスチャセットで使用可能な完全なレイヤースタックを書き出して、PSDファイル内に同様の構造を作成できます。 この機能&#x200B;**は、PSDファイルを作成するために、Photoshopがコンピューターにインストールされている**&#x200B;必要があります。

プラグインメニューの「設定」ボタンから、いくつかのオプションを使用できます。

![](../../assets/configure-ps.png)

最新のチュートリアルでは、新しいプラグインを使用した書き出しプロセスについて説明します。

## リリースノート

### 2.3.1

（2016年10月7日リリース）

**追加：**

* [Plugin][Photoshop]書き出すマテリアル/スタック/チャンネルを指定できます
* [スクリプト]関数名に不整合がある

**修正済み：**

* [書き出し] Alphaは、カスタム書き出しプリセットで破棄できます
* [書き出し] sRGBチャンネルでAlphaのガンマ変換が正しく行われない
* [書き出し]非正方形のドキュメントは四角形で書き出されます
* [書き出し]追加のマップが見つからない場合、追加のマップを書き出すことができない
* [Iray]一部のパラメーター（emissiveの適用度など）は影響しません
* [NVIDIA] NVIDIA Quadro K2200/GTX 750/760を使用した起動時のクラッシュ
* [AMD]サムネールとプレビューのカラーセットが正しくない
* [AMD]新しいファイルを開くとフリーズし、ドライバが失敗する
* [ログ]ログファイルに「software-version」がありません

### 2.3.0

（2016年9月15日リリース）

**追加：**

* [プラグイン]新しい「Photoshopに書き出し」プラグイン（書き出し完了レイヤースタック）
* [書き出し]パディングの幅をピクセル単位または無限単位で指定できます
* [書き出し] UVの外側の背景のタイプを設定できます
* [シェルフ] 10個のマテリアルをブレンドする新しいマテリアルレイヤシェーダー
* [シェルフ]Height/法線チャンネルでディテールを確認する新しいクレイシェーダー
* [シェルフ]環境入力を備えた新しいベイク照明フィルタ
* [シェルフ]非正方形の変形を追加するマスクジェネレーターが更新されました
* [ビューポート]合成法線マップ（通常+Height+烘焙）をソロモードに追加
* [スクリプト]追加のマップをエクスポートできます
* [スクリプト]使用可能なクエリーを許可テクスチャセットごとの追加のマップ
* [スクリプト]チャネル形式の取得を許可する
* [スクリプティング] ベイク処理ドキュメントに例を追加する
* [スクリプト]レイヤーの表示/非表示を照会できます
* [スクリプト]レイヤーの描画モードと不透明度を照会できます
* [スクリプティング]変換されたマップ（最終的な法線マップ、混合AOなど）を書き出すことができます。
* [Substance]カスタム使用状況の読み取りと接続
* [ショートカット]ソロモードを逆方向に切り替えるには修飾キー(Shift)を押します
* [書き出し]アルファを無効にするデフォルトの書き出しプリセットの更新
* [UI] エンジンが使用可能な場合にのみサムネールが計算されるようになりました
* [UI]サムネールの計算中にメンションを表示する

**修正済み：**

* 一部の古いプロジェクトを開くとクラッシュが発生する
* テクスチャチャンネルキャッシュが破損しているクラッシュ
* マテリアルレイヤーワークフローで4つ以上のマテリアルをブレンドするとクラッシュが発生する
* [UI]ツールバーが非表示の場合にツールショートカットが機能しない
* [UI] Irayツールバーがビューメニューで「名称未設定」と表示されている
* [UI]プラグインツールバーが表示メニューで「Untlanked」と表示される
* [ベイカー] 烘焙設定の編集中にEnterキーを押すと、ベイクプロセスが開始されます
* [ベイカー]一部のパラメーターの範囲が正しくありません
* [読み込み]非常に大きな数字のため、OBJ メッシュを読み込むことができません
* [読み込み]読み込まれるOBJファイルのサブオブジェクトが多すぎます
* [書き出し]書き出し時にチャンネル背景がデフォルトカラーではなく黒で塗りつぶされる
* [ツール]視野が低すぎると、パーティクルが正しく動作しません
* [ツール]サブスタックのマスクでブラシプレビューの色が正しくない
* [ビューポート] 2D ビューの空白部分にブラシが入ると巨大になる
* [ビューポート]標準テクスチャでペイントすると、ブラシが表示されない
* [スクリプト]誤ったドキュメント: 「ambientocclusion」ではなく「ao」が表示される
* [スクリプティング] Painterを閉じると、subprocess()で開始したプロセスが終了する
* [シェルフ]ベイクされた照明フィルタが誤ったAO入力を使用しています
* [MacOS]削除された消火栓プロジェクト（非互換）
* \*.sppファイルを読み込むときに（\*.sppファイルではなく）既定のプロジェクトが開く
