# UV チェッカー

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_uv_checker.png" alt=""/><br><strong>イン：</strong> UV、境界、ランダム</td>
    <td style="border: 0;" valign="top"><strong>説明</strong><br>UVチェッカージェネレータは、モデルにグリッドのようなチェッカーパターンを適用するので、伸縮、スケールの不均等、ゆがみなどのUVの問題を簡単に見つけることができます。 <br><br>UVチェッカージェネレータは、通常、UVのゆがみを確認するために塗りつぶしレイヤー上で直接使用されます。</td>
  </tr>
</table>

## パラメーター

<table>
  <tr>
    <th>パラメーター名</th>
    <th>説明</th>
  </tr>
  <tr>
    <td><strong>シード</strong></td>
    <td>テクスチャの作成に使用するシード値を設定します。 <br><ul><li>別のランダムシードに切り替えるには、「ランダム」をクリックします。</li><li>鉛筆をクリックして現在のシード値を表示し、必要に応じて特定の値を入力します。</li></ul></td>
  </tr>
  <tr>
    <td><strong>チェッカーカラーモード</strong></td>
    <td>カラーの割り当て方法を選択します。<br><ul><li><strong>均一</strong>:テクスチャセット全体に同じ色を適用します。</li><li><strong>ランダム</strong>：各UV アイランドにランダムな色を適用します。</li></ul></td>
  </tr>
  <tr>
    <td><strong>チェッカーカラー</strong></td>
    <td>チェックパターンの色を設定します。</td>
  </tr>
  <tr>
    <td><strong>チェッカーグリッドタイル</strong></td>
    <td>チェッカーパターンのサイズを調整します。</td>
  </tr>
  <tr>
    <td><strong>チェッカーグリッドの不透明度</strong></td>
    <td>グリッドの不透明度を調整します。 不透明度を0に設定すると、グリッドのないチェッカーテクスチャのみが表示されます。</td>
  </tr>
  <tr>
    <td><strong>UVの罫線の色</strong></td>
    <td>UVの罫線の色を設定します。</td>
  </tr>
  <tr>
    <td><strong>UV罫線の幅</strong></td>
    <td>UVの枠線の幅を調整します。</td>
  </tr>
</table>
