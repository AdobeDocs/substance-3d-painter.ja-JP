## 説明

カラー補正フィルターでは、ハイライト、中間調、シャドウを補正します。

塗りつぶしレイヤーで使用して、コントラスト、輝度、彩度を微調整します。

## パラメーター

### シャドウ

| パラメーター名 | 説明 |
| --- | --- |
| **コントラスト：** | シャドウのコントラストを調整します。 |
| **輝度：** | シャドウの明るさを調整します。 |
| **彩度：** | シャドウの彩度を調整します。 |

### 中間調

| パラメーター名 | 説明 |
| --- | --- |
| **コントラスト：** | 中間調のコントラストを調整します。 |
| **輝度：** | 中間調の明るさを調整します。 |
| **彩度：** | 中間調の彩度を調整します。 |

### ハイライト

| パラメーター名 | 説明 |
| --- | --- |
| **コントラスト：** | ハイライトのコントラストを調整します。 |
| **輝度：** | ハイライトの明るさを調整します。 |
| **彩度：** | ハイライトの彩度を調整します。 |
