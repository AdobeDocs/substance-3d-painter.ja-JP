# 定義済みの出力テンプレート

定義済みの出力テンプレートはSubstance 3D Painter自体によって生成されるため、編集することはできません。 定義済みの出力テンプレートは、<b>書き出しウィンドウ</b>の<b>設定タブ</b>の<b>出力テンプレートドロップダウンリスト</b>の上部に表示されます。

編集可能ではないプリセットのリストを次に示します。

* 2D ビュー
* ドキュメントチャンネル+通常+ AO（Alphaなし）
* ドキュメントチャンネル+通常+ AO（Alphaあり）
* Sketchfab
* Substance 3D Stager
* [USDz (Apple AR)](usd-pbr-metal-roughness-preset.md)
* glTF PBRメタルの粗さ
* glTF PBRメタルの粗さ+ディスプレイスメントテクスチャ（試験的）
