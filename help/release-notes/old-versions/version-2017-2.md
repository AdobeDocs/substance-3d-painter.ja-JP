# バージョン2017.2

**Substance Painter 2017.2**&#x200B;は、アンカーポイントシステムを使用した新しい強力な機能を導入します。 これにより、レイヤースタックでより高度な設定を作成できるようになり、多くの新しい可能性が開かれます。

リリース日： *27 July 2017*

## 主な機能

### 新規アンカーポイントエフェクト

![](../../assets/anchor-height-blend-optim.gif)

**新しい効果の種類**&#x200B;がSubstance Painterに追加されました。既存の種類（**フィルター**&#x200B;や&#x200B;**レベル**&#x200B;など）の横に、新しい&#x200B;**アンカーポイント**&#x200B;が表示されます。 この新しい効果を使用すると、**レイヤースタック**&#x200B;内の&#x200B;**場所**&#x200B;を定義して、他のレイヤーのプロジェクトの残りの部分で&#x200B;**参照**&#x200B;できます。 これにより、例えば、レイヤーのHeight情報をこのレイヤーのすぐ上にあるレイヤーのマスクに使用して、より自然なブレンドを実現できます（上のgifで示されています）。

アンカーは効果として機能するため、では&#x200B;**多くの状況**&#x200B;で作成できます。レイヤーの&#x200B;**コンテンツ**、**マスク**、さらには&#x200B;**パススルー**&#x200B;フィルターとして作成することもできます。 このエフェクトは、そのレイヤーが無効になっている場合でも機能します。 アンカーは位置を定義するだけで、その位置から取得できるものは定義しないことに注意してください。 この情報は、アンカーへの参照が作成される場所に定義されます。

技術的な詳細と例については、専用ページを参照してください： [アンカーポイント](../../features/effects/anchor-point.md)

### 様々な新機能の改善

新しいアンカーポイントエフェクトとともに、次の操作も行いました。

* 塗りつぶしやペイントなどの一部のエフェクトの名前を変更する機能
* 新しいスクリプト機能（Unityなどの他のアプリケーションとのライブリンクを作成できます）

## リリースノート

### 2017.2

（2017年7月27日リリース）

**追加：**

* [効果]レイヤーとマスクを参照できる新しいアンカーポイント
* [レイヤー]塗りつぶしエフェクトとペイントエフェクトの名前を変更する機能
* [Plugin]更新されたSubstance Sourceプラグイン
* [スクリプティング]テクスチャセットの解像度のクエリを許可
* [スクリプティング]ペイントエンジンのステータスを取得できます
* [パフォーマンス]プロジェクトの読み込みとブラシスタンプの最適化を改善

**修正済み：**

* [ツール]マテリアルパラメーターを微調整する際のパフォーマンスの問題
* [エンジン]解像度を変更すると、ブラシストロークが消える(4K>2K)
* [3Dビュー]接線空間はベイカーと同期されません
* [シェルフ]ユーザードキュメントのシェルフパスが自動的に作成されない
* [シェルフ]更新後にプリセットを以前のバージョンと互換性を持たせる
* [シェーダ]非PBRシェーダが機能しない
* [ベイカー] [名前で一致]が有効な場合、IDマップのベイク処理に失敗する
* [サンプル] Meet Matサンプルプロジェクトのテクスチャセット名が正しくない
* テンプレートを作成する前にプロジェクトを保存すると、書き込み権限エラーが返される
