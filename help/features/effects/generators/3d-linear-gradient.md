# 3D Linear gradient

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_3d_linear_gradient.webp" alt=""/><br><strong>イン：</strong>グラデーション、グレースケール</td>
    <td style="border: 0;" valign="top"><strong>説明</strong><br>3D Linear gradientジェネレータは、位置マップを使用して、メッシュ上の2点間にグラデーションを作成します。 <br><br>3D Linear gradientはモノクロ（白黒）テクスチャを出力します。 そのため、マスクを生成して特定の領域に線形グラデーションを配置すると便利です。<br><br>焼き付けられた位置マップは、画像入力として必要です。 <a href="../../../baking/baking.md">ベーキングの詳細については、こちらを参照してください</a>。<br><br>位置マップは、X、Y、およびZ軸に沿った0 ～ 1の位置に対応するメッシュ上の各点に色を割り当てます。 つまり、メッシュ上の各ポイントには固有のカラーがあります。 線形グラデーションの始点と終点を設定するには、始点と終点で位置マップカラーを選択します。</td>
  </tr>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| **位置** | ベイク処理された位置マップを使用します。 |

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| **反転** | 線形グラデーションを反転します。 |
| **残高** | 線形グラデーションの中間点の位置をシフトします。 |
| **コントラスト** | 線形グラデーションのコントラストを調整します。 |
| **3D位置の開始** | 位置マップのカラーに基づいてグラデーションの開始点を設定します。 開始点を簡単に定義するには、ビューポートの画面に位置マップを表示し、カラーピッカーを使用して開始点を選択します。 |
| **3D位置の終了** | 位置マップのカラーに基づいてグラデーションの終了点を設定します。 終点を簡単に定義するには、ビューポートに位置マップを画面に表示し、カラーピッカーを使用して終点を選択します。 |
