# 塗りつぶし領域のカラー

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![塗りつぶし領域の色アイコン](./Resources/icon_fill_area_color.png "塗りつぶし領域の色")

<b>イン：</b>効果/塗りつぶし、シェイプ、アウトライン、rgba、色

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

塗りつぶし領域カラーフィルターは、アウトラインを塗りつぶされたシェイプに変換します。 実線で囲まれた領域はすべて塗りつぶされます。 カラーバージョンでは、アルファを使用して領域の境界線が決定されます。

ペイントレイヤー（カラーチャンネル）上で使用され、閉じたペイントされたストロークを塗りつぶします。

</tr>

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>領域の検出：</b> | 塗りつぶす領域を識別する方法を選択します。 |
| <b>領域の検出のしきい値：</b> | 領域検出のしきい値を調整します。 |
| <b>デバッグ領域の検出：</b> | 「領域検出」設定で検出されたアウトラインの表示を切り替えます。 これにより、完全に閉じていない可能性のある領域を特定できます。 |
| <b>UV境界の動作：</b> | 領域の入力中にUV境界を処理する方法を選択します。 |
| <b>UV境界のしきい値：</b> | 領域検出プロセスによって塗りつぶされる可能性があるUV領域を無視するために使用する閾値を調整します。 |
| <b>カラーモード：</b> | 領域の内側を塗りつぶすために使用する方法を選択します。 |
| <b>塗りつぶしの色：</b> | 塗りのカラーを調整します。 |
| <b>ぼかしの強さ：</b> | ぼかしの強度を調整します。 |
| <b>ぼかしサンプル：</b> | ぼかしサンプル数を調整します。 |
| <b>反復:</b> | 実行する反復の数を調整します。 値を大きくすると結果は良くなりますが、遅くなります。 有効な値の範囲は[8, 48]です。 |
