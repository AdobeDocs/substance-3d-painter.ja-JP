# ヘルプメニュー

<table style="table-layout:auto">
  <tr style="border: 0;">
    <td style="border: 0;" valign="top">Substance 3D Painterについて詳しくは、ヘルプメニューのリンクとオプションを参照してください。 これには、チュートリアル、リリースノート、ドキュメントなど、ローカルインストールのPainterの問題を解決するのに役立つコンテンツが含まれます。ここでは、ログへのアクセスやバグの報告などが含まれます。</td>
    <td style="border: 0;" valign="top"><img src="../../assets/help-menu.png" alt=""/></td>
  </tr>
</table>

| アクション | 説明 |
| --- | --- |
| チュートリアル | アプリケーションに関連する公式の[チュートリアル](https://helpx.adobe.com/jp/substance-3d/unlisted/tutorials.html)へのリンク。 |
| リリースノート | [リリースノート](../../release-notes/all-changes.md)へのリンク。 |
| ドキュメント | このドキュメントへのリンク。 |
| ショートカットリスト | [ショートカット](../settings/shortcuts.md)のドキュメントへのリンクです。 |
| スクリプトのドキュメント | 各種スクリプトAPIのローカルドキュメントへのリンク。 |
| フォーラム | [アプリケーションフォーラム](https://community.adobe.com/t5/substance-3d-painter/bd-p/substance-3d-painter)へのリンク。 |
| 不具合を報告 | バグレポートウィンドウを開いて情報を送信します。 |
| ログを表示 | デフォルトのTXTファイルエディターで、現在のPainterセッションのログファイルを開きます。 |
| ログを書き出し | ログファイルを書き出して、サポートが必要な場合に問い合わせます。 |
| フィードバックを送信 | [機能リクエスト](https://feedback.substance3d.adobe.com/forums/261284-substance-3d-painter)プラットフォームへのリンク。 |
| アカウントを管理 | [account.adobe.com](http://account.adobe.com)を開いて、アカウントとサブスクリプションを管理します。 |
| ログアウト | 現在ログインしているAdobeアカウントからログアウトします。 |
| スタートアップスクリーン | [ようこそ画面](../../getting-started/getting-started.md)ウィンドウを開きます。 |
| 新機能 | 現在の更新の変更点について詳しくは、「新機能」画面を表示してください。 |
| ホーム画面 | ホーム画面を開きます。 |
| アップデートをチェック | [更新プログラムのチェック](../miscellaneous/update-checker.md)ウィンドウを開きます。 |
| Substance 3D Painterについて | 「バージョン情報」ウィンドウを開きます。このウィンドウには、アプリケーションのバージョン、法律上の注意、その他の詳細情報が表示されます。 |
| パートナー | Painterに統合されているパートナーソフトウェアに関する情報にアクセスします。 |
