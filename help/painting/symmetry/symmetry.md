# 対称

![](../../assets/radial-demo.gif)

「対称」は、ブラシと塗りつぶしレイヤーで幾何拘束に基づいてコンテンツを簡単かつ正確に複製できる便利な設定です。

* ブラシレイヤーでは、シンメトリーを使用して、対称軸に基づいてメッシュの他の場所に個々のブラシストロークを複製します。
* 塗りつぶしレイヤーでは、対称を使用して、対称軸を中心に塗りつぶしレイヤー全体を複製します。

Painterで使用できるシンメトリーの種類について詳しく説明します。

* [ミラー対称](mirror-symmetry.md)
* [ラジアル対称](radial-symmetry.md)

## ペイントツールでのシンメトリーの使用

対称を有効にするには、コンテキストツールバーの<b>対称ボタン</b>を使用します。

![](../../assets/SymmetryToggle.png)

コンテキストツールバーの<b>対称設定ボタン</b>を使用して、対称オプションを調整します。

![](../../assets/BrushSymmetrySettings.png)

>[!NOTE]
>
> 2Dビューでのペイント投影とステンシル投影は対称をサポートしていません。 必要に応じて、代わりに3Dビューを使用することをお勧めします。

## 塗りつぶしレイヤーでのシンメトリの使用

塗りつぶしレイヤーを選択すると、ブラシツールのシンメトリーと同様に、コンテキストツールバーの<b>シンメーターボタン</b>を使用できます。 塗りつぶしレイヤーを使用して、<b>プロパティパネル</b>から対称オプションを有効にして、アクセスすることもできます。 対称は、次の投影方法でのみ使用できます。

<table>
<tr style="border: 0;">
<td style="border: 0;" valign="top">

* 三面投影
* 平面投影
* 球投影
* 円筒投影法
* ワープ投影

適切な投影方法を選択したら、プロパティパネルの「シンメトリ」セクションで「シンメトリを有効にする」を選択して、シンメトリのオプションにアクセスします。

サポートされていないプロジェクションメソッドが選択された場合、<b>[シンメトリを有効にする]</b>オプションは使用できなくなり、コンテキストツールバーの<b>[シンメトリ]ボタン</b>は灰色表示されます。

</td>
<td style="border: 0;" valign="top">

![プロパティパネルの[対称]セクションのスクリーンショット](../../assets/FillSymmetry.png){width="400px"}

</td>
</tr>
</table>

>[!NOTE]
>
> 対称表示オプションは、コンテキストツールバーの<b>対称設定ボタン</b>からのみ使用できます。 <b>プロパティパネル</b>から対称表示設定を変更することはできません。
