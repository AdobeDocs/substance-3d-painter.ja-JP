# 保存検索

保存された検索は、パスによるフィルターとともに、アセットウィンドウ内で開くことができる新しいセクションです。 これにより、最も頻繁に実行する検索やクエリを保存し、いつでも簡単にアクセスしたり、個別にドッキングできる新しいサブライブラリタブとして開いたりすることができます。

![](../../assets/02-01-savedsearches.jpg)

保存された検索を作成するには、様々な種類のナビゲーションを組み合わせることができます。検索フィールドに手書きのクエリを入力し、目的のアセットタイプ（または複数のアセットタイプ）と場所を選択します。パスによるフィルターまたはパンくずを使用します。 これらすべてを1つの保存済みサーチとして保存することも、個別の保存済みサーチに分割することもできます。 例えば、頻繁に使用するダイナミックストロークのブラシのサーチを保存することができます。

>[!NOTE]
>
> 保存したサーチは、手動で編集できる設定ファイルに保存されます。 詳細については、[保存された検索を手動で追加する](../../pipeline-and-integration/resource-management/adding-saved-searches-manually.md)を参照してください。

保存した検索を作成すると、検索一覧に表示されます。 サブライブラリを右クリックして、新しいサブライブラリタブを作成したり、名前を変更したり、削除することができます。

![](../../assets/02-02-savesearch.gif)

検索フィールドの検索タグにカーソルを合わせて、検索コンテンツに関する情報を表示することもできます。

![](../../assets/02-03-searchinfo.jpg)
