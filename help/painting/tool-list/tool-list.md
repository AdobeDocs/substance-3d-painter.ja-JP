# ツールリスト

このページでは、使用可能なすべてのペイントツールとその使用方法について説明します。

| *ツール* | *説明* |
| --- | --- |
| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r1-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-paint.png" width="100px"/></div> | [ペイントツール](paint-brush.md)を使用すると、特定のマテリアルのブラシストロークをメッシュ上に適用できます。 |
| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r2-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-eraser.png" width="100px"/></div> | [消しゴム](eraser.md)を使用すると、既存のペイント情報を削除できます。 |
|  | [パスツール](path.md)を使用すると、モデルのサーフェスに沿って曲線を定義し、いくつかの異なる効果を作成できます。 ブラシストロークを追加したり、ペイントやぼかしを消したり、ジッパーや亀裂など、パスに沿ってすべてのディテールを追加したりできます。 |
| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r3-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-projection.png" width="100px"/></div> | [投影](projection.md)を使用すると、現在の視点に合わせて調整されたマテリアルまたはテクスチャを適用できます。 |
| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r4-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-polygonfill.png" width="100px"/></div> | [多角形の塗りつぶし](polygon-fill.md)を使用すると、3Dメッシュの多角形を選択し、ジオメトリに基づいてマスクを作成できます。 |
| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r5-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-smudge.png" width="100px"/></div> | [指先ツール](smudge-tool.md)を使用すると、カラーやその他のマテリアルプロパティを伸縮、混合、ぼかすことができます。 |
| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r6-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-clone.png" width="100px"/></div> | [コピーツール](clone-tool.md)を使用すると、3Dメッシュ上の既存のマテリアルの任意の部分を複製したり、パッチを適用したりできます。 |
| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r7-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-materialpicker.png" width="100px"/></div> | マテリアルピッカーを使用すると、3Dメッシュのサーフェスからプロジェクトのマテリアルプロパティをコピーできます。  これは一時的なツールです。カラーを選択すると、前のツールが使用できるようになります。 |
|  | [クイックマスク](quick-mask.md)を使用すると、ペイントを適用する場所をより詳細に制御できる一時的なマスクを作成できます。 |
