# レイヤーの管理

レイヤースタックでは、次の操作が可能です。

| *アクション* | *デモ* |
| --- | --- |
| クリック&amp;ドラッグでレイヤーを移動します。 レイヤーを移動すると、レイヤーが配置される場所を示すバーが表示されることがあります。<ul data-preserve-html="true"><li data-preserve-html="true"><strong>レイヤーの上のバー</strong> :レイヤーはレイヤーの上に配置されます</li><li data-preserve-html="true"><strong>2つのレイヤー間のバー</strong> :レイヤーは2つのレイヤーの間に配置されます</li><li data-preserve-html="true"><strong>レイヤーの下のバー</strong> :レイヤーはレイヤーの下に配置されます</li></ul> | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r1-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/dragdrop-above.gif"/></div> |
| **フォルダーに移動** ：レイヤーをクリックしてドロップし、フォルダーにカーソルを合わせて中に配置します | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r2-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/dragdrop-folder.gif"/></div> |
| **複数選択** ：次の2つの異なる方法で実行できます。<ul data-preserve-html="true"><li data-preserve-html="true">[Ctrl]または[Command]キーを押したままにします</li><li data-preserve-html="true">Shiftキーを押しながら、最初と最後のレイヤーをクリック</li></ul> | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r3-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/dragdrop-ctrlselect.gif"/></div><div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r3-column-c1_dynamic_grid1_items_grid-cell_position-par_image" src="../../assets/dragdrop-shiftselect.gif"/></div> |
| **レイヤーのグループ化** ：次のいずれかの操作を行うことで、現在選択されているレイヤーを使用してフォルダーを作成できます。<ul data-preserve-html="true"><li data-preserve-html="true">右クリックして「レイヤーをグループ化」を選択します</li><li data-preserve-html="true">Ctrl+GまたはCommand+Gを押す</li></ul> | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r4-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/group-layer.gif"/></div> |
