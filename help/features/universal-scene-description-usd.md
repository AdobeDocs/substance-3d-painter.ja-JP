# Universal Scene Description(USD)

![](../assets/banner-usd.jpg)

USDワークフローは、Painter 8.3で使用できます。 [USD](https://graphics.pixar.com/usd/release/intro.html)は、Pixarによって、多くの異なる種類のデータを伝送できる、共同作業に適した交換可能な形式として開発されました。

Painterでは、次のことが可能になりました。

* [プロジェクトを作成する](../getting-started/project-creation.md)。範囲とバリアントの選択、サブディビジョンレベル、アニメーションフレームなど、USD固有の機能を使用します。
* USDフォーマットを使用して[書き出し](../export/export-window/export-settings.md)マテリアルおよびテクスチャ。
* また、メッシュのみの書き出し用の新しいファイルフォーマットとして、USDが追加されました。
