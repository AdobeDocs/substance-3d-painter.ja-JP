# 自動保存

![](../../assets/autosave-details.png){width="500px"}

自動保存プラグインを使用すると、現在開いているプロジェクトの&#x200B;**バックアップを作成**&#x200B;できます。 これにより、現在のプロジェクトを変更せずに、横にファイルが作成されます。

バックアップファイルは、次の3つの場所に配置されます。

* 現在のプロジェクトが保存されている場合は、その横にバックアップが表示されます。
* プロジェクトが一度も保存（名称未設定）されていない場合、バックアップはユーザーのDocumentsフォルダーの自動保存フォルダーにあります。 ( **Documents/Allegorithmic/Substance 3D Painter/autosave** )
* 上書き設定が有効になっている場合、バックアップは設定で指定されたパスに配置されます。

*自動保存を遅延させる再通知ボタンがインターフェイスで使用できます。*

## 自動保存はどのようにトリガーされますか？

自動保存は、タイマーが自動保存プロセスを終了すると、内部タイマーに基づいて行われます。\
再通知ボタンは、タイマーの終了近くになると自動的に有効になり、自動保存を数時間遅らせることができます。

時間ベースの値はすべて、設定ウィンドウで変更できます。

## 自動保存を無効にする方法

何らかの理由で自動保存プロセスを無効にする必要がある場合は、プラグインメニューを使用して実行できます。 これを行うには、**プラグイン** > **自動保存** > **無効化**&#x200B;メニューをクリックします。

## 自動保存の設定

自動保存の動作を構成するには、**プラグイン** > **自動保存** > **構成**&#x200B;メニューをクリックします。

* **自動保存の間隔（分）** ：各自動保存の間隔を指定します。
* **自動保存ファイルの数** ：特定のプロジェクトで作成されたバックアップファイルの最大数です。
* **再通知の間隔（分）** ：再通知ボタンをクリックしたときに自動保存が遅延する時間。
* **保存前の警告時間（秒）** ：再通知ボタンがアクティブになり、自動保存トリガーが表示されるまでの進行状況バーが表示されるまでの時間。

>[!NOTE]
>
> 次の場合、自動保存タイマーは一時停止します。
> 
> * エンジンは計算をしている
> * テクスチャを書き出しています
> * 設定ウィンドウが開きます
> * プロジェクトは現在保存中です

ウィンドウの下部で、バックアップファイルのデフォルトの場所を上書きすることができます。\
設定「**常に次のディレクトリに保存** 」を有効にすると、指定されたフォルダーにすべてのバックアップファイルが保存されます（既定のパスはユーザーのドキュメントフォルダーです）。
