# ビューポートメニュー

![](../../assets/viewport-menu.png)

ビューポートメニューを使用して、[ビューポート](https://substance3d.adobe.com/)の表示モードを変更できます。

| アクション | 説明 |
| --- | --- |
| **ディスプレイマテリアル** | ビューポートを&#x200B;**マテリアル**&#x200B;モードに切り替えます。これにより、照明とシェーディングを備えた3Dモデルが表示されます。 |
| **次のチャンネルを表示** | ビューポートをソロモードに切り替えて、次のテクスチャセットチャンネルを表示します。 |
| **前のチャンネルを表示** | ビューポートをソロモードに切り替えて、前のテクスチャセットチャンネルを表示します。 |
| **次のメッシュマップを表示** | ビューポートをソロモードに切り替えて、次にベイク処理されたメッシュマップタイプを表示します。 |
| **前のメッシュマップを表示** | ビューポートをソロモードに切り替えて、以前のベイク処理されたメッシュマップタイプを表示します。 |
| **メッシュ全体を表示** | ビューポートカメラを調整して、3Dモデルの中央に配置します。 |
| **有効なクイックマスク** | 詳細については、[クイックマスク](../../painting/tool-list/quick-mask.md)のページを参照してください。 |
| **クイックマスクを編集** | 詳細については、[クイックマスク](../../painting/tool-list/quick-mask.md)のページを参照してください。 |
| **クイックマスクを反転** | 詳細については、[クイックマスク](../../painting/tool-list/quick-mask.md)のページを参照してください。 |

表示モードの詳細については、[表示設定](../display-settings/display-settings.md)を参照してください。

クイックマスクの詳細については、[専用ページ](../../painting/tool-list/quick-mask.md)を参照してください。
