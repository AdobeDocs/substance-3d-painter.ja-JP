# テクスチャセットの再割り当て

![](../../assets/txtset-reassignment-window.png)

Texture Set Reassignmentウィンドウを使用すると、シーンメッシュの別の部分へのレイヤスタックの割り当てを変更できます。 これは、新しいメッシュを既存のプロジェクトに読み込んだ後、一部のテクスチャセットが無効になった場合などに便利です。 これは、レイヤスタックが存在しないマテリアルに割り当てられたために発生します。 再割り当てウィンドウを使用すると、そのレイヤースタックを元に戻すことができます（下の「無効なテクスチャセットの復元」を参照）。

テクスチャセットの再割り当てウィンドウにアクセスするには、[テクスチャセットリスト](texture-set-list.md)ウィンドウで&#x200B;**設定/テクスチャセットの再割り当て**&#x200B;を選択します。

ウィンドウは3つのセクションに分かれています。

* **無効なテクスチャセット** ：現在未使用のすべてのテクスチャセットを一覧表示します。
* **プロジェクトテクスチャセット** :メッシュマテリアルに現在割り当てられているすべてのテクスチャセットを一覧表示します。
* **メッシュマテリアル** :プロジェクトのメッシュマテリアルを一覧表示します。

このウィンドウには、次のアクションを実行する追加のボタンもあります。

* **取り消し** ：ウィンドウを以前の状態に戻します
* **やり直し** ：取り消された変更を再適用します。
* **適用** ：ウィンドウを閉じて、再割り当てを実行します。
* **キャンセル** ：ウィンドウを閉じ、進行中の変更をすべて破棄します。

## テクスチャセットの再割り当て

![](../../assets/reassign-existing-sets.gif)

テクスチャセットの再割り当ては、ボタンをドラッグ&amp;ドロップするだけで実行できます。

## 無効にしたテクスチャセットを復元する

![](../../assets/reassign-disabled-sets.gif)

テクスチャセットは、メッシュマテリアルに関連付けられなくなった場合に無効にすることができます。\
これは、プロジェクトと新しいメッシュでマテリアル名が異なるプロジェクトに新しいメッシュを読み込む場合に発生する可能性があります。

テクスチャセットを復元するには、「**プロジェクトのテクスチャセット**」リスト内のテクスチャセットと&#x200B;**スワップ**&#x200B;します。

## 無効なテクスチャセットを削除する

![](../../assets/reassign-delete-sets.gif)

**無効なテクスチャセット**&#x200B;リストのテクスチャセットの横にある&#x200B;**クロス**&#x200B;をクリックすると、**削除対象としてマーク**&#x200B;されます。\
削除は、ウィンドウの下部にある「**適用**」ボタンをクリックしたときに実行されます。

>[!WARNING]
>
> 「適用」ボタンでウィンドウを閉じると、このアクションは取り消せません。
