</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

粗い仕上げフィルターはメタル仕上げのコレクションの一部で、粗いメタル効果を作成するために使用されます。

塗りつぶしレイヤーで使用されます。 基本塗りつぶしレイヤーの色、ラフネス、メタリック、およびその他のプロパティを調整し、最終的な表面処理に使用するフィルターを追加します。

</td>
</tr>
</table>

<a name="parameters"></a>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| <b>カスタム経年劣化:</b>グレースケール | カスタムテクスチャまたはアンカーポイントを使用します。 |
| <b>位置：</b>カラー | ベイク位置マップを使用します。 |
| <b>ワールド空間法線:</b>色 | ワールド空間法線マップを使用します。 |

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>シード：</b> | ランダム値を割り当てると、全体的な設定を変更することなく、異なるバリエーションを作成できます。 |
| <b>スケール：</b> | 仕上げの全体的なスケールを調整します。 |
| <b>スケール経年劣化:</b> | 経年劣化パターンの尺度を調整します。 |
| <b>ブラシの適用度：</b> | ブラシ効果の適用度を調整します。 |
| <b>ワープのブラシ処理：</b> | ブラシに適用するワープの量を調整します。 |
| <b>カスタムフレークを使用する：</b> | カスタムフレーク入力の使用を切り替えます。 |
| <b>三平面マッピング：</b> | 三平面マッピングを切り替えます。 |
| <b>カスタム経年劣化を使用する：</b> | カスタムテクスチャの使用を切り替えます。 |
