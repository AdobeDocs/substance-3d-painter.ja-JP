# プロジェクト設定

![](../assets/project-configuration-full.png)

「プロジェクト構成」ウィンドウには、プロジェクト設定を変更するためのコントロールがあります。 通常、プロジェクト設定は新規プロジェクトの作成時に設定されますが、これらの設定の変更はプロジェクトの後半で必要になる場合があります。

## 3D メッシュ

3Dメッシュまたはメッシュファイルに変更を加えた場合は、他のプロジェクトデータを維持しながら、メッシュを再読み込みできます。 **[メッシュの再読み込み]**&#x200B;をオンにし、正しいファイルが読み込まれていることを確認します。

メッシュの再読み込みは、次のような場合に便利です。

* 3Dモデルトポロジを更新する
* UVを更新する
* [テクスチャセット](texture-set/texture-set.md)を追加または削除

| **パラメーター** | **説明** |
| --- | --- |
| **3Dメッシュ** | 3Dモデルファイルへのパスを示します。 **選択ボタン**&#x200B;を使用して、プロジェクトのソースファイルを変更します。 |
| **メッシュの再読み込み** | 有効にすると、インターフェイスの下部で「OK」をクリックしたときにメッシュファイルが再読み込みされます。 元のメッシュファイルとは異なるメッシュファイルを指定するために選択ボタンを使用すると、このパラメータは自動的にチェックされます。 |

>[!NOTE]
>
> プロジェクトメッシュを再読み込みするときにマテリアルIDが変更されたり名前が変更されると、プロジェクト内の以前のテクスチャセットが無効になり、テクスチャが見つからないような外観になることがあります。 この問題は、[再割り当てウィンドウ](texture-set/texture-set-reassignment.md)で&#x200B;**テクスチャセットリスト**&#x200B;から修正できます。

## UVタイル設定

このセクションには、プロジェクトでのUDIMの使用を切り替えるコントロールがあります。 プロジェクトの作成後にこれらの設定を変更することはできませんが、ここでプロジェクトの設定を表示することができます。 詳細については、[UVタイルのドキュメント](../features/uv-tiles/uv-tiles.md)を参照してください。

## 読み込み設定

次の設定は、選択したメッシュのインポート方法を制御します。

| *設定* | *説明* |
| --- | --- |
| **カメラの読み込み** | 有効にすると、メッシュファイルに存在するカメラも読み込まれ、3Dビューポートで使用できるようになります。 |
| **メッシュ上でストロークの位置を保持する** | この設定は、新しい3Dメッシュを読み込んだ後にブラシストロークが再計算される方法を制御します。 ほとんどの場合、この設定を有効にしておくことをお勧めします。 詳細については、[UV再投影](../features/uv-reprojection.md)のドキュメントを参照してください。 |
| **自動ラップ解除** | 自動UVアンラップ 「オプション」ボタンをクリックして、プロセスを設定します。 詳細については、[UVの自動アンラップのドキュメント](../features/automatic-uv-unwrapping.md)を参照してください。 |

### 物理サイズ設定

読み込んだメッシュの[物理サイズ](../features/physical-size.md)を調整します。

| *設定* | *説明* |
| --- | --- |
| **メッシュファイルの内部単位尺度を使用** | メッシュが物理的に正確な測定値で作成された場合、Painterで同じ物理サイズを保つためにこのオプションを選択したままにします。 |
| **カスタムの単位尺度** | メッシュが物理サイズを考慮して作成されていない場合は、このオプションを使用してメッシュのサイズをカスタマイズします。 この値を決定するには、インポートするメッシュの物理サイズとサイズを知っている必要があります。 |
| **マテリアルを割り当てるときに塗りつぶしレイヤーの拡大/縮小を物理サイズに切り替える** | 有効にすると、物理サイズプロパティを持つマテリアルを割り当てる際に、塗りつぶしレイヤーと効果が自動的にスケール方式を物理サイズに切り替えます。 |

### カラーマネジメント設定

このセクションでは、色の変換方法に関する設定をコントロールします。 詳細については、[カラーマネジメント](../features/color-management/color-management.md)のドキュメントを参照してください。
