# ファイアウォールの構成

Substance 3D Painterでは、外部との通信が必要になる場合があります。その場合、ファイアウォールソフトウェアでホワイトリストに登録する必要があります。

| --- | --- | --- |

| バグレポート | 80 | <https://bugs.allegorithmic.com/api/bug> |
