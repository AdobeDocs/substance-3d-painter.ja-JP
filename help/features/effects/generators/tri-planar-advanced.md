# 3平面アドバンス

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_tri_planar_advanced.png" alt=""/><br><strong>内部：</strong>マスク、ジェネレータ</td>
    <td style="border: 0;" valign="top"><strong>説明</strong><br>3平面アドバンスドジェネレータは、3平面のブレンドモードのスタンドアロン版で、全投影を手動で制御できます。これには、それぞれの個別の軸のすべての回転とオフセット値の制御が含まれます。 ネイティブの塗り潰し投影と比較すると、Tri-Planar Advanced Generatorは、ワールド空間法線を使用して3つの投影軸をブレンドしますが、ネイティブの実装はロー – ポリゴンジオメトリのみに依存します。 この結果、より制御しやすく、より正確な結果が得られます。<br><br>3平面の高度なジェネレーターは、モノクロ（白黒）テクスチャを出力します。 したがって、カスタムマスクまたはアンカーポイントをブレンドして3平面を作成し、マスクとして使用すると便利です。<br><br>イメージ入力には、ベイク処理された位置とワールド空間の法線マップが必要です。 <a href="../../../baking/baking.md">ベーキングの詳細については、こちらを参照してください</a>。</td>
  </tr>
</table>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| **ワールド空間の標準**&#x200B;色 | ベイクワールド空間法線マップを使用します。 |
| **位置**&#x200B;の色 | ベイク処理された位置マップを使用します。 |
| **マスク**&#x200B;グレースケール | カスタムテクスチャまたはアンカーポイントを使用します。 |

## パラメーター

<table>
  <tr>
    <th>パラメーター名</th>
    <th>説明</th>
  </tr>
  <tr>
    <td><strong>投影</strong></td>
    <td>すべての軸を投影するか、1つの軸のみを投影するかを選択します。</td>
  </tr>
  <tr>
    <td><strong>描画モード</strong></td>
    <td>描画モードを選択して、軸を中心にブレンドします。<br><ul><li><strong>リニア</strong>:リニア描画モードでは、描画トランジション線は直線です。</li><li><strong>高度</strong>：高度な描画モードでは、指定された位置にある3つの軸と法線角度の間の最大値に基づいて軸がブレンドされます。</li></ul></td>
  </tr>
  <tr>
    <td><strong>描画コントラスト</strong></td>
    <td>ブレンドの変化線をぼかす度合いを調整します。</td>
  </tr>
  <tr>
    <td><strong>テクスチャタイリング</strong></td>
    <td>マスクテクスチャのタイリングを調整します。</td>
  </tr>
</table>

### X 軸

| パラメーター名 | 説明 |
| --- | --- |
| **回転X** | X軸テクスチャ投影を回転します。 |
| **オフセットX X** | X軸テクスチャ投影を左右に移動します。 |
| **オフセットX Y** | X軸テクスチャ投影を上下に移動します。 |

### Y 軸

| パラメーター名 | 説明 |
| --- | --- |
| **回転X** | Y軸テクスチャ投影を回転します。 |
| **オフセットY X** | Y軸テクスチャ投影を左右に移動します。 |
| **オフセットY Y** | Y軸テクスチャ投影を上下に移動します。 |

### Z 軸

| パラメーター名 | 説明 |
| --- | --- |
| **回転X** | Z軸テクスチャ投影を回転します。 |
| **オフセットZ X** | Z軸テクスチャ投影を左右に移動します。 |
| **オフセットZ Y** | Z軸テクスチャ投影を上下に移動します。 |
