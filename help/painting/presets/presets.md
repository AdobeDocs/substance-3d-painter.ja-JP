# プリセット

プリセットは、[ペイントツール](../../painting/tool-list/tool-list.md)の保存済み設定です。 次の3種類のいずれかになります。

* **ブラシプリセット** ：ブラシのパラメーター（サイズ、流量、ジッター、ステンシル、アルファ）を保存します。
* **マテリアルプリセット** :マテリアルのプロパティ（個々のチャンネルおよびSubstanceファイル）を保存します。
* **ツールプリセット** ：ブラシとマテリアルのプロパティと、使用されたツールの種類（ペイント、指先、クローンなど）を保存します。

プリセットは、[Assets](../../interface/assets/assets.md)フォルダー内のディスクに保存されます。 使用するすべてのリソースが埋め込まれているため、コンピューター間で簡単にコピーできます。

プリセットを管理するには、以下を参照してください。

* [プリセットの作成と保存](https://helpx.adobe.com/substance-3d/unlisted/documentation/spdoc/creating-and-saving-a-preset-180191514.html)
* [パーティクルプリセットの作成](../../painting/presets/creating-particles-pre/creating-particles-presets.md)
* [ブラシプリセット(ABR)](../../painting/presets/photoshop-brush-presets/photoshop-brush-presets-abr.md)
