# ベーキングログ

**ベーキングログパネル**&#x200B;には、ベーキングに関連する技術出力が表示されます。 パネルには、次の3つのタブがあります。

* **ベーキングプロセス**：進行中のベーキングタスクの状態または最新のベーキングの実行を確認します。
* **High polyパラメーター**:プロジェクトで使用されているHigh polyファイルの詳細を確認します。
* **名前による一致**: **高ポリゴンパラメータ>一致**&#x200B;が&#x200B;**メッシュ名**&#x200B;に設定されている場合、このタブにはアセットがどのように一致したかに関する情報が表示されます。

>[!TIP]
>
> アセットを名前で照合する方法については、[ベイカーのドキュメント](https://experienceleague.adobe.com/ja/docs/substance-3d/bakers/features/matching-by-name)を参照してください。
