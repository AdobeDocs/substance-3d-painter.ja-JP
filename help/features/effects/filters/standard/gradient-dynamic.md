# グラデーション動的

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![グラデーションの動的アイコン](./Resources/icon_gradient_dynamic.png "グラデーションの動的")

<b>イン:</b>エフェクト/グラデーション、グレースケール、再マップ

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

グラデーションダイナミックフィルターは、画像内のグレースケール値を、グラデーション上の特定のポイントに配置されたカラーによって定義されたグラデーションに再マップします。

このエフェクトは、テクスチャレイヤー上またはマスク内（白黒出力）で、別の画像からサンプリングしたグラデーションにグレースケール値を再マップするときに使用します。

</td>
</tr>
</table>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| <b>グラデーションソース：</b>カラー | カスタムカラーマップまたはアンカーポイントを使用します。 |

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>グラデーションの向き：</b> | グラデーションソースを水平方向または垂直方向のどちらでサンプリングするかを選択します。 |
| <b>グラデーションの入力位置：</b> | グラデーション入力からサンプリングした位置を調整します。 |
