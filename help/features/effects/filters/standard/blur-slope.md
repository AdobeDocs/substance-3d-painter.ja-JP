# ぼかし勾配

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="./Resources/icon_blur_slope.png" alt="ぼかし勾配アイコン" title="ぼかし勾配"/><br><strong>イン:</strong>効果/ぼかし、グレースケール</td>
    <td style="border: 0;" valign="top">説明<br>勾配ぼかしフィルターは、にじみやフェード効果を生み出します。特に、カラー間のコントラストの強いエッジで顕著です。<br>完全なテクスチャまたは特定のマテリアルをぼかすにはテクスチャレイヤー上で直接使用し、マスクににじませるにはマスク上で使用します。 エッジの欠損や風化、Dirtの漏れ、錆のしみなどのエフェクトを生み出すことができます。</td>
  </tr>
</table>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| **カスタムノイズ:**&#x200B;グレースケール | カスタムテクスチャまたはアンカーポイントをカスタムノイズとして使用します。 |

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| **シード：** | ランダム値を割り当てると、全体的な設定を変更することなく、異なるバリエーションを作成できます。 |
| **強度：** | ぼかしの強度を調整します。 |
| **強度分割線：** | ぼかしの適用度の分割方法を選択します。 |
| **描画モード：** | 勾配ぼかしに使用する描画モードを選択します。 |
| **品質：** | 効果の品質を調整します。 |

### ソースパラメーター

| パラメーター名 | 説明 |
| --- | --- |
| **ソースの種類：** | ソースで既定のノイズ、以前の入力、またはユーザー設定のノイズのいずれを使用するかを選択します。 |
| **ぼかし：** | ソースノイズまたは入力のぼかしの強さを調整します。 |
| **位置：** | 明るさコントロールと同様に、ソースノイズまたはソース入力の中心点を調整します。 |
| **コントラスト：** | ソースノイズまたは入力のコントラストを調整します。 |
| **ソースのティリング：** | ソースノイズまたは入力のタイリングを調整します。 |
