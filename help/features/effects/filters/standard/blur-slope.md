# ぼかし勾配

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![ぼかし勾配アイコン](./Resources/icon_blur_slope.png "ぼかし勾配")

<b>イン:</b>効果/ぼかし、グレースケール

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

ぼかし(勾配)フィルターは、にじみやフェードを与え、特にカラー間のコントラストの強いエッジで目立たせます。

完全なテクスチャや特定のマテリアルをぼかすにはテクスチャレイヤー上で直接使用し、マスクにににじませるにはマスク上で使用します。 エッジの欠損や風化、Dirtの漏れ、錆のしみなどのエフェクトを生み出すことができます。

</td>
</tr>
</table>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| <b>カスタムノイズ:</b>グレースケール | カスタムテクスチャまたはアンカーポイントをカスタムノイズとして使用します。 |

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>シード：</b> | ランダム値を割り当てると、全体的な設定を変更することなく、異なるバリエーションを作成できます。 |
| <b>強度：</b> | ぼかしの強度を調整します。 |
| <b>強度分割線：</b> | ぼかしの適用度の分割方法を選択します。 |
| <b>描画モード：</b> | 勾配ぼかしに使用する描画モードを選択します。 |
| <b>品質：</b> | 効果の品質を調整します。 |
