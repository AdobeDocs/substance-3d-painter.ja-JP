## 説明

MatFX油彩ペイントフィルターは、ソースを油彩ペイントの外観に仕上げます。

テクスチャレイヤーで使用され、油彩ペイントから着想を得た絵画調のストローク、カラーバリエーション、表面のディテールを作成します。

<a name="parameters"></a>

## パラメーター

**プリセット**&#x200B;が利用可能です。フィルター内の他の複数のパラメーターをすばやく更新して、出発点として機能させることができます。

>[!NOTE]
>
> プリセットを選択すると、すべてのパラメーターがプリセット値に設定されます。つまり、失いたくないフィルターに変更を加えた場合は、プリセットを試す前に、フィルターの複製を作成し、表示を切り替えることをお勧めします。

| パラメーター名 | 説明 |
| --- | --- |
| <b>入力の種類：</b> | エフェクトで使用する入力タイプを選択します。 |
| <b>効果の強さ：</b> | エフェクトの全体的な適用度を調整します。 |
| <b>詳細：</b> | 結果に保持される細かいディテールの量を調整します。 |
| <b>シャープ：</b> | 結果のシャープを調整します。 |
| <b>ラフネス:</b> | ラフネスの値を調整します。 |
| <b>ラフネスのバリエーション：</b> | 結果全体のラフネスの変化を調整します。 |
| <b>ラフネスの詳細：</b> | ラフネスに影響するディテールの量を調整します。 |
| <b>法線の強度：</b> | 法線の効果の強さを調整します。 |
| <b>ストロークの方向の影響（標準）:</b> | ストロークの方向が法線の結果に与える影響の強さを調整します。 |
