# ポスタリゼーション

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![ポスタリゼーションアイコン](./Resources/icon_posterize.png "ポスタリゼーション")

<b>イン：</b>エフェクト/カラー、ステップ

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

ポスタリゼーションフィルターは、画像のカラーまたはトーンの数を減らし、領域とエッジが目立つ段階的な外観を作成します。

テクスチャレイヤーまたはマスク（カラーまたはグレースケール）で使用され、色を単純化して、スタイライズされたグラフィックの外観を作成します。 これは、ポスターやイラストの場合や、芸術的な効果を得るためにディテールを抑える場合に便利です。

</tr>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>色の量：</b> | カラーステップ数を調整します。 |
| <b>Alphaに適用：</b> | アルファチャンネルもこのフィルターの影響を受けるかどうかを切り替えます。 |
