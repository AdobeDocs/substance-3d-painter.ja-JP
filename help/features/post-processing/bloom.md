# ブルーム

![](../../assets/v12_post_bloom.jpg)

シーンの明るい領域の周りにソフトな光彩を作成します。 明るいオーラの中で光の散乱がどのように変化するかをシミュレートします。

| <b>パラメーター</b> | <b>説明</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>金額</b> | ブルーム効果の強度を制御します。 値が大きいほど、明るい領域の周囲の輝きが強くなります。 |
| <b>しきい値</b> | ブルームをトリガーするのに必要な最小の輝度レベルを設定します。 この値より明るいピクセルだけが輝きます。 しきい値を1.0に設定すると、白いスクリーンよりも明るいピクセルだけが表示されます。 |
| <b>フォールオフ</b> | 明るい領域から花が広がる範囲を指定します。 値を小さくすると、光彩がよりコンパクトになり、値を大きくすると、効果がより広い領域に広がります。 |
