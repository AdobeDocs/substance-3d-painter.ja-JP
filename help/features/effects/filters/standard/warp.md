## 説明

ワープフィルターは、様々なデフォメーションエフェクトに使用されます。 ワープフィルターでは、通常のワープ、特定の方向にワープする方向ワープ、およびより多くのバリエーションを可能にする多方向ワープにアクセスできます。

ワープは、マテリアル、シェイプ、マスク、アウトラインなどを変形するために、テクスチャレイヤー上またはマスクの内側（白黒出力）に使用します。

</td>
</tr>
</table>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| <b>カスタムノイズ</b> | カスタムテクスチャをノイズ入力マップとして使用します。 |

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>シード：</b> | ランダム値を割り当てると、全体的な設定を変更することなく、異なるバリエーションを作成できます。 |
| <b>ワープモード：</b> | ワープモードを選択します。 |
| <b>強度：</b> | ワープの強度を調整します。 |
| <b>強度分割線：</b> | ワープの適用度の分割方法を選択します。 |
| <b>角度：</b> | ワープの角度を調整します。 |
| <b>描画モード：</b> | ワープで使用する描画モードを選択します。 |
| <b>方向：</b> | ワープの方向の数を選択します。 |
