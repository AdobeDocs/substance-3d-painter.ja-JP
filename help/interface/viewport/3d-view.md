# 3D ビュー

![](../../assets/3d-view.jpg){width="370px"}

この3D ビューは、照明条件下の3Dモデルを示しており、サーフェスマテリアルの定義方法を確認するのに役立ちます。 また、3Dモデルに直接ペイントを合わせることもできます。

## プロファイル

ビューポートの左上に、現在ロードされているプロファイルを示すテキストが表示されます。 詳細については、[カラープロファイル](../../features/post-processing/color-profile.md)のページを参照してください。

## カメラ選択

![](../../assets/display-mode.png)

プロジェクトの作成やメッシュの読み込みに使用した3Dモデルファイルにカメラが定義されている場合は、その3Dモデルファイルをプロジェクトに読み込んで、カメラの場所や方向を変更することができます。 このドロップダウンでは、プロジェクトで使用可能なカメラを切り替えることができます。 デフォルト以外のカメラがない場合、ドロップダウンは表示されません。

専用の[キーボードショートカット](../settings/shortcuts.md)を使用して、カメラの切り替えをすばやく行うことができます。 詳細については、[カメラ管理](camera-management.md)のページを参照してください。

## 表示モード

![](../../assets/display-mode.png)

デフォルトでは、ビューポート表示モードはマテリアルに設定され、環境照明が表示されます。 ドロップダウンでは、表示モードをソロに切り替えて、チャンネルとメッシュマップを個別に分離できます。

この照明は、[表示設定](../display-settings/display-settings.md)およびその他のレンダリング設定で制御できます。 照明の向きは、[キーボードショートカット](../settings/shortcuts.md)を使用して変更することもできます。

## 軸

![](../../assets/3d-axis.png)

ビューポートの右下には、カメラと比較してシーンの向きを示す3Dビュー軸があります。
