# 3D ビュー

![](../../assets/3d-view.jpg){width="370px"}

3Dビューは、照明条件下の3Dモデルを表示します。これにより、サーフェスのマテリアルがどのように定義されているかを確認できます。 また、3Dモデルを直接ペイントすることもできます。

## プロファイル

ビューポートの左上に、現在ロードされているプロファイルを示すテキストが表示されます。 詳細については、[カラープロファイル](../../features/post-processing/color-profile.md)のページを参照してください。

## カメラの選択

![](../../assets/display-mode.png)

プロジェクトの作成やメッシュの読み込みに使用した3Dモデルファイルにカメラが定義されている場合は、そのカメラをプロジェクトに読み込んで、カメラの位置や方向を変更することができます。 このドロップダウンを使用すると、プロジェクトで使用可能なカメラを切り替えることができます。 デフォルト以外のカメラがない場合、ドロップダウンは表示されません。

専用の[キーボードショートカット](../settings/shortcuts.md)を使用して、カメラをすばやく切り替えることができます。 詳細については、[カメラ管理](camera-management.md)のページを参照してください。

## 表示モード

![](../../assets/display-mode.png)

デフォルトでは、ビューポート表示モードは環境照明を表示するマテリアルに設定されています。 ドロップダウンを使用すると、表示モードをソロに切り替えて、チャンネルとメッシュマップを個別に分離できます。

この照明は、[表示設定](../display-settings/display-settings.md)およびその他のレンダリング設定で制御できます。 [キーボードショートカット](../settings/shortcuts.md)を使用して、照明の向きを変更することもできます。

## 軸

![](../../assets/3d-axis.png)

ビューポートの右下には3Dビュー軸があり、カメラと比較してシーンの方向を示します。
