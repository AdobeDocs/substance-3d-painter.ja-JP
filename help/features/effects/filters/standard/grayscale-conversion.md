# グレースケール変換

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![グレースケール変換アイコン](./Resources/icon_grayscale_conversion.png "グレースケール変換")

<b>イン：</b>効果/カラー、彩度の低下、最小、最大

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

グレースケール変換フィルターは、各色チャンネルの輝度を比較して、チャンネル/カラー画像をグレースケールに変換します。 変換を微調整するには、多くのオプションがあります。

チャンネルをグレースケールに変換したり、カラー画像をグレースケールに変換してマスクとして使用したりする場合に、テクスチャレイヤーまたはマスクレイヤー上で使用します。

</td>
</tr>
</table>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| <b>カスタム入力：</b>カラー | カスタムテクスチャまたはアンカーポイントを使用します。 |

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>チャネル入力：</b> | 変換に使用するチャンネル入力を選択します。 |
| <b>反転：</b> | 結果の反転を切り替えます。 |
| <b>残高：</b> | 明るさの調整と同様に、結果の黒と白のバランスを調整します。 |
| <b>コントラスト：</b> | 結果のコントラスト/フォールオフを調整します。 |
| <b>モード：</b> | グレースケール変換モードを選択します。 |
| <b>赤：</b> | 赤チャンネルの重みを調整します。 この重み付けは、グレースケール結果の計算に使用されます。 |
| <b>緑：</b> | グリーンチャンネルの重みを調整します。 この重み付けは、グレースケール結果の計算に使用されます。 |
| <b>青：</b> | 青チャンネルの重みを調整します。 この重み付けは、グレースケール結果の計算に使用されます。 |
| <b>Alpha:</b> | アルファチャンネルの重みを調整します。 この重み付けは、グレースケール結果の計算に使用されます。 |
