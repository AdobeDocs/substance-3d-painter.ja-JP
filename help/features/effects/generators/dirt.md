# 汚れ

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_dirt.webp" alt=""/><br><strong>内部：</strong>マスク、ジェネレータ</td>
    <td style="border: 0;" valign="top"><strong>説明</strong><br>Dirtジェネレータは、曲率、周囲オクルージョンに基づいて、すき間、エッジ、および平面にDirtと経年劣化のリアルな組み込みを追加します。 必要に応じて、マイクロHeightマップとマイクロ法線マップを使用して詳細を追加することもできます。<br><br>Dirtジェネレータは、白黒のテクスチャを出力します。 そのため、マスクを作成してDirtや経年劣化のディテールをモデルに加えると便利です。<br><br>イメージ入力には、ベイク処理された位置、曲率、環境オクルージョン、およびワールド空間の法線マップが必要です。 <a href="../../../baking/baking.md">ベーキングの詳細については、こちらを参照してください</a>。</td>
  </tr>
</table>

>[!NOTE]
>
> Dirtジェネレータは、メッシュにDirtをすばやく加えるための強力なツールです。 最良の結果を得るには、Dirtの適用方法を制御するために、常に素材の環境と履歴を考慮しながら、別のマスクを使用することをお勧めします。

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| **曲線**&#x200B;グレースケール | ベイク処理された曲率マップを使用します。 |
| **環境オクルージョン**&#x200B;グレースケール | ベイク処理されたアンビエントオクルージョンマップを使用します。 |
| **ワールド空間の標準**&#x200B;色 | ベイクワールド空間法線マップを使用します。 |
| **位置**&#x200B;の色 | ベイク処理された位置マップを使用します。 |
| **カスタム経年劣化**&#x200B;グレースケール | カスタムテクスチャまたはアンカーポイントを使用します。 |
| **マイクロ法線**&#x200B;カラー | カスタムの法線テクスチャまたはアンカーポイントを使用します。 |
| **マイクロHeight**&#x200B;の色 | カスタムテクスチャまたはアンカーポイントを使用します。 |

## パラメーター

<table>
  <tr>
    <th>パラメーター名</th>
    <th>説明</th>
  </tr>
  <tr>
    <td><strong>シード</strong></td>
    <td>Dirtテクスチャの作成に使用するシード値を設定します。 <br><ul><li>別のランダムシードに切り替えるには、「ランダム」をクリックします。</li><li>鉛筆をクリックして現在のシード値を表示し、必要に応じて特定の値を入力します。</li></ul></td>
  </tr>
  <tr>
    <td><strong>反転</strong></td>
    <td>Dirtマスクを反転する</td>
  </tr>
  <tr>
    <td><strong>汚れのレベル</strong></td>
    <td>Dirt効果の強度を調整します。</td>
  </tr>
  <tr>
    <td><strong>汚れのコントラスト</strong></td>
    <td>Dirt効果のコントラストを調整します。</td>
  </tr>
  <tr>
    <td><strong>Triplanar を使用</strong></td>
    <td>Triplanarを有効にすると、テクスチャはUVのみに依存するのではなく、3方向（X、Y、Z軸）から投影されます。 <br><ul><li>Triplanarを有効にしていない場合、テクスチャはUVレイアウトに従います。</li><li>三角形を有効にすると、テクスチャは複数の角度から投影され、ブレンドされます。</li></ul></td>
  </tr>
  <tr>
    <td><strong>Triplanar の描画コントラスト</strong></td>
    <td>三平面マッピングを使用して、投影時にテクスチャがブレンドされる滑らかさを調整します。 各方向からの投影間のブレンドの柔らかさを調整します。</td>
  </tr>
  <tr>
    <td><strong>汚れ量</strong></td>
    <td>経年劣化ディテールの適用度を調整します。</td>
  </tr>
  <tr>
    <td><strong>汚れの拡大・拡張</strong></td>
    <td>経年劣化のディテールのサイズを調整します。</td>
  </tr>
  <tr>
    <td><strong>カスタム汚れを使用</strong></td>
    <td>カスタム経年劣化マップの使用のオンとオフを切り替えます。</td>
  </tr>
  <tr>
    <td><strong>エッジのマスキング</strong></td>
    <td>曲線マップに基づいてエッジのマスクを調整します。</td>
  </tr>
</table>

### マイクロ詳細

<table>
  <tr>
    <th>パラメーター名</th>
    <th>説明</th>
  </tr>
  <tr>
    <td><strong>マイクロ高さ</strong></td>
    <td>カスタムマイクロHeightマップの使用のオンとオフを切り替えます。</td>
  </tr>
  <tr>
    <td><strong>マイクロ法線</strong></td>
    <td>カスタムマイクロ法線マップの使用のオン/オフを切り替えます。</td>
  </tr>
  <tr>
    <td><strong>曲率の種類</strong></td>
    <td>曲線のタイプを設定します。 <br><ul><li><strong>標準</strong>：通常、非常にシャープな結果が得られますが、詳細の幅が狭くなる場合があります。</li><li><strong>Sobel</strong>: Sobelフィルターを使用して法線マップを評価するため、標準と比較して同様の結果が得られますが、やや不鮮明です。</li><li><strong>滑らか</strong>：情報を累積するために、さまざまなレベルのぼかし（ミップマップなど）を作成します。 これにより通常はより滑らかなカーブになりますが、ディテールが失われる可能性があります。</li></ul></td>
  </tr>
  <tr>
    <td><strong>曲率の強度</strong></td>
    <td>標準モードとソベル曲線モードで曲線の強さを調整します。</td>
  </tr>
  <tr>
    <td><strong>高さの詳細の強度</strong></td>
    <td>マイクロHeightのディテールの量を調整します。</td>
  </tr>
  <tr>
    <td><strong>AO の半径</strong></td>
    <td>周囲オクルージョンの半径（範囲）を微調整します。</td>
  </tr>
  <tr>
    <td><strong>AO 深度</strong></td>
    <td>周囲オクルージョンの深度（強さ）を微調整します。</td>
  </tr>
</table>
