# ネットワークからのファイルの読み込み

Substance 3D Painterでは、ソフトウェアでサポートされていない&#x200B;**アカウント認証**&#x200B;が必要なため、ネットワークパスはサポートされていません。\
したがって、パスは、オペレーティングシステムによって&#x200B;**マップ** / **マウント**&#x200B;されている必要があります。

* **Windows** : <http://www.laptopmag.com/articles/map-network-drive-windows-10>
* **MacOS** : <http://osxdaily.com/2010/09/20/map-a-network-drive-on-a-mac/>
* **Linux** : <http://superuser.com/questions/145191/how-do-i-map-a-drive-network-share-using-the-linux-terminal>
