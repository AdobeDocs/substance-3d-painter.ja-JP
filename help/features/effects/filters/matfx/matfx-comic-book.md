## 説明

MatFX Comic Bookフィルターは、コミック本風の外観でマテリアルをスタイライズします。

テクスチャレイヤーで使用され、シェーディングを簡素化し、大胆な視覚的処理を施したグラフィック、イラスト入りのレンダリングスタイルを作成します。

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| <b>Ambient occlusion:</b>グレースケール | ambient occlusionマップを使用します。 |
| <b>曲率:</b>グレースケール | 曲率マップを使用します。 |
