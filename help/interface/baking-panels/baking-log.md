# ベーキングログ

**ベイクログパネル**&#x200B;には、ベイクに関連する技術的な出力が表示されます。 パネルには、次の3つのタブがあります。

* **ベイク処理プロセス**：進行中のベイク処理タスクまたは最新のベイク処理実行のステータスを確認します。
* **High polyパラメーター**:プロジェクトで使用されているHigh polyファイルの詳細を確認します。
* **名前による一致**: **高ポリゴンパラメーター>マッチ**&#x200B;が&#x200B;**メッシュー名による一致**&#x200B;に設定されている場合、このタブにはアセットがどのように一致したかに関する情報が表示されます。

>[!TIP]
>
> アセットを名前で照合する方法については、[ベイカードキュメント](https://experienceleague.adobe.com/en/docs/substance-3d/bakers/features/matching-by-name)を参照してください。
