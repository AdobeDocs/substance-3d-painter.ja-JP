# パスでフィルター

**パスでフィルター**&#x200B;は、アセット間を移動するために使用できる追加セクションです。 ブレッドクラムと同じ構造であるため、アセットのパス/場所を確認できます。

![](../../assets/01-01-panel.jpg)

既定では、**適用されないフォルダーを非表示**&#x200B;がアクティブになり、空のフォルダーをUIから非表示にすることができます。 これは、例えば、パスによるフィルターと特定の検索語を組み合わせたり、アセットのタイプを選択したりした場合に便利です。これにより、検索を含む関連する場所のみを表示できます。

![](../../assets/01-02-hideempty.gif)
