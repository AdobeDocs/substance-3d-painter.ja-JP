## 説明

クオンタイズフィルターは、画像のカラーを限定したセットに限定します。

テクスチャレイヤー上で、より平坦なカラー領域、ポスタリゼーションされたカラー領域、スタイル化されたカラー領域を作成するために使用されます。

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>色の適用量：</b> | クオンタイズした画像で使用するカラーの最大数を調整します。 この値は抽出されたパレットも駆動しますが、量子化方法によっては実際のカウントが低くなる場合があります。 出力されるパレットのカラー量で、抽出される最終的なカラーの数を確認します。 |
| <b>等高線のスムージング：</b> | 入力画像に適用される滑らかさの半径を調整して、量子化した結果をより立体的でまとまりのある形状に単純化します。 値が大きいほど、計算時間が大幅に長くなります。 |
| <b>ディザリング:</b> | クオンタイズ後に残った色だけを使用しながら、グラデーションとカラーブレンドの再作成に使用するディザリングの量を調整します。 予想されるディザリング効果には、[等高線のスムージング]の値0を使用します。 |
| <b>ディザリングパターン：</b> | 元の画像のグラデーションとカラーブレンドの再作成に使用するディザリングパターンを選択します。 |
| <b>距離のカラースペース：</b> | 量子化中にカラーを比較および分布するために使用されるカラースペースを選択します。 知覚的なカラー画像にはラボ（カラー）を使用し、法線マップなどのRawデータにはRGB（データ）を使用します。 |
| <b>Alphaに適用：</b> | レイヤーのアルファチャンネルの量子化を切り替えます。 |
| <b>Alphaしきい値：</b> | アルファしきい値を調整します。 |
