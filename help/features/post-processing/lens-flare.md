# レンズフレア

![](../../assets/v12_post_flare.jpg)

明るい光源がカメラのレンズ素子と相互作用して、ハロー、縞、およびゴーストの反射光が生じるときに発生する光アーティファクトをシミュレートします。

| <b>パラメーター</b> | <b>説明</b> |
| --- | --- |
| <b>解決策</b> | レンズフレアエフェクトのレンダリング解像度を設定します。 値を大きくすると、線がよりシャープになりますが、パフォーマンスに影響を与える可能性があります。 |
| <b>カメラ</b> | フレアのシミュレーションに使用するカメラモデルを選択します。 指定可能な値は次のとおりです。<ul data-preserve-html="true"> <li data-preserve-html="true"><b>パノラマレンズ</b> （短い焦点距離） </li> <li data-preserve-html="true"><b>望遠レンズ</b> （長焦点距離）。</li> </ul> |
| <b>金額</b> | フレアエフェクトの全体的な強度を制御します。 値は1.0を超えて強度を上げることができます。 |
| <b>しきい値</b> | フレアの生成に必要な画像の最小輝度を指定します。 値を小さくすると、フレアを生成する領域が多くなり、値を大きくすると効果が非常に明るい光源に限定されます。 |
| <b>アパーチャスケール</b> | フレア要素に使用されるアパーチャシェイプのサイズを拡大・縮小し、フレア計算全体のサイズに影響します。 |
| <b>コートの厚み</b> | レンズ要素上の反射防止コーティングをシミュレートします。 コーティングのThicknessは光の散乱に影響し、フレアのカラーも変化します。 |
| <b>コートIOR</b> | レンズの屈折率をシミュレートします。つまり、光がThicknessを通過する様子を表現します。 値が小さいほど、ゴーストの密度が高くなります。 |
| <b>オクルージョンスケール</b> | 影響を受ける中央領域のサイズを設定します。 |
| <b>Smoothness</b> | レンズフレアのフェード（徐々に減少）の度合いを制御します。 値が大きいほど、変化が緩やかになります。 |
| <b>一意のゴースト</b> | フレアシェイプの変化の度合いを定義します。 値を大きくすると、パフォーマンスに大きな影響を与える可能性があります。 |
| <b>ゴーストの位置スケール</b> | フレアゴーストの広がりとサイズを制御します。 |
| <b>テクスチャ</b> | フレアパターンの作成に使用するレンズアパーチャの形状を指定します。 テクスチャは、回折とゴーストの形状を制御する。 |
