# バージョン8.3

**Substance 3D Painter 8.3**&#x200B;は、新しいベイク処理モード、USDファイルのインポート、およびUV 投影モードでの物理サイズのサポートを導入します。

リリース日： *10 January 2023*

## 主な特徴

### 新しいベイクモード

![](../assets/banner-baking_1.jpg)

古いベーキングウィンドウは、ケージの表示やマッチングエラーなどのビューポートの視覚化など、いくつかの新機能を備えた専用モードに置き換えられました。

* **モードへのアクセスと切り替え**\
  ベイク処理は、アプリケーションの既存のペイントモードとレンダリングモードに加えて、新しい個別のモードになりました。 ベイクモードに切り替えるには、コンテキストツールバーの小さな「クロワッサン」アイコンを使用します。 モードの切り替えは、それ以外の場合にも実行できます。モードメニューまたはキーボードショートカットを使用します。 別のモードに戻るには、モードの専用アイコンを使用します（さらに、[メッシュマップ](../interface/texture-set/texture-set-settings.md)内の&#x200B;**設定**&#x200B;ボタンを使用して、新しいモードに戻ることができます）。

  ![](../assets/baking-mode-switch-menu.png)

  ![](../assets/baking-mode-switch-icon.png)

* **新しいモードインターフェイス**\
  従来のベーキングウィンドウは、専用のドックを備えたモードに変わりました。特に次のようになります。

  * **テクスチャセットリスト**&#x200B;を使用して、プロジェクトのどの部分をベイクするかを定義できます。
  * **メッシュマップベイカー**&#x200B;では、一般的なベイク処理の設定とベイカー処理の設定を選択できます。 また、どのベイカープロセスを開始するかを指定することもできます。
  * **メッシュマップの設定**&#x200B;には、すべてのベイカーと共通の設定が保存され、前の2つのウィンドウの選択内容に応じて変更することができます。
  * **ベイクログ**&#x200B;は、ベイク処理に関するさまざまな情報（特にエラーメッセージ）を再編成します。
  * **視覚化のベイク**：このパネルはビューポートにあり、ローポリゴンとハイポリゴンのメッシュの表示に関するいくつかのオプションを制御します。

  ![](../assets/baking-mode-overview.jpg){width="500px"}

* **ビューポートから直接ベイク処理を開始およびキャンセル**\
  ベイクプロセスを開始またはキャンセルするボタンが、ビューポートの下部に表示されるようになりました。 小さな矢印を使用して、テクスチャセットリストの選択内容や現在アクティブなテクスチャセットに基づいてベイクモードを指定することもできます。

  ![](../assets/baking-button.png)

  ![](../assets/baking-button-cancel.png)

* **ビューポートにハイポリメッシュを表示する**\
  ベイク設定でhigh-poly メッシュを指定すると、専用のビジュアライゼーション設定が無効になっていない限り、ビューポートにも読み込まれます。 これにより、ローとハイポリメッシュのジオメトリが適切に一致しているかどうかを確認できます。

  ![](../assets/low-vs-high.jpg){width="400px"}

* **メッシュをビューポートに表示し、領域が不足している場合はエラーとして表示する**\
  メッシュは、ビューポートに表示することもできます。 専用のメッシュファイルを使用しない場合は、代わりに暗黙的なケージが表示され、「最大前頭距離」パラメーターに応じて変化します。 ケージサイズを調整する場合、高ポリゴンメッシュのケージの外側にあるパーツは、デフォルトで赤で表示されるため、ベイク処理プロセスによって見落とされるメッシュのパーツを簡単に見つけることができます。

  ![](../assets/cage-distance.gif)

* **読み込みとベイク中にメッシュを見回す**\
  メッシュを読み込み、ベイクしてもアプリケーションがフリーズしなくなったため、これらの処理中にビューポートとやり取りすることができます。 これは、進行中のベイクを調べ、問題を早期に特定してベイクをキャンセルし、最終的に時間を節約するのに役立ちます。 同様に、ビューポートで最も見えるテクスチャセットが最初にベイクされ、事前に特定の領域の結果を確認するのに役立ちます。

  ![](../assets/interaction-while-baking.gif)

* **ニュートラルマテリアルとビューポートの設定**\
  ベイク結果に集中し、問題が発生した場合に問題を見つけやすくするために、ベイクモードではペイントされたテクスチャが表示されず、ニュートラルマテリアルが使用されます。 このニュートラルマテリアルの設定は、ビューポート内のベイク処理表示パネルで調整できます。

  ![](../assets/neutral-material-demo.gif)

* **シームのないハードエッジを表示する**\
  ベイク処理時にアーチファクトが発生する原因の1つは、UVシームのないハードエッジが存在することです。 これにより、線が表示され、シェーディングのSmoothnessが損なわれる可能性があります。 この目的のために、ビジュアライゼーション設定が追加され、3Dと2D ビューの両方でハイライトされるようになりました。

  ![](../assets/hard-edge-missing-seams.png){width="450px"}

  ![](../assets/hard-edge-missing-seams-2d.jpg){width="300px"}

* **パラメーターの同期と同期の解除**\
  新しい同期操作を使用すると、ベイク処理設定のどの部分をテクスチャセット間で同期するかを指定できます。 そうでないと、同じ方法で設定を複数回設定するのは面倒です。 場合によっては、専用の設定を持つテクスチャセットを用意し、同期を取らないようにすることが望ましい場合もあります。 例えば、共通設定を分割したままにすると、「最前面距離」、「解像度」、および/またはテクスチャセットごとに異なるハイポリメッシュのリストを使用できるようになりました。

  ![](../assets/sync-icon-1.png){width="400px"}

  ![](../assets/sync-ao-settings.png){width="400px"}

* **名前チェッカーによる一致**\
  **ベイクログ**&#x200B;の[**名前による一致**]タブは、ベイク前に一致プロセスでエラーを見つけるのに役立ち、一致しないメッシュを容易に確認できます。 一致するメッシュはグループ化され、その他のアセットは赤で表示されます。

  ![](../assets/matching-by-name-log.png){width="450px"}

>[!NOTE]
>
> この新しいモードには、さらに多くの新しい設定があります。 詳しくは、[専用のドキュメントページ](../baking/baking.md)を参照してください。

### USDファイルの新しい読み込みと書き出し

![](../assets/banner-usd.jpg)

この新しいバージョンでは、[Universal Scene Description (USD)](https://graphics.pixar.com/usd/release/intro.html)ファイルフォーマットのサポートが追加されています。 Painterのプロジェクトを開始し、USD形式を使用してメッシュとテクスチャを書き出せるようになりました。これにより、アプリケーション間でより一貫したワークフローが可能になります。

* **バリアント型、スキン、および指定したフレームでのUSDファイルのインポート**\
  USDファイル形式は、プロジェクトを作成するときや、プロジェクト内にメッシュを再読み込みするときに使用できます。 USDファイルは複雑なシーンになる場合があるので、スコープとバリアントセレクターもファイルのサブセットを読み込むためにのみ使用できます。

  ![](../assets/usd-import-settings.png){width="400px"}

  ![](../assets/usd-scope-variants.png){width="400px"}

* **USDを新しいファイルとして書き出すか、プロジェクトで使用されている元のUSDにリンクします**\
  テクスチャリングの準備ができたら、**ファイル/テクスチャを書き出し**&#x200B;ウィンドウを使用して、USDファイルとテクスチャファイルを一緒に書き出すことができます。 設定&#x200B;**USDアセットの書き出し**&#x200B;を有効にするだけです。 これにより、いくつかのUSDファイルが生成され、後でパイプラインに簡単に統合できます。 USD以外のファイルまたはUVのないUSDファイルを使用した場合は、テクスチャマップおよびUSDマテリアルファイルに加えて、新しいUSDジオメトリファイルが書き出されます。\
  また、**ファイル/メッシュを書き出し**&#x200B;を使用して、プロジェクトのジオメトリをUSDファイルとして書き出すこともできます。

  ![](../assets/usd-export-textures.png)

  ![](../assets/usd-export-mesh.png){width="400px"}

### UVモードでの物理サイズのサポートの改善

![](../assets/banner-physicalsize-1.jpg)

物理サイズが埋め込まれたSubstanceマテリアルのサポートが、UVベースの投影にも拡張されました。

* **UVモードの物理サイズ**\
  UV 投影モードを使用して、塗りつぶしレイヤーおよび塗りつぶし効果で物理サイズの代わりに、拡大・縮小モードをタイリングに設定できるようになりました。 UVのサイズは、UVラップ解除からの三角形の平均サイズに基づいて自動的に計算されます。

  ![](../assets/physicalsize-uvmode.png){width="400px"}

* **物理サイズに自動的に切り替える**&#x200B;新しいプロジェクト設定が追加され、マテリアルを作成するとき（たとえば[資産]ウィンドウのリソースをドラッグアンドドロップするとき）に、スケール設定が自動的に物理サイズに設定されます。 これにより、新しい塗りつぶしレイヤーを作成するたびに手動で設定を切り替えることなく、プロジェクト全体で一貫したサイズ設定を使用できます。 既存のプロジェクトで有効にするには、**編集/プロジェクト構成**&#x200B;に移動し、**マテリアルを割り当てるときに塗りつぶしレイヤーのスケーリングを物理サイズに切り替える**&#x200B;を有効にします。 この設定は、新規プロジェクトの作成時にも有効にすることができます。

  ![](../assets/physicalsize-settings.png)

* [SVT] AMD GPUで疎ハードウェアサポートを有効にする

  スパース仮想テクスチャシステムのハードウェアアクセラレーションをAMD GPUで有効にできるようになりました。 この設定は、一般環境設定で自動的に有効になります。
* [投影]円柱投影パラメータの名前を変更

  パラメータ「Cylinder Cap Culling」の名前が「Backface Culling」に変更され、アクションがより適切に表現されるようになりました。 関連付けられたツールチップは、それに応じて調整されます。
* [プロジェクト]プロジェクトにアプリケーションバージョンを保存し、スクリプトを使用して取得する

  バージョン8.2以降では、アプリケーションのバージョンは保存時にsppファイル内に保存されるようになりました。\
  このバージョン番号は、Python APIのプロジェクトモジュール内の関数last\_saved\_substance\_painter\_version()で取得できます。\
  8.2より前に作成されたプロジェクトの場合、戻り値はnullになります。
* [読み込み] 3Dモデルの一般的な読み込み時間を短縮

  メッシュの一般的な読み込み時間を改善しました。 たとえば、ベイク処理のために高ポリゴンメッシュをロードする際の待ち時間を短縮できます。 この最適化は、特にOBJファイルのロードに適用されます。
