# バージョン2019.2

**Substance Painter 2019.2**&#x200B;は、ベイカーに新しい強力な機能をもたらし、シェルフに新しいスマートマテリアルとスマートマスクのセットを提供します。

リリース日： *25 July 2019*

## 主な機能

### ベイカーのワークフローの改善

![](../../assets/header-image-vizu.jpg)

このリリースでは、ベイク処理ワークフローが改善され、いくつかの新機能が追加されました。 これらの機能強化により、Substance Painterを使用した日常業務が高速化され、容易になります。

* **プロセスの視覚化のベイク**\
  この新しいバージョンでは、デフォルトでベイクプロセスがビューポートに表示されるようになりました。 これにより、ベイカーの結果をリアルタイムでプレビューし、必要に応じてプロセスの終了を待たずにキャンセルして、より迅速な反復を提供できます。 このビヘイビアーは、メイン設定で、「**ベイク処理オプション**」セクションの「**ライブプレビューベイク処理プロセスを有効にする**」設定のチェックボックスをオフにすることで無効にできます。

  ![](../../assets/baking-options-v2.png)

  ![](../../assets/bake-process.gif){width="500px"}
* **ベイク処理ダイアログの改善**\
  ベイクダイアログが修正され、現在のベイクプロセスのより良いステータスが表示されるようになりました。 ベイカーごとに計算されるテクスチャの数と、計算対象のテクスチャセットを示すカウンターが追加されました。 ベイカーが発生すると、エラー名の横に赤い十字が表示されます。 プロセスの最後に、新しいボタンをクリックすると、ログウィンドウをすばやく開いて問題の詳細を確認できます。\
  ![](../../assets/baking-dialog.png)
* **進行中のベイクを取り消しています**&#x200B;ベイクプロセスでアプリケーションがロックされなくなりました。 Substance Painterの応答性が向上しました。つまり、現在進行中の烘焙は、終了するのを待つことなくキャンセルできます。 ただし、キャンセルはすぐに行われるものではなく、有効になるまでに数秒かかる場合があります。 これは、内部的にはベイクプロセスがチャンク内のテクスチャで動作し、チャンクの計算中に停止できないためです。 ベイクプロセスをキャンセルすると、ベイクウィンドウが自動的に再び開きます。\
  ![](../../assets/baking-cancel-optim.gif)

### ベイカーのパフォーマンスの向上

![](../../assets/header-image-baker.jpg)

また、ワークフローの改善により、ベイカーの更新とパフォーマンスの向上も実現しました。 また、DXRとOptixのサポートが追加され、GPU レイトレーシングを以前よりもはるかに高速にベイクできるようになりました。 ただし、GPU レイトレーシングはAmbient occlusionとThicknessのベイカーにのみ影響することに注意してください。

* **CPU レイトレーシングが改善されました**\
  CPU上の計算は、以前の2～3倍の速度になりました。 そのため、GPUがGPU レイトレーシングと互換性がない場合でも、一般的なパフォーマンスは向上します。
* **DXRおよびOptixでのGPU レイトレーシングのサポート**\
  互換性のあるハードウェアを使用することで、ベイカーはGPU上で直接計算できるようになり、特にアンチエイリアスが有効で大量の光線が定義されている場合に、計算時間が大幅に短縮されます。 DXRがデフォルトです（使用可能な場合）。それ以外の場合はOptixが使用されます。 [メイン設定](../../interface/settings/settings.md)に移動して「**ベイク処理オプション**」を探すと、GPU レイトレーシングを無効にできます。

  ![](../../assets/baking-options-v2.png)

>[!NOTE]
>
> GPU レイトレーシング機能を有効にするには、次のドライバーに更新してください： **Nvidiaドライバー430.86**。\
> DXRは、RTX GPUおよび[GeForce GTX 10xx GPU](https://www.nvidia.com/en-us/geforce/news/geforce-gtx-dxr-ray-tracing-available-now/)で使用できます。 DXRを使用するには、Windows 10が最新のバージョン（バージョン1809）である必要があります。詳しくは、こちらのページを参照してください。

>[!WARNING]
>
> GPU レイトレーシングを使用する場合、高ポリゴンのメッシュがVRamに収まらない場合、ベイカーが失敗することがあります。 このような場合は、[メイン設定](../../interface/settings/settings.md)に移動し、「**ベイク処理オプション**」セクションの「**GPU レイトレーシング**」設定を無効にすることをお勧めします。 その後、ベイクプロセスを再起動するだけです。

### さまざまな新機能と改善点

![](../../assets/header-image-misc.jpg)

このリリースでは、Substance Painter内のQOLを向上させるために、いくつかの機能も追加および修正しました。

* **回転マニピュレーターの向上**\
  以前は回転マニピュレーターが少し遅かったため、回転が面倒なことがありました。 これで、回転速度がカメラとシーンサイズにリンクされます。
* **ビューポートのダウンスケールにより、高DPI画面のパフォーマンスが向上しました**\
  [メイン設定](../../interface/settings/settings.md)に、「ビューポートのスケーリング」という名前の新しいパラメーターが追加されました。このパラメーターの値は、「**なし**」および「**自動**」（既定）です。 Substance Painterは、画面がHDPIスケール（MacOSのRetina画面など）を使用していることを検出すると、ビューポート解像度を2で自動的に割ります。 このビヘイビアーにより、ビューポートを大きくしすぎずに、目立った画質の低下を防ぎ、一般的なパフォーマンスを向上させることができます。

  ![](../../assets/settings-viewport-downscale.png)
* **スクリプト用の新しいコンソールプラグイン**\
  スクリプトAPIから簡単にコマンドを実行するための新しいプラグインを作成しました。 Githubで使用可能です： <https://github.com/AllegorithmicSAS/painter-plugin-console>。 コンソールはオートコンプリートもサポートしています。

  ![](../../assets/console-plugin.png)
