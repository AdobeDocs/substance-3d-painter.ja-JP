# バージョン9.0

<b>Substance 3D Painter 9.0</b>では、3Dビューポートで再編集可能なパスを使用してストロークをペイントする新しい方法と、更新されたデフォルトのコンテンツが導入されています。

リリース日： *20 June 2023*

## 主な機能

### 3Dビューポートのパスに沿って新規ペイント

![上にパスの描画がある革靴をヘルパーのUIで閉じる](../assets/v90_banner_path.jpg)

<b>パスに沿ってペイント</b>ツールは、3Dビューポートでストロークをペイントするための新しい方法です。 他のアプリケーションと同様に、3Dオブジェクトのサーフェス上のポイントによって駆動されるベジェベースの曲線を作成して、パターンを描画できます。 Substance素材と組み合わせることで、新たな可能性が広がります。

* <b>ポイントのあるパスで駆動されるペイントストロークを作成するための新しいツール</b>\
  ツールのツールバーには、パスツール専用の新しいアイコンが表示されます。 この新しいツールを使用すると、3Dモデルのサーフェスに曲線を描画して、ペイントストロークを作成できます。 これらのストロークはいつでも再編集できます。 ツールがアクティブな場合は、メッシュサーフェスをクリックするだけでポイントを追加できます。 既存のポイントをクリックし、Deleteキーを押して削除します。

  ![3種類のパスツールを示すツールバーのインターフェイスのスクリーンショット。](../assets/v90_path_toolbar.png)

  ![パス上のポイントの追加と削除を示すGif](../assets/v90_path_add_remove_points.gif)
* <b>メッシュサーフェス上のポイントをドラッグして移動します</b>\
  パスの形状を編集するには、ポイントをクリックしてドラッグし、3Dモデルのサーフェスに沿って移動します。

  ![ポイントの移動方法を示すGif](../assets/v90_path_move_points.gif)
* <b>シームレスなパターンを作成するためのパスを閉じる</b>\
  パスを閉じてループを作成することもできます。これは、例えば、特定の領域の周囲に繰り返しパターンを作成する場合に便利です。

  ![開いているパスまたは閉じているパスを示すGIF](../assets/v90_path_open_close.gif)

  ![機械的な面にリベットを描くためのクローズパスを示しているGif](../assets/v90_path_closed_loop_demo.gif)
* <b>パスパネルでパス（およびそのプロパティ）を再編集する</b>\
  パスツールを選択すると、現在のペイントレイヤーで作成されたパスが3Dビューポートの上部にある専用のパスパネルに一覧表示されます。 このパネルでは、次のパスを選択、削除、名前変更できます

  ![アクションのパスパネルを示すGIF](../assets/v90_path_panel_demo.gif)

  ![変更されているパスプロパティを示すGID](../assets/v90_path_edit_properties.gif)
* <b>シンメトリー、ジオメトリマスク、動的ストロークなど、他のペイント機能と互換性があります。</b>\
  通常のペイントストロークの多くの設定は、パスツールで使用できます。

  * 対称を有効にすると、パスを複数回描画しながら、1つのパスのみを管理することができます。
  * ジオメトリマスクが有効になっているレイヤー上にあるパスは、非表示のジオメトリの下にペイントできます

  ![対称プロパティを使用して2回溺れているパスを示しているGif](../assets/v90_path_symmetry.gif)
* <b>消しゴムや指先ツールなどの他のツールでペイントする</b>\
  また、パスツールは、消しゴムや指先ツールと互換性があり、より高度なペイント方法やストロークの結合方法、およびパスポイントを簡単かつ再編集可能な方法のロックを解除します。

  ![パスポイントが移動され、指先エフェクトが更新されていることを示すGid](../assets/v90_path_smudge.gif)

* <b>パスのプロパティをプリセットで保存して再利用する</b>\
  パスツールを使用するときに、ブラシのプロパティをプリセットとして保存することもできます。 これにより、ツールプリセットを保存できます。このプリセットは、アセットウィンドウから選択されたときに自動的にパスツールに切り替わります。

>[!NOTE]
>
> 詳細については、[専用ドキュメント](../painting/tool-list/path.md)を参照してください。

### パスに沿ってペイント機能で使用する新しいコンテンツ

パスに沿ってペイントの新機能を利用するために、このバージョンにはいくつかの新しいツールプリセットが含まれています。

* パイプラックSf
* ひだ
* シーム
* 上塗り

* ジッパーテープ

### パスに沿ってペイント機能の動的ストロークが改善されました

![丸いシェイプを始点とし、矢印の先端を終点とする矢印のようなパスストロークを示す画像。](../assets/v90_banner_dyn_strokes.jpg)

新しいパスツールを機に、ダイナミックストロークシステムに新しいプロパティを追加しました。 これらの新しいプロパティは、前には不可能だった新しい種類のストロークをロック解除します。上の画像の矢印は、異なる開始と終了の視覚的な特徴があります。

* <b>新しい開始/中間/終了プロパティ</b>\
  ストローク内のスタンプが最初のスタンプ、最後のスタンプ、または中間のスタンプの場合は、Substanceグラフを指定するように新しいプロパティを定義できます。 これにより、開始点と終了点を作成でき、例えばジッパーを作成する場合などに非常に便利です。 （<b>注意</b>：終了状態はパスツールでのみ使用できます。）
* <b>新しいサイズと間隔のプロパティ</b>\
  「サイズ」プロパティと「間隔」プロパティを使用すると、現在のスタンプのステートに基づいてSubstanceグラフの出力を調整できます。
* <b>新しいストロークの長さのプロパティ</b>\
  パスに沿った距離とパスの最大距離を指定すると、エフェクトが繰り返される場合に、正規化された値を直接指定するよりも、より適切に制御できます。\
  例えば伸びていく線も、描いた距離（スタンプ総数ではなく）に基づいた繰り返しパターンの線も作ることが可能です。

![ダイナミックな線のパスを示しているGif](../assets/v90_path_dyn_stroke_wave_demo.gif)

>[!NOTE]
>
> 詳細については、[専用ドキュメント](../painting/dynamic-strokes/creating-custom-dynamic-strokes.md)を参照してください。

### 更新されたデフォルトのマテリアル

![左右に並べて表示された球を一覧表示して、さまざまな新しいマテリアルを紹介します](../assets/v90_banner_materials.jpg)

このリリースでは、ライブラリのクリーンアップを少し行うことにしました。そのため、すべてのユーザーが使いやすくするために、デフォルトのベースマテリアルを変更しました。 これらのマテリアルは、[Substance 3D Assets](https://substance3d.adobe.com/assets)にコンテンツを提供する同じチームによって作成されています。

>[!NOTE]
>
> 削除されたコンテンツは、[Substance 3Dコミュニティアセット](https://substance3d.adobe.com/community-assets?q=painter23update&u=painter23update)で利用できます。
