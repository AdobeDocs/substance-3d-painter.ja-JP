# プラグイン

Substance 3D Painterには専用のスクリプトAPIがあり、カスタムプラグインを作成して、カスタムの機能とビヘイビアーを追加できます。\
プラグインはJavascriptで記述されており、QML言語と組み合わせて、アプリケーション内にカスタムインターフェイスを作成できます。 APIで使用できる機能について詳しくは、スクリプトのドキュメント（アプリケーションのヘルプメニューから入手できます）を参照してください。

## デフォルトのプラグイン

Substance 3D Painterには、異なる表示を行う2つのデフォルトのプラグインがあります。

* [自動保存](autosave.md)
* [Resources Updater](resources-updater.md)
