# アウトラインをマスク

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

<b>イン:</b>エフェクト/フィルター、グレースケール、マスク

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

マスクアウトラインフィルターは、マスクのエッジからアウトラインを作成します。

テクスチャレイヤーまたはマスクの内側（白黒出力）で使用し、マスクされたシェイプの周囲に内側、外側、またはダブルアウトラインを生成します。

</td>
</tr>
</table>

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>マスクの位置：</b> | アウトラインをマスクのエッジの外側、内側、または両側に表示するかどうかを選択します。 |
| <b>黒から開始：</b> | アウトラインが黒から始まるかどうかを切り替えます。 これは一種の反転トグルとして効果的に機能します。 |
| <b>しきい値：</b> | マスクのエッジの検出に使用するしきい値を調整します。 |
| <b>幅：</b> | アウトラインの幅を調整します。 |
| <b>ぼかし：</b> | アウトラインに適用されるぼかしを調整します。 |
| <b>曲線の形状：</b> | アウトラインのフォールオフのシェイプを調整します。 |
