# ヒストグラムスキャン

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

<b>イン:</b>エフェクト/グレースケール

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

ヒストグラムスキャンフィルターは、入力グレースケールイメージのコントラストと明るさをリマップします。

コントラストと明るさを調整するには、塗りつぶしレイヤー上またはマスク（白黒出力）上で直接使用します。

</tr>

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>位置：</b> | ヒストグラムの位置を調整します。 |
| <b>コントラスト：</b> | 結果のコントラスト/フォールオフを調整します。 |
| <b>位置の反転：</b> | 位置の反転を切り替えます。 位置の値が非常に高い、または非常に低い場合は、出力が効果的に反転します。 |
