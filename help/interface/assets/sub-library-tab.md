# 「サブライブラリ」タブ

サブライブラリは、特定の検索専用のSubstance 3D Painterの新しいタブまたはウィンドウです。\
デフォルトで開いているサブライブラリタブはなく、メインアセットウィンドウのみが開いています。 サブライブラリタブは、メインの「アセット」ウィンドウから2つの方法で作成できます。

* 保存された検索の1つを&#x200B;**右クリック**&#x200B;し、**新しいタブの作成**&#x200B;を選択します。

![](../../assets/08-01-sublibrary.jpg)

* **検索クエリ**&#x200B;を選択または入力し（アセットの種類、パンくず、テキストクエリ、またはパスでフィルター）、[アセット]ウィンドウの下部にある専用の&#x200B;**ボタン**&#x200B;を使用します。

![](../../assets/08-02-sublibrary.jpg)

サブライブラリを作成すると、新しいタブが自動的に作成され、メインのアセットウィンドウと同じスペースのインターフェイスに&#x200B;**ドッキング**&#x200B;されます。

そこから、サブライブラリウィンドウは他の場所にドッキングすることも、インターフェイス内や別の画面上でフローティング状態にしておくこともできます。

>[!NOTE]
>
> * サブライブラリには、メインアセットウィンドウと同じ機能がありますが、リセットすると元の検索クエリに戻ります。
> * メインアセットウィンドウとは異なり、サブライブラリを閉じた場合は、再作成する必要があります。
> * 保存された検索が削除された場合、サブライブラリウィンドウは閉じられるまで存在し続けます。
