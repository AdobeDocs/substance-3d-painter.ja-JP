# 出力テンプレート

![](../../assets/preset-list.png)

Substance 3D Painterには、書き出しプロセスの動作を制御するために使用できる2種類の出力テンプレートがあります。

* [既定の出力テンプレート](default-presets.md)は、特定の3Dアプリケーションまたはワークフローで動作するように設計されており、<b>書き出しウィンドウ</b>の<b>出力テンプレートタブ</b>で使用できます。 デフォルトのテンプレートを複製して変更したり、独自のテンプレートを最初から作成したりできます。
* [定義済みの出力テンプレート](../../export/export-presets/predefined-presets/predefined-presets.md)は変更できません。 定義済みのテンプレートは、<b>書き出しウィンドウ</b>の<b>設定タブ</b>にある<b>出力テンプレートドロップダウンリスト</b>の上部に表示されます。
