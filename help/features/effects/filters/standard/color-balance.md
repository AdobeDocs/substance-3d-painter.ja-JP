## 説明

カラーバランスフィルターでは、ハイライト、中間調、シャドウをわずかに変更できます。

塗りつぶしレイヤーで使用して、微妙なカラー調整を行います。

## パラメーター

### ハイライト

| パラメーター名 | 説明 |
| --- | --- |
| **シアン&lt;->赤：** | カラーをシアンまたはレッド側にシフトします。 |
| **マゼンタ&lt;->グリーン：** | カラーをマゼンタまたはグリーン側に動かします。 |
| **黄&lt;->青：** | カラーをイエローまたはブルー側にシフトします。 |

### 中間調

| パラメーター名 | 説明 |
| --- | --- |
| **シアン&lt;->赤：** | カラーをシアンまたはレッド側にシフトします。 |
| **マゼンタ&lt;->グリーン：** | カラーをマゼンタまたはグリーン側に動かします。 |
| **黄&lt;->青：** | カラーをイエローまたはブルー側にシフトします。 |

### シャドウ

| パラメーター名 | 説明 |
| --- | --- |
| **シアン&lt;->赤：** | カラーをシアンまたはレッド側にシフトします。 |
| **マゼンタ&lt;->グリーン：** | カラーをマゼンタまたはグリーン側に動かします。 |
| **黄&lt;->青：** | カラーをイエローまたはブルー側にシフトします。 |
