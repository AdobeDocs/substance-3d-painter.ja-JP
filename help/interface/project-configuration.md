# プロジェクト設定

![](../assets/project-configuration-full.png)

「プロジェクト構成」ウィンドウには、プロジェクト設定を変更するためのコントロールがあります。 通常、プロジェクト設定は新規プロジェクトの作成時に設定されますが、これらの設定の変更はプロジェクトの後半で必要になる場合があります。

## 3D メッシュ

データまたはメッシュファイルに変更が加えられた場合は、他のプロジェクト3D メッシュを保持したままメッシュを再読み込みできます。 **メッシュの再読み込み**&#x200B;をオンにし、正しいファイルが読み込まれていることを確認してください。

多くの場合、メッシュの再読み込みは次のような場合に便利です。

* 3Dモデルトポロジを更新する
* UVを更新する
* [テクスチャセット](texture-set/texture-set.md)を追加または削除

| **パラメーター** | **説明** |
| --- | --- |
| **3D メッシュ** | 3Dモデルファイルへのパスを示します。 **選択ボタン**&#x200B;を使用して、プロジェクトのソースファイルを変更します。 |
| **メッシュの再読み込み** | 有効にすると、インターフェイスの下部にある「OK」をクリックしたときにメッシュファイルが再インポートされます。 元のメッシュファイルと異なるメッシュファイルを指定するために「選択」ボタンを使用した場合、このパラメーターは自動的にチェックされます。 |

>[!NOTE]
>
> プロジェクトメッシュを再読み込みするときにマテリアルIDが変更されたり名前が変更されると、プロジェクトの以前のテクスチャセットが無効になり、テクスチャが見つからないように見える場合があります。 この問題は、**テクスチャセットリスト**&#x200B;の[再割り当てウィンドウ](texture-set/texture-set-reassignment.md)で修正できます。

## UV タイル設定

このセクションには、プロジェクトでのUDIMの使用を切り替えるコントロールがあります。 プロジェクトの作成後にこれらの設定を変更することはできませんが、ここでプロジェクトの設定を表示することができます。 詳細については、[UV タイルのドキュメント](../features/uv-tiles/uv-tiles.md)を参照してください。

## 読み込み設定

次の設定は、選択したメッシュの読み込み方法を制御します。

| *設定* | *説明* |
| --- | --- |
| **カメラの読み込み** | 有効にすると、メッシュファイルに存在するカメラも読み込まれ、3D ビューポートで使用できるようになります。 |
| **メッシュ上のストロークの位置を保持する** | この設定は、新しい3D メッシュの読み込み後にブラシストロークが再計算される方法を制御します。 ほとんどの場合、この設定を有効にしておくことをお勧めします。 詳細については、[UV再投影](../features/uv-reprojection.md)のドキュメントを参照してください。 |
| **自動ラップ解除** | 自動ラップ解除。 「オプション」ボタンをクリックして、プロセスを設定します。 詳細については、[UVの自動ラップ解除に関するドキュメント](../features/automatic-uv-unwrapping.md)を参照してください。 |

### 物理サイズ設定

読み込んだメッシュの[物理サイズ](../features/physical-size.md)を調整します。

| *設定* | *説明* |
| --- | --- |
| **メッシュファイルの内部単位尺度を使用** | メッシュが物理的に正確な測定値で作成されている場合、Painterで同じ物理サイズを保つためにこれを選択したままにします。 |
| **カスタムの単位尺度** | 物理サイズを考慮してメッシュが作成されていない場合は、このオプションを使用してメッシュのサイズをカスタマイズします。 この値を決定するには、目的の物理サイズと読み込まれたメッシュのサイズを知っている必要があります。 |
| **マテリアルを割り当てるときに塗りつぶしレイヤーの拡大/縮小を物理サイズに切り替える** | 有効にすると、物理サイズプロパティを持つマテリアルを割り当てる際に、塗りつぶしレイヤーとエフェクトが自動的にスケール方式を物理サイズに切り替えます。 |

### カラーマネジメント設定

このセクションでは、色の変換方法に関する設定をコントロールします。 詳細については、[カラーマネジメント](../features/color-management/color-management.md)のドキュメントを参照してください。
