# マスクビルダー

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_mask_builder_dark.png" alt=""/><strong>内部：</strong>マスク、ジェネレータ</td>
    <td style="border: 0;" valign="top"><strong>説明</strong><br>マスクビルダジェネレータは、従来のバージョンのマスクエディタジェネレータです。 これは、経年劣化、AO、曲率、グラデーション、ワールド空間法線、Scratches、散乱、マイクロディテールを1つのマスクに結合できる多目的マスクジェネレータです。<br><br>マスクビルダジェネレータは非常に柔軟ですが、複雑なため、ほとんどのジェネレータよりもパフォーマンスに影響を与える可能性があります。<br><br>マスクビルダジェネレータは、白黒テクスチャを出力します。 したがって、様々なベイク済みマップに基づいてマスクを作成する場合に便利です。 <br><br>イメージ入力には、ベイク処理された位置、曲率、環境オクルージョン、およびワールド空間の法線マップが必要です。 <a href="../../../baking/baking.md">ベーキングの詳細については、こちらを参照してください</a>。</td>
  </tr>
</table>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| **ワールド空間の標準**&#x200B;色 | ベイクワールド空間法線マップを使用します。 |
| **カスタム経年劣化 1**&#x200B;グレースケール | カスタムテクスチャまたはアンカーポイントを使用します。 |
| **カスタム経年劣化 2**&#x200B;グレースケール | カスタムテクスチャまたはアンカーポイントを使用します。 |
| **散乱入力**&#x200B;グレースケール | カスタムテクスチャまたはアンカーポイントを使用します。 |
| **位置**&#x200B;の色 | ベイク処理された位置マップを使用します。 |
| **曲線**&#x200B;グレースケール | ベイク処理された曲率マップを使用します。 |
| **環境オクルージョン**&#x200B;グレースケール | ベイク処理されたアンビエントオクルージョンマップを使用します。 |
| **マイクロ法線**&#x200B;カラー | カスタムの法線テクスチャまたはアンカーポイントを使用します。 |
| **マイクロHeight**&#x200B;の色 | カスタムテクスチャまたはアンカーポイントを使用します。 |

### 汚れ

| パラメーター名 | 説明 |
| --- | --- |
| **スケール** | 経年劣化テクスチャのサイズを調整します。 |
| **カスタム経年劣化を使用する** | カスタム経年劣化マップの使用のオンとオフを切り替えます。 これは、カスタム経年劣化の表示のみである1。 カスタム経年劣化 2の表示を制御するには、「セカンダリのカスタム経年劣化」スライダーを調整します。 |
| **セカンダリカスタム経年劣化** | カスタム経年劣化 2テクスチャの表示/非表示を調整します。 |
| **反転** | 経年劣化マップを反転します。 |

### アンビエントオクルージョン

| パラメーター名 | 説明 |
| --- | --- |
| **範囲** | AOマスクの範囲を調整します。 |
| **コントラスト** | AOマスクのコントラスト/フォールオフを調整します。 |
| **騒々しさ** | AOの結果にノイズを加えて、マスクの明るさを効果的に下げます。 |
| **反転** | AOマスクを反転します。 |

### 曲率

| パラメーター名 | 説明 |
| --- | --- |
| **凸型範囲** | マスクでハイライト表示するのに必要な最小凸角度を調整します。 |
| **凸型コントラスト** | 凸状マスクのコントラストを調整します。 |
| **凸型反転** | 凸状マスクを反転します。 |
| **凹型範囲** | マスクでハイライトする凹形の最小角度を調整します。 |
| **凹型コントラスト** | 凹面マスクのコントラストを調整します。 |
| **凹型の反転** | 凹状マスクを反転します。 |
| **Smoothness** | 曲線マスクの明るい領域と暗い領域のブレンドを調整します。 |
| **レベルブースト** | これを使用して、マスクされた領域の範囲を拡大します。 これは、**凸型範囲**&#x200B;と&#x200B;**凹型範囲**&#x200B;パラメーターの乗数のように機能します。 |
| **騒々しさ** | 湾曲結果にノイズを追加して、マスクの明るさを効果的に下げます。 |

### グラデーション

グラデーションの位置は、[シーン全体]または[マテリアル単位]の正規化スケールでベイク処理できる位置マップに基づいています。 マテリアルがシーンの小さな領域に表示されるだけで、位置マップが完全なシーン正規化スケールでベイク処理されている場合は、目的の結果を得るためにグラデーション範囲を調整するのが難しいことがあります。

| パラメーター名 | 説明 |
| --- | --- |
| **範囲** | グラデーション範囲を調整します。 |
| **コントラスト** | グラデーションのコントラストを微調整します。 |
| **反転** | グラデーションを反転します。 |

### ワールド空間法線

**前面**、**背面**、**左**、および&#x200B;**右**&#x200B;の値は、メッシュの前面、背面、左、右側と対応していない場合があります。 既定では、**前面**&#x200B;は正のX軸に対応し、右面は正のZ軸に対応します。

| パラメーター名 | 説明 |
| --- | --- |
| **最高の適用度** | 上から下へのグラデーションの範囲（適用度）を調整します。 |
| **下の適用度** | ボトムアップグラデーションの範囲（強度）を調整します。 |
| **フロントの照度** | 前後のグラデーションの範囲（強度）を調整します。 |
| **戻る強さ** | 後方前方グラデーションの範囲（強度）を調整します。 |
| **右の照度** | 右左グラデーションの範囲（適用度）を調整します。 |
| **左方向の強さ** | 左右のグラデーションの範囲（適用度）を調整します。 |

### スクラッチ

| パラメーター名 | 説明 |
| --- | --- |
| **金額** | スクラッチの密度を調整します。 |
| **スケール** | スクラッチのサイズを調整します。 |

### 散布図

| パラメーター名 | 説明 |
| --- | --- |
| **スケール** | 散乱効果のサイズを調整します。 高いスケールを指定するほどスタンプの数が多くなり、小さいスケールを指定するほどスタンプのサイズが大きくなり、見えにくくなります。 |
| **密度** | 散布スタンプの数を調整します。 |
| **サイズ** | 散布スタンプのサイズを調整します。 |
| **サイズのバリエーション** | 散布スタンプの各インスタンスのサイズにランダム度がどれだけ存在するかを調整します。 サイズの変動を大きくすると、スタンプのサイズがランダムに減少します。したがって、サイズの変動を大きくすると、同じ平均サイズを維持するためにサイズの値を大きくする必要が生じる場合があります。 |
| **不透明度のバリエーション** | 散布スタンプの各インスタンスの不透明度にランダム度をどの程度追加するかを調整します。 |
