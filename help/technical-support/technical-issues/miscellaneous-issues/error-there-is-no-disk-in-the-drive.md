# ドライブにディスクがありません。

Windowsでは、次のエラーが発生することがあります。

「ドライブにディスクがありません。 ドライブXにディスクを挿入してください。」

![](../../../assets/disk-drive-error.png)

このエラーを取り除くには、いくつかのチェック項目があります。

* ドライブ文字の設定が正しいことを確認してください（<https://support.microsoft.com/en-us/kb/330137>を参照）
* Substance 3D Painterで使用されている以前の場所（「最近使用したファイル」など）が有効であることを確認します
