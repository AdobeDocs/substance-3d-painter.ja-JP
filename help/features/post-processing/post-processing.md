# 後処理

![](../../assets/v12_banner_post_effects2.jpg)

ポストエフェクトはフィルターであり、Substance 3D Painterのビューポートにレンダリングされたイメージに適用して、一般的なカメラエフェクトをシミュレートすることができます。

Post-effectsは、[ディスプレイ設定](../../interface/display-settings/display-settings.md)ウィンドウを使用して、任意のプロジェクトでアクティブにできます。

>[!NOTE]
>
> これらのPostエフェクトは、便宜上、2Dビューには適用されません。 効果を適用したイメージ結果は、3Dビューでのみ表示されます。

以下のページでは、現在サポートされている様々なポストプロセスエフェクトについて説明します。

* [被写界深度](depth-of-field.md)
* [ブルーム](bloom.md)
* [グレア](glare.md)
* [レンズフレア](lens-flare.md)
* [横収差](lateral-aberration.md)
* [周辺光量補正](vignette.md)
* [シャープ](sharpen.md)
* [粒状フィルム](film-grain.md)
* [トーンマッピング](tone-mapping.md)
* [カラー補正](color-correction.md)

ルックアップテクスチャテーブルを使用して、最終的なイメージ結果を微調整することもできます。 詳しくは、[カラープロファイル](color-profile.md)のドキュメントを参照してください。
