# ベベルスムーズ

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![ベベルスムーズアイコン](./Resources/icon_bevel_smooth.png "ベベルスムーズ")

<b>イン:</b>効果/ベベル、スムーズ、距離、グレースケール

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

ベベルスムーズフィルターは、マスクの境界線から外側、内側、またはその両方にグラデーションを作成します。

テクスチャレイヤー上またはマスク内（白黒出力）で使用し、マスクのエッジから滑らかなベベルグラデーションを作成します。

</td>
</tr>
</table>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| <b>距離マップ:</b>グレースケール | カスタムテクスチャまたはアンカーポイントを使用します。 |

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>方向：</b> | マスクの境界線の、拡張する側を選択します。 |
| <b>距離：</b> | ベベル拡張の間隔を調整します。 |
| <b>滑らかさ：</b> | マスクに適用されるスムージングの強度を調整します。 |
| <b>曲線オフセット:</b> | マスクの境界線を内側または外側に調整します。 |
| <b>曲線の形状：</b> | ベベル勾配でピンチしたカーブを使用するか、丸みを帯びたカーブを使用するかを選択します。 |
| <b>マスクのしきい値：</b> | 入力からマスクの境界線を検出するために使用する値を調整します。 |
| <b>距離マップ乗数：</b> | 最大距離に対する距離マップの影響を調整します。 |
| <b>ベベルラップ：</b> | ベベルタイルを水平および垂直に並べるかどうかを切り替えます。 |
