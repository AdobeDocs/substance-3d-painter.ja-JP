# バージョン2.2

**Substance Painter 2.2**&#x200B;は、動的マテリアルレイヤリングである新しいワークフローを追加します。

リリース日： *21 July 2016*

## 主な機能

### 新しい動的マテリアルレイヤリングワークフロー

![](../../assets/dynamic-material-blending-materials-preview.jpg)

この新しいバージョンでは、**マテリアルレイヤー**&#x200B;と呼ばれる新しい&#x200B;**ワークフロー**&#x200B;を追加します。 従来のテクスチャリングワークフローでは、**高解像度**&#x200B;で&#x200B;**ディテールを保持**&#x200B;するテクスチャを作成する必要がありますが、ユースケースについては&#x200B;**不便**&#x200B;です。 より興味深いアプローチは、**小さな耕耘物質を作成**&#x200B;して、**シェーダ内で繰り返す**&#x200B;ことです。 このシェーダ&#x200B;**を使用すると、特定の画質を維持し、ディテールを失うことなく**&#x200B;オブジェクトに&#x200B;**ズームして近づける**&#x200B;機能を利用できます。 唯一の問題は、最終結果をプレビューするために、以前は最終シェーダを表示するゲームエンジン/レンダラーに移動する必要があったことです。 この新しいバージョンでは、Substance Painter内で同様のシェーダを使用できるようになりました。これにより、**最終結果を視覚化すると同時にペイント**&#x200B;できます。

「**FireHydrant**」という名前の&#x200B;**新しいサンプルプロジェクト**&#x200B;が、新しいワークフローを紹介するために追加されました。

![](../../assets/layer-stacks.png)

この新しいワークフローでは、次の2つの方法を使用できます。

* マテリアルはシェーダで定義されます。マスクをペイントしてブレンドすることしかできません
* マテリアルとマスクは一緒にペイントできます

いずれの場合も、毎回新しいレイヤースタックを定義することで、マスクとマテリアルの作成時により多くの自由度を与えることができます。 レイヤの管理ははるかに簡単になり、各スタックには、最終的なシェーダでブレンドできる固有のチャンネルのセットを含めることができます。\
また、Shareで利用可能なUnity 5とUnreal Engine 4用の特別なシェーダもあります。

* [Unity 5](https://share.allegorithmic.com/libraries/2126)
* [Unreal Engine 4](https://share.allegorithmic.com/libraries/2125)

詳細については、ドキュメントの専用ページを参照してください： [動的マテリアルレイヤリング](../../features/dynamic-material-layering.md)

### 新しいミニシェルフ検索フィールド

![](../../assets/mini-shelf-search.gif)

## リリースノート

### 2.2.0

（2016年7月21日リリース）

**追加：**

* [Shelf]検索システムとクエリの改善
* [シェルフ]ミニシェルフの検索フィールドを追加する
* [シェーダ]スライダのステップ精度を定義できます
* [シェーダ]シェーダパラメータに[元に戻す/やり直し]ボタンを追加する
* [シェーダ]シェーダをリロードしても、パラメータはリセットされません
* [MatLayering] 動的マテリアルレイヤリングとサブスタックのサポートを追加
* [MatLayering] JSONファイルを読み込んでシェーダ設定を設定できるようにします
* [MatLayering]テクスチャサンプラの制限を解除します（[Binless]テクスチャに切り替えます）。
* [スクリプト]ベーカーの設定を許可し、計算を開始します
* [Substance]IDの他に入力/出力コネクションにも「使用法」を使用します
* [ツール]投影ツールのプレビューチャンネルをビューポートで選択できるようにします

**修正済み：**

* 物質が間違ったフォルダーに配置されている場合に起動時にクラッシュする
* ログファイルが正しくないためにクラッシュレポートが機能しない場合がある
* [Iray] Irayを一時停止してもPostエフェクトが更新されない
* [Iray]自動フォーカスショートカットが機能しない
* [Iray]アセットサイズに応じて絞りスライダーの動作が変わる
* [レイヤ]最初のマテリアルチャンネルがすべて無効になっている場合、既定値では有効になりません
* [シェーダ] 「パラメータauto」が正しくない場合、エラーは出力されません

**既知の問題：**

* [Mac]テクスチャサンプルの制限が16でロックされる（GPUドライバーの問題）
