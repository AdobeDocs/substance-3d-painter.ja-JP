# バージョン2019.2

**Substance Painter 2019.2**&#x200B;は、パン屋さんに新しい強力な機能をもたらし、シェルフに新しいスマートマテリアルとスマートマスクのセットを提供します。

リリース日： *25 July 2019*

## 主な機能

### ベイカーのワークフローの改善

![](../../assets/header-image-vizu.jpg)

このリリースでは、ベイク処理のワークフローが改善され、いくつかの新機能が追加されました。 これらの機能強化により、Substance Painterを使用した日常業務が高速化され、容易になります。

* **ベーキングプロセスの視覚化**\
  この新しいバージョンでは、デフォルトでベイク処理がビューポートに表示されます。 これにより、ベーカーの結果をリアルタイムでプレビューし、必要に応じてプロセスの終了を待たずにキャンセルして、より迅速な反復を提供できます。 この動作は、メイン設定で、「**ベイク処理オプション**」セクションの「**ライブプレビューのベイク処理を有効にする**」設定のチェックを外すと無効にできます。

  ![](../../assets/baking-options-v2.png)

  ![](../../assets/bake-process.gif){width="500px"}
* **ベーキングダイアログを改善**\
  ベイク処理ダイアログが修正され、現在のベイク処理のステータスが改善されました。 計算されるテクスチャの数を示すカウンタと、ベイカーごとの明示的なリスト、および計算対象のテクスチャセットが表示されるようになりました。 エラーが発生した場合は、パン屋の名前の横に赤い十字が表示されます。 プロセスの最後に、新しいボタンをクリックすると、ログウィンドウをすばやく開いて問題の詳細を確認できます。\
  ![](../../assets/baking-dialog.png)
* **進行中のベイク処理を取り消しています**&#x200B;ベイク処理でアプリケーションがロックされなくなりました。 Substance Painterの応答性が向上しました。つまり、現在進行中のベイク処理は、終了するのを待つことなくキャンセルできます。 ただし、キャンセルはすぐに行われるものではなく、有効になるまでに数秒かかる場合があります。 これは、内部的にはベイク処理がチャンク内のテクスチャで機能し、チャンクの計算中に停止できないためです。 ベイク処理をキャンセルすると、ベイクウィンドウが自動的に再び開きます。\
  ![](../../assets/baking-cancel-optim.gif)

### ベーカーのパフォーマンスの向上

![](../../assets/header-image-baker.jpg)

ワークフローの改善に伴い、ベイカーの更新やパフォーマンスの向上も行いました。 また、DXRとOptixのサポートを追加し、従来よりもはるかに高速にベイク処理できるGPU レイトレーシングを実現しました。 ただし、GPU レイトレーシングは環境オクルージョンとThicknessベイカーにのみ影響します。

* **CPUレイトレーシングが改善されました**\
  CPU上のレイトレーシング計算は、以前よりも2～3倍高速になりました。 そのため、GPUがGPU レイトレーシングと互換性がない場合でも、一般的なパフォーマンスは向上します。
* **DXRおよびOptixでのGPU レイトレーシングのサポート**\
  互換性のあるハードウェアを使用して、ベイカーはGPU上で直接計算を行うことができるようになりました。これにより、特にアンチエイリアスが有効で大量の光線が定義されている場合に、計算時間が大幅に短縮されます。 DXRがデフォルトで選択されている場合、それ以外の場合はOptixが使用されます。 [メイン設定](../../interface/settings/settings.md)に移動して「**ベイク処理オプション**」を探すと、GPU レイトレーシングを無効にできます。

  ![](../../assets/baking-options-v2.png)

>[!NOTE]
>
> GPU レイトレーシング機能を有効にするには、次のドライバーに更新してください： **Nvidiaドライバー430.86**。\
> DXRは、RTX GPUおよび[GeForce GTX 10xx GPU](https://www.nvidia.com/en-us/geforce/news/geforce-gtx-dxr-ray-tracing-available-now/)で使用できます。 また、DXRを使用するには、Windows 10が最新の状態になっている必要があります（バージョン1809）。詳細については、このページを参照してください。

>[!WARNING]
>
> GPU レイトレーシングを使用する場合、高ポリゴンメッシュがVRamに収まらない場合、ベイカーが失敗することがあります。 このような場合は、[メイン設定](../../interface/settings/settings.md)に移動し、「**ベイクオプション**」セクションの「**GPU レイトレーシング**」設定を無効にすることをお勧めします。 その後、単にベーキングプロセスを再起動することができます。

### さまざまな新機能と改善点

![](../../assets/header-image-misc.jpg)

このリリースでは、Substance Painter内のQOLを向上させるために、いくつかの機能も追加および修正しました。

* **回転マニピュレータの改善**\
  これまで回転マニピュレータは少し遅かったため、回転を実行するのは面倒なことがありました。 カメラとシーンサイズに回転速度がリンクされるようになりました。
* **ビューポートのダウンスケールにより、高DPI画面のパフォーマンスが向上しました**\
  [メイン設定](../../interface/settings/settings.md)に、値「**なし**」および「**自動**」（デフォルト）を持つ「ビューポートのスケーリング」という名前の新しいパラメーターがあります。 画面がHDPIスケール（MacOSのRetinaスクリーンなど）を使用していることをSubstance Painterが検出した場合、ビューポート解像度が2で自動的に割られます。 この動作により、ビューポートの描画が大きくなりすぎるのを防ぎ、品質を著しく低下させることなく、一般的なパフォーマンスを向上させることができます。

  ![](../../assets/settings-viewport-downscale.png)
* **スクリプト用の新しいコンソールプラグイン**\
  スクリプトAPIから簡単にコマンドを実行するための新しいプラグインを作成しました。 Githubで使用可能です： <https://github.com/AllegorithmicSAS/painter-plugin-console>。 コンソールはオートコンプリートもサポートしています。

  ![](../../assets/console-plugin.png)
