# 繊維ガラスEdge Wear

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_fiber_glass_edge_wear.webp" alt=""/><br><strong>内部：</strong>マスク、ジェネレータ</td>
    <td style="border: 0;" valign="top"><strong>説明</strong><br>ファイバーグラスEdge Wearジェネレーターは、ベイク処理された曲率マップと周囲オクルージョンマップに基づいて、リアルなファイバーグラスのエッジ摩耗とほつれなどのディテールを追加します。 詳細については、マイクロHeightマップとマイクロ法線マップを使用することもできます。<br><br>ファイバーグラスEdge Wearジェネレーターは、白黒テクスチャを出力します。 したがって、マスクを生成してファイバーガラスのエッジの摩耗のディテールをレイヤーに追加すると便利です。<br><br>イメージ入力には、ベイク処理された位置、曲率、環境オクルージョン、およびワールド空間の法線マップが必要です。 <a href="../../../baking/baking.md">ベーキングの詳細については、こちらを参照してください</a>。</td>
  </tr>
</table>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| **カスタム経年劣化**&#x200B;グレースケール | カスタムテクスチャまたはアンカーポイントを使用します。 |
| **曲線**&#x200B;グレースケール | ベイク処理された曲率マップを使用します。 |
| **環境オクルージョン**&#x200B;グレースケール | ベイク処理されたアンビエントオクルージョンマップを使用します。 |
| **ワールド空間の標準**&#x200B;色 | ベイクワールド空間法線マップを使用します。 |
| **位置**&#x200B;の色 | ベイク処理された位置マップを使用します。 |
| **マイクロ法線**&#x200B;カラー | カスタムの法線テクスチャまたはアンカーポイントを使用します。 |
| **マイクロHeight**&#x200B;の色 | カスタムテクスチャまたはアンカーポイントを使用します。 |

## パラメーター

<table>
  <tr>
    <th>パラメーター名</th>
    <th>説明</th>
  </tr>
  <tr>
    <td><strong>シード</strong></td>
    <td>Dirtテクスチャの作成に使用するシード値を設定します。 <br><ul><li>別のランダムシードに切り替えるには、「ランダム」をクリックします。</li><li>鉛筆をクリックして現在のシード値を表示し、必要に応じて特定の値を入力します。</li></ul></td>
  </tr>
  <tr>
    <td><strong>反転</strong></td>
    <td>特定の内部マップ（曲率、AOなど）を反転してから、最終的なマスクに結合します。</td>
  </tr>
  <tr>
    <td><strong>摩耗レベル</strong></td>
    <td>ジェネレータ効果の総摩耗量と全体的な可視性を調整します。</td>
  </tr>
  <tr>
    <td><strong>摩耗コントラスト</strong></td>
    <td>最終的な摩耗結果のコントラストを調整します。</td>
  </tr>
  <tr>
    <td><strong>Triplanar を使用</strong></td>
    <td><strong>[三角形を使用] </strong>が有効な場合、テクスチャはUVのみに依存するのではなく、3方向（X、Y、Z軸）から投影されます。 <br><ul><li>Triplanarを有効にしていない場合、テクスチャはUVレイアウトに従います。</li><li>三角形を有効にすると、テクスチャは複数の角度から投影され、ブレンドされます。</li></ul></td>
  </tr>
  <tr>
    <td><strong>Triplanar の描画コントラスト</strong></td>
    <td>三平面マッピングを使用して、投影時にテクスチャがブレンドされる滑らかさを調整します。 これにより、各方向からの投影間のブレンドの柔らかさが調整されます。</td>
  </tr>
  <tr>
    <td><strong>汚れ量</strong></td>
    <td>経年劣化ディテールの適用度を調整します。</td>
  </tr>
  <tr>
    <td><strong>カスタム汚れを使用</strong></td>
    <td>カスタム経年劣化マップの使用のオンとオフを切り替えます。</td>
  </tr>
  <tr>
    <td><strong>エッジの滑らかさ</strong></td>
    <td>エッジ摩耗効果の柔らかさを調整します。</td>
  </tr>
  <tr>
    <td><strong>アンビエントオクルージョンのマスキング</strong></td>
    <td>アンビエントオクルージョンマップが結果に与える影響を調整します。</td>
  </tr>
  <tr>
    <td><strong>曲率の重み付け</strong></td>
    <td>曲線マップが結果に与える影響を調整します。</td>
  </tr>
</table>

### マイクロ詳細

<table>
  <tr>
    <th>パラメーター名</th>
    <th>説明</th>
  </tr>
  <tr>
    <td><strong>マイクロ高さ</strong></td>
    <td>カスタムマイクロHeightマップの使用のオンとオフを切り替えます。</td>
  </tr>
  <tr>
    <td><strong>マイクロ法線</strong></td>
    <td>カスタムマイクロ法線マップの使用のオン/オフを切り替えます。</td>
  </tr>
  <tr>
    <td><strong>曲率の種類</strong></td>
    <td>曲線の種類を指定します。 <br><ul><li><strong>標準</strong>：通常、非常にシャープな結果が得られますが、詳細の幅が狭くなる場合があります。</li><li><strong>Sobel</strong>: Sobelフィルターを使用して法線マップを評価するため、標準と比較して同様の結果が得られますが、やや不鮮明です。</li><li><strong>滑らか</strong>：情報を累積するために、さまざまなレベルのぼかし（ミップマップなど）を作成します。 これにより通常はより滑らかなカーブになりますが、ディテールが失われる可能性があります。</li></ul></td>
  </tr>
  <tr>
    <td><strong>曲率の強度</strong></td>
    <td>標準モードとソベル曲線モードで曲線の強さを調整します。</td>
  </tr>
  <tr>
    <td><strong>高さの詳細の強度</strong></td>
    <td>マイクロHeightのディテールの量を調整します。</td>
  </tr>
  <tr>
    <td><strong>AO の半径</strong></td>
    <td>周囲オクルージョンの半径（範囲）を微調整します。</td>
  </tr>
  <tr>
    <td><strong>AO 深度</strong></td>
    <td>周囲オクルージョンの深度（強さ）を微調整します。</td>
  </tr>
</table>
