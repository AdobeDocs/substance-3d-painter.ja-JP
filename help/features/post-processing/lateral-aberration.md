# 横収差

![](../../assets/v12_post_aberration.jpg)

カラーチャンネルを画像の中心から外側にシフトして、色収差をシミュレートします。実際のカメラレンズのエッジに見えるカラーフリンジが再現されます。

| <b>パラメーター</b> | <b>説明</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>金額</b> | カラーフリンジエフェクトの適用度を調整します。 値が大きいほど、エッジに向かってチャンネルが明確に分離されます。 |
| <b>半径</b> | 影響を受けない中央領域のサイズを制御します。 値を小さくすると、収差エフェクトが中央に近くなり、画像の大部分に影響します。 |
| <b>柔らかさ</b> | 補正する中心とアブレーションされたエッジ間の変化のSmoothnessを制御します。 |
| <b>比率</b> | 影響を受ける領域の縦横比を設定します。 1を指定すると円形になり、1を超える値を指定すると広い楕円のパターンになります。 |
| <b>中央X</b> | 収差が放射される光学中心の水平位置。 |
| <b>中心Y</b> | 収差が放射される光学中心の垂直位置。 |
| <b>色収差</b> | 収差色を標準の虹から緑と紫のトーンに切り替えます。 |
