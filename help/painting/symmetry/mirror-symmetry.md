# ミラー対称

ミラー対称は軸に基づいた対称で、コンテキストツールバーで有効にできます。

![](../../assets/symmetry-mirror.png)

## マニピュレータを使用して対称軸を配置します

対称の表示設定には、3Dビューの上部にあるコンテキストツールバーの<b>対称設定ボタン</b>からアクセスできます。 表示設定で、マニピュレーターを有効にしてカスタマイズできます。 3Dビューでマニピュレータハンドルをドラッグして、対称軸の位置を変更します。

![](../../assets/MirrorSymmetryManip.png)

## 対称パラメータのミラー

![ミラー対称設定のスクリーンショット](../../assets/MirrorSymmetry-2.png){width="300px"}

| *パラメーター* | *説明* |
| --- | --- |
| <b>軸</b> | 対称の実行に使用するシーンの軸を指定します。 |
| <b>軸の位置</b> | プロジェクト内の軸のオフセットを指定します。 この値は、スライダまたはマニピュレータ（上記を参照）を使用して編集できます。 |
| <b>平面の表示</b> | 有効にすると、ミラー対称の各側面を区切る透明な平面がビューポートに表示されます。 |
| <b>交差点を表示</b> | 有効にすると、ミラー対称の両側を区切る線がビューポートのメッシュに描画されます。 |
| <b>カーソルの表示</b> | 有効にすると、対称の反対側に2番目のカーソルが表示され、ペイントが実行されるタイミングが示されます。 |
| <b>描画中に非表示にする</b> | このオプションを有効にすると、ペイントの実行中（マウスクリックを放すまで）に2番目のカーソルが非表示になります。 |
| <b>マニピュレーターサイズ</b> | ビューポートのマニピュレータのサイズを制御します。 |
