# 環境設定を手動で編集してリソースパスを追加する

アプリケーションを開かずに、カスタムシェルフまたはAssetsパスを追加することができます。

これを行うには、アプリケーションの環境設定を編集する必要があります（これらはプラットフォームごとに異なって保存されます）。 追加された新しいシェルフは、メインの環境設定のシェルフリストに表示されます。 詳細については、次のページを参照してください： [ライブラリ構成](../../../interface/settings/libraries-configuration.md)

>[!NOTE]
>
> ネットワークパスはサポートされていません。問題を回避するには、マウントされたパスを使用してください。 参照： [ネットワークからファイルを読み込んでいます](../../../technical-support/workflow-issues/project-issues/loading-files-from-a-network.md)。
