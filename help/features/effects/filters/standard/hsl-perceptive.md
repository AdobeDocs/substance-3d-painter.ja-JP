## 説明

HSLの知覚的フィルターは、色相、彩度、明度を補正します。

色相、彩度、明度を調整するために、テクスチャレイヤー（カラー）で使用されます。

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>モード：</b> | HSL調整モードを選択します。 **知覚的**&#x200B;では、ユーザーが色をどう認識するかに基づいて値が調整され、**標準**&#x200B;では、コンピューターが内部でどのように色を表現するかに基づいて調整されます。 |
| <b>色相：</b> | 色相を調整します。 |
| <b>彩度：</b> | 彩度を調整します。 |
| <b>明度:</b> | 明度を調整します。 |
