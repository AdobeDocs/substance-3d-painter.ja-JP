# 滑らかさ

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![スムーズステップアイコン](./Resources/icon_smoothstep.png "スムーズステップ")

<b>イン:</b>エフェクト/グレースケール、ステップ

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

スムースステップフィルターは、定義された最小値と最大値に基づいて、一連のグレースケール値を抽出します。 ヒストグラムスキャンと似ていますが、より滑らかな結果を得るために補間します。

しきい値またはヒストグラムスキャンよりも滑らかな変化のグレースケール範囲を切り分けるには、塗りつぶしレイヤー上で直接使用するか、マスク（白黒出力）上で使用します。

</td>
</tr>
