# 用語集

Substance 3D Painterは、多くのテクニックと技術的なキーワードを必要とする3Dアプリケーションで、最初は理解が難しいかもしれません。\
このページでは、アプリケーションで使用される最も一般的なキーワードと、その背後にある概念の簡単な説明を一覧で示します。

| *キーワード* | *定義* |
| --- | --- |
| **整列** | この整列により、ペイント時にブラシが3Dメッシュに向かう方向が決まります。 |
| **Alpha** | アルファは、バーコードやロゴなどの詳細や複雑なシェイプをペイントするために使用できるマスクです。 |
| **ベイク** | ベイク（またはベイク処理）とは、3D メッシュから情報を計算し、メッシュの UV 情報に基づいてテクスチャに保存する操作のことです。 |
| **ビット深度** | ビット深度は、テクスチャに格納できる情報の量です（カラー単位）。 数値が大きいほど、情報の精度が高くなります。 ただし、計算を行う場合は、パフォーマンスが高い数値で低下します。 |
| **ブラシ** | ブラシは、メッシュ上でペイントするためのツールです。 ブラシは、その動作を制御する複数のパラメーター（サイズや不透明度など）によって定義されます。 |
| **カメラ** | カメラは、3Dまたは2Dビューポート内の視点の位置と方向をコントロールできるオブジェクトです。 |
| **チャネル** | チャンネルとは、特定の動作を持つテクスチャです。 マテリアルの色を定義するために使用するチャンネルもあれば、サーフェス上の動作光を制御するために使用するチャンネルもあります。 |
| **複製** | コピースタンプは、ペイントやテクスチャの一部を別の場所に複製するのに使用するツールです。 |
| **コンテンツ/マスク** | 内容とマスクは、レイヤーの2つの主なプロパティを参照しています。 コンテンツは、レイヤーに含まれているチャンネルに保存されている実際のペイントで、マスクはコンテンツの表示と非表示を切り替えるために使用されます。 黒のマスクは、非表示のコンテンツと同じです。 |
| **誤差拡散法** | 拡散は、メッシュのUV アイランドの外側に情報を生成する方法です。 UV アイランドの境界に最も近いピクセルをにじませて、ぼやけたカラーを作ることで機能します。 |
| **拡張/パディング** | 拡散と同じ考え方で、拡張はピクセルの色を拡張することで、UV アイランドの外側に情報を生み出す方法です。 |
| **効果** | エフェクトは、コンテンツまたはマスクのいずれかのレイヤーに追加できる要素です。 Substance 3D Painterは、フィルターなどの様々な種類のエフェクトをサポートしています。 |
| **環境** | 環境は、シーンのライティングの計算に使用されるイメージで、通常は広範囲のカラー情報を表すHDRテクスチャです。 |
| **書き出し** | 書き出しの動作は、アプリケーション内で実現されたペイントから統合されたテクスチャを生成する方法です。 書き出しによって作成されたテクスチャは、他のアプリケーションで使用できます。 |
| **視野/視野** | 視野は、カメラによって観測できる世界の範囲です。 |
| **入力** | 塗りつぶしは、3Dメッシュ全体にカラー、テクスチャ、またはマテリアルを読み込むことができるアクション（効果またはレイヤーにすることができます）です。 |
| **フィルター** | フィルターは、以前の情報を変更できるSubstance効果です。 例えば、ぼかしフィルターは前の画像を柔らかくします。 フィルターはさらに複雑になり、マテリアル全体を変更することもできます。 |
| **フィルター** | フィルタリングとは、3Dビューポート内にテクスチャを表示する方法を指します。 最も一般的には、ニアレスト（ピクセルがそのまま読み取られ、画像が濃淡の寄った画像になる）とバイリニア（ピクセルが補間され、画像が濃淡の寄った画像になる）です。 |
| **GPU** | GPU（グラフィック処理ユニット）は、画像を生成するための迅速な計算を実行するコンピューターの一部です。 |
| **Generator** | Generatorは、通常、新しいテクスチャを基に新しい情報やイメージを生成するSubstanceです。 例えば、一部のマスクジェネレーターでは、ベイク処理されたテクスチャを使用して複雑なマスクを作成します。 |
| **ヒストグラム** | ヒストグラムは、カラー値の分布をグラフで表したものです。 シャドウ、中間調、およびハイライトの間の画像内での色のバランスを視覚化するために使用されます。 |
| **Iray** | Irayは、NVIDIAが作成したパストレーサーレンダラーで、3Dメッシュにリアルなライティングを投影するために使用されます。 これは高度なレンダラーなので、美しいイメージを作成するためのもので、リアルタイムの作業には使用しないでください。 |
| **ジッター** | ジッターはブラシのプロパティで、ペイント時にランダムな動作を生成します。 |
| **レイヤー** | レイヤーは、描画モードや不透明度などの追加のプロパティを持つ複数のチャンネルを含む要素です。 |
| **レイヤースタック** | レイヤースタックは、レイヤーを管理および整理できる場所です。 レイヤーは下から上に編成されます。 一番下のレイヤーが最初に描画され、その上の各レイヤーが重なって追加されます。 |
| **レイジーマウス** | 遅延マウスは、ブラシツールの動作です。 これによりブラシパスの速度が低下し、ペイント時の精度が向上し、マウスカーソルと実際のペイント間に遅延やオフセットが生じました。 |
| **レベル** | レベルは、ヒストグラムを使用して範囲またはカラー/グレースケール情報を制御できるエフェクトです。 これは、カラーの反転や、カラーの暗くする/明るくなどに使用できます。 |
| **ログ** | ログは、ソフトウェアから情報を書き込むテキストファイルで、通常はアプリケーションを実行しているコンピューターに関連しています。 |
| **低/高ポリメッシュ** | 低ポリゴンメッシュと高ポリゴンメッシュは、どちらも3Dメッシュです。1つはポリゴンの密度が低く、もう1つはポリゴンの数が多い（多くの場合100倍の大きさ）メッシュです。 通常、高いメッシュ情報は低いメッシュにベイクダウンされます。 |
| **マテリアル** | マテリアルは、特定の物質を表すプロパティを定義します。 3Dメッシュでは、マテリアルはポリゴンフェースのグループを定義するためにも使用されます。 |
| **メッシュ** | メッシュは、複数の情報で定義された3Dオブジェクトです。 Substance 3D Painterでは、メッシュはポリゴン（通常は三角形）によって定義されます。 メッシュは、 **Blender**&#x200B;や&#x200B;**Autodesk Maya**&#x200B;などの3Dモデリングアプリケーションで作成できます。 |
| **メッシュマップ** | メッシュマップは、メッシュに関連する情報を含むメッシュからベイクされたマップです。 例えば、ポジションやオクルージョンの情報です。 |
| **マップ** | Mip-mapは事前に計算されたテクスチャで、通常は元のテクスチャよりも低い解像度でイメージのシーケンスとして毎回表示されます。 |
| **モード** | モードとは、モードに応じて特定のツールとコントロールのセットにアクセスできるインターフェイスの設定を指します。 |
| **ノイズ** | ノイズは、手続き型のランダムなイメージで、通常、有機的なシェイプとカラー/グレースケール値を表します。 |
| **標準** | 法線は、3Dメッシュのサーフェス上でライトが動作する方法を変形させて、ジオメトリに存在しないディテールをシミュレートする特別なテクスチャです。 |
| **OpenGL / DirectX** | OpenGLおよびDirectXは、2Dおよび3D情報のレンダリングに使用されるアプリケーションプログラミングインターフェイス(API)です。 また、法線マップ形式も定義します。 |
| **直交投影** | 直交投影は、すべての投影線が投影平面に直交する2次元で3次元オブジェクトを表す手段です。 |
| **PBR / PBS** | Physically Based Rendering(PBR)またはPhysically Based Technology(PBS)は、現実世界の光の流れをより正確にモデリングするようにグラフィックのレンダリングを試みるコンピューターグラフィックスのモデルです。 |
| **パッキング** | パッキングとは、複数の画像を 1 つのテクスチャ内に保存するアクションです。 テクスチャは、赤、緑、青のチャンネルが分割されて構成されているため、他のアプリケーションで個別に読み取ることができる異なる情報を格納できます。 |
| **パーティクル** | パーティクルは、物理的なプロパティやその他の複雑な動作に基づいてブラシストロークを生成するツールの一種です。 |
| **遠近法** | 遠近法とは、画面のように平らな面に人間の目が映した、おおよその表現やオブジェクトまたはシーンのことです。 深度とスケールのシミュレーションです。 |
| **ピクセル/テキスト** | ピクセルは画像内のドットで、カラー情報を含む可能な限り最小の要素です。 解像度が高いほど使用可能なピクセルが増え、解像度とディテールが向上します。 テクスチャは、テクスチャ内のピクセルです。 |
| **プラグイン** | プラグインは、ソフトウェアに追加できるプログラミング機能（スクリプトで表現されることが多い）であり、アプリケーションの可能性を広げます。 |
| **後処理** | ポストプロセスは、3Dイメージがレンダリングされた後に画面に適用される視覚効果で、多くの場合、カラー補正やブルームなどの特別な動作をシミュレートします。 |
| **手続き型** | 手続き型とは、一連のパラメータに基づいてコンピュータによって生成されるプロセスを記述する用語です。 数値や複雑な画像などの単純な数学結果です。 |
| **プロジェクション** | 投影とは、特定の視点（カメラなど）から3Dメッシュのサーフェスにイメージ/オブジェクトを適用するアクションです。 |
| **解像度（2の累乗）** | 解像度は、テクスチャのX軸とY軸（または幅とHeight）のサイズを定義します。 しばしば2倍の累乗(2、4、8、16... 512、1024、2048...) これは、GPUでの計算用に最適化されているためです。 |
| **スクリプト** | スクリプトは、特定の動作を実行するために、テキストベースのファイル形式を介して特定のコマンドを実行する行為または使用です。 |
| **シェーダー** | シェーダは、ライト情報を受け取る際のマテリアルの動作を定義します。 一部のシェーダは、トゥーンシェーディングのように単純な場合もあれば、サーフェスのライトの吸収をシミュレートするスキンシェーディングのように高度な場合もあります。 |
| **棚** | シェルフは、複数の種類のリソースが整理されているアプリケーション内の場所です。 単純な画像から複雑なツールに変更できます。 |
| **スマートマスク** | スマートマスクは、スマートマテリアルのように動作しますが、レイヤーではなく、現在の3Dメッシュのみに基づいてマスクを生成するように定義されたエフェクトです。 |
| **スマートマテリアル** | スマートマテリアルは、1 つのファイルとして保存されたレイヤーのグループです。 スマートマテリアルはSubstance 3D Painterの各プロジェクトに適応できるため、現在の3Dメッシュに応じて変化するマテリアルを作成できます。 |
| **指先** | 指先ツールは、カラーをにじませたり、広げたり、混合したりするツールです。 多くの場合、ピクセルをソフトにするために使用されます。 |
| **ステンシル** | ステンシルは、画面に合わせて配置された画像で、カメラ投影で3Dメッシュ上にペイントするために使用されます。 |
| **Substance** | Substanceは、一連のパラメータに基づいてテクスチャを作成できるファイルフォーマットです（パラメータには手続き型の計算が含まれます）。 これらのパラメーターを変更して、バリエーションを作成できます。 |
| **対称** | 対称は、ミラー内の2つの場所で同時にペイントできるツールのオプションです。 |
| **テンプレート** | テンプレートは、新しいプロジェクトを作成するときに使用される定義済みのオプションのセットです。 たとえば、デフォルトの解像度やデフォルトのベイク設定を定義できます。 |
| **テキセル比** | テキセル比とは、UV アイランドのサイズ(2D)とそれに関連する3Dメッシュのジオメトリを比較する規則です。 良好なテキセル比率とは、2Dでジオメトリを均等に展開することを意味します。 これは、3Dメッシュ上でペイント/テクスチャリングの外観と品質の一貫性を維持するために重要です。 |
| **テクスチャ** | テクスチャとは、解像度によって定義された2次元のピクセルを含むファイルです。 ピクセルはグレースケールまたは色付けできます。 色付けされている場合、ピクセルは透明度の情報を持つことができます（ファイル形式でサポートされている場合）。 |
| **テクスチャセット** | Substance 3D Painterでは、テクスチャセットはペイントする特定のUVを持つメッシュの一部を表します。 テクスチャセットは、3Dメッシュの読み込み時に検出された一意のマテリアルに基づいて作成されます。 |
| **ティリング** | タイリングとは、境界で継ぎ目が見えないテクスチャを繰り返すことです。無限の平面をシミュレートすることを目的としています。 例：草または舗装 |
| **ツール** | ツールとは、3Dメッシュとの相互作用を可能にするアクションを指します。このアクションは、ペイントしたりエフェクトを適用したりすることが多いものです。 |
| **ツールバー** | ツールバーには、ツールに対するすべてのアイコンショートカットが表示されます。 |
| **UDIM** | UDIMは、3DメッシュのUVを複数の範囲に分割して、一般的なテクスチャ解像度を上げる方法です。 |
| **UV** | UVは、3Dメッシュ上で定義された情報で、展開してフラットなシェイプにする方法を示します。 この情報は、3Dメッシュにテクスチャを投影するために使用されます。 Substance 3D Painterでは、テクスチャのサイズを表す0 ～ 1の範囲のペイントのみが可能です。 その他の範囲は、UDIMシステムでのみサポートされています。 |
| **VRam** | VRamはGPU（グラフィックカード）のメモリで、計算時に情報とテクスチャを格納するために使用されます。 VRが大きいほど、Substance 3D Painterでの作業が快適になります。 |
| **ビューポート** | ビューポートは、画面上で 3D シーンまたは 2D シーンが表示される場所です。 これは、カメラを制御することによって、ツールや 3D メッシュとの相互作用を可能にする場所でもあります。 |
