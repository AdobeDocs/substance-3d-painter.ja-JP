# メッシュマップ設定

<b>メッシュマップ設定パネル</b>は、ベイクモードで使用でき、メッシュをベイク用に準備するためのコントロールがあります。 特定のマップのメッシュマップ設定を調整するには、<b>メッシュマップベイカーパネル</b>でマップを選択します。 メッシュマップごとに異なる設定を使用できます。 ベイカーパネルの上部に、すべてのメッシュマップが共有する<b>共通の設定</b>のコレクションがあります。

メッシュマップ間で共有されている設定は、個々のメッシュマップーではなく、「共通」ページに表示されます。

## 共通設定

共通メッシュマップページには、すべての設定のベイク方法に影響するコントロールが含まれています。

### 出力設定

| 設定 | 関数 |
| --- | --- |
| 出力サイズ | 生成されるメッシュマップのXおよびY解像度を指定します。 非正方形の解像度を許可するには、ロックをクリックします。 |
| 拡張幅 | ベイクした範囲がUV アイランドの境界線を越える範囲を調整します。 |
| 拡散を適用 | このボックスを有効にすると、生成された拡散のエッジに情報が適用されます。 |

### ハイポリパラメーター

| 設定 | 関数 |
| --- | --- |
| ローポリメッシュをハイポリメッシュとして使用 | この設定を有効にすると、プロジェクトのメッシュに基づいてマップがベイクされます。 |
| ハイポリメッシュ | ハイポリメッシュからプロジェクト内のローポリメッシュに作成するために、プロジェクトにハイポリゴンメッシュを追加します。 複数のメッシュを読み込むことができます。 |
| ケージ | ケージの生成方法を確認します。<ul data-preserve-html="true"> <li data-preserve-html="true">[距離に基づく]: 頂点をメッシュから離れてモデル全体で均一に膨張させて、ケージを作成します。</li> <li data-preserve-html="true">自動（試験的）:Painterは、メッシュを分析し、ケージを自動的に生成します。最適な結果を得るために、交点を作成せずにケージをサーフェスに近づけるようにします。</li> <li data-preserve-html="true">カスタムファイル：ケージとして使用するために作成したファイルを読み込みます。 読み込まれたファイルが正しく動作するには、基本メッシュと同じ数の頂点が必要であることに注意してください。</li> </ul> |
| 背面を無視 | ベイク処理中にバック面を無視するかどうかを切り替えます。 これはアーチファクトを減らすのに役立ちますが、特定のエッジケースではエラーが発生する可能性もあります。 |
| ハイ / ローメッシュのマッチング | ベイク処理時にオブジェクトを含めるかどうかをベイカーで指定する方法を変更します。<ul data-preserve-html="true"> <li data-preserve-html="true">常に：ベイク中にケージ内でヒットしたすべての高ポリゴンメッシュを含めます。</li> <li data-preserve-html="true">メッシュ名別：各ケージに対して、対応するメッシュの接尾辞を持つメッシュのみをベイクします。</li> </ul> |
| ローポリメッシュサフィックス | [メッシュ名で一致]を使用する場合は、この接尾辞を使用してローポリゴンメッシュを定義します。 |
| ハイポリメッシュサフィックス | [メッシュ名で一致]を使用する場合、この接尾辞を使用して高ポリゴンメッシュを定義し、対応するローポリメッシュと一致させます。 |
| アンチエイリアス | 生成されたマップのアンチエイリアシングの量を調整します。 |

#### ゆがみ補正

| 設定 | 説明 |
| --- | --- |
| **ゆがみ補正** | ゆがみ補正ペイントモードに入ります。 |
| **エッジ保護** | エッジ保護を切り替えて、ハードエッジに近いペイントされたゆがみ補正値をマスクアウトします。 |
| **エッジの距離** | ハードエッジからエッジ保護までの距離を制御 |
| **エッジのコントラスト** | エッジ保護のグラデーションを完全保護から非保護に切り替える度合いを制御します。 |

## ID マップ設定

| 設定 | 関数 |
| --- | --- |
| カラーソース | ID マップのベイクする色の決定方法を変更します。<ul data-preserve-html="true"> <li data-preserve-html="true">頂点カラー</li> <li data-preserve-html="true">マテリアルカラー</li> <li data-preserve-html="true">ファイル ID</li> <li data-preserve-html="true">メッシュID/ポリグループ</li> </ul> |
| カラージェネレーター | カラーソースにファイルIDまたはメッシュ ID/Polygroupを使用する場合は、次のようにカラーの生成方法を指定します。<ul data-preserve-html="true"> <li data-preserve-html="true">ランダム</li> <li data-preserve-html="true">色相シフト</li> <li data-preserve-html="true">グレースケール</li> </ul> |

## Ambient occlusionマップの設定

| 設定 | 関数 |
| --- | --- |
| セカンダリレイ | セカンダリレイ数を変更します。 レイ数を増やすと結果は良くなりますが、処理時間が長くなります。 |
| 最小オクルーダー距離 | 高ポリゴンジオメトリに当たって結果のAOマップに影響を与える光線の最小距離を調整します。 |
| 最大オクルーダー距離 | ハイポリメッシュに当たらずにこの距離を超えて伸びる光線は、遮蔽されないとみなされ、AOマップに影響しません。 |
| バウンディングボックスに相対的 | このボックスをオンにすると、距離を参照する他の設定がプロジェクトメッシュのバウンディングボックスに基づきます。 したがって、1の距離はバウンディングボックスのサイズと同じです。 |
| 広がり角度 | 生成されるレイのangular範囲を調整します。 広がり角度を大きくすると、サーフェスから垂直に離れて配置されていないジオメトリによって、サーフェスが簡単に閉塞されます。 |
| 分布方法 | 光線の分布方法を選択します。 |
| 背面を無視 | 背面がオブジェクトを隠しているとみなすかどうかを変更します。 |
| セルフオクルージョン | 現在のメッシュのambient occlusionに影響するメッシュを選択します。 |
| 減少 | オクルーダー距離によってオクルージョンが減衰される方法を変更します。 |
| グランドプレーン | これを有効にすると、オクルーダとして動作するグリッドが作成されます。 |
| グランドプレーンオフセット | グリッドの位置を変更します。 |

## 曲率マップ設定

| 設定 | 関数 |
| --- | --- |
| 方法 | 曲率マップの生成方法を選択してください。 |
| セカンダリレイ | 曲率マップの生成に使用するセカンダリレイ数を調整します。 セカンダリレイが多いほど結果は良くなりますが、処理時間が長くなります。 |
| サンプリング半径 | 現在の点の曲率を求めるためにベイカーが検索する距離を調整します。 |
| バウンディングボックスを基準 | オンにすると、すべての距離がメッシュのバウンディングボックスのサイズに基づきます。 |
| セルフ積集合 | 曲率を判断するときに考慮するオブジェクトを選択します。 |
| 自動トーンマッピング (UV タイル単位) | UVタイルごとにトーンマップ曲率マップを自動調整するには、このチェックボックスをオンのままにします。 |
| トーンマッピング最小 | 自動トーン補正が無効な場合、トーン補正の最小値を調整します。 |
| トーンマッピング最大 | 自動トーン補正が無効な場合、トーン補正の最大値を調整します。 |

## 位置マップ設定

| 設定 | 関数 |
| --- | --- |
| モード | すべての軸職位マップを生成するか、選択した軸の職位のみを計算するかを選択します。 |
| 軸 | シングル軸モードを選択した場合は、この設定を使用して計算する軸を選択します。 |
| 正規化タイプ | 位置の値の正規化の方法を、バウンディングボックスまたはバウンディングボックスを使用して変更するか、正規化を無効にします。 |
| スケールの正規化 | 位置スペースの最大境界と見なされる値を変更します。 |

## 厚みマップ設定

| 設定 | 関数 |
| --- | --- |
| セカンダリレイ | セカンダリレイ数を変更します。 レイ数を増やすと結果は良くなりますが、処理時間が長くなります。 |
| 最小オクルーダー距離 | 高ポリゴンジオメトリに当たって結果の厚みマップに影響を与える光線の最小距離を調整します。 |
| 最大オクルーダー距離 | ハイポリメッシュに当たらずにこの距離を超えて伸びる光線は遮られないと見なされ、厚みマップに影響を与えません。 |
| バウンディングボックスに相対的 | このボックスをオンにすると、距離を参照する他の設定がプロジェクトメッシュのバウンディングボックスに基づきます。 したがって、1の距離はバウンディングボックスのサイズと同じです。 |
| 広がり角度 | 生成されるレイのangular範囲を調整します。 広がり角度を大きくすると、サーフェスから垂直に離れて配置されていないジオメトリによって、サーフェスが簡単に閉塞されます。 |
| 分布方法 | 光線の分布方法を選択します。 |
| セルフオクルージョン | 現在のメッシュのThicknessに影響するメッシュを選択します。 |
| 正規化 | Thickness値の正規化の方法を変更します。 |

## 高さマップ設定

| 設定 | 関数 |
| --- | --- |
| 正規化 | Height値の正規化の方法を変更します。 |
| スケーリング除数 | 「正規化」が「手動」に設定されている場合、このスライダーを使用して拡大・縮小の除数を調整し、高さマップの正規化を調整します。 |

## Bent normalsマップの設定

| 設定 | 関数 |
| --- | --- |
| セカンダリレイ | セカンダリレイ数を変更します。 レイ数を増やすと結果は良くなりますが、処理時間が長くなります。 |
| 最小オクルーダー距離 | 高ポリゴンジオメトリに当たって、結果のbent normalsマップに影響を与える光線の最小距離を調整します。 |
| 最大オクルーダー距離 | ハイポリメッシュに当たらずにこの距離以上に伸びる光線は、遮蔽されないとみなされ、bent normalsマップに影響を与えません。 |
| バウンディングボックスに相対的 | このチェックボックスをオンにすると、プロジェクトメッシュの境界ボックスに基づいて、距離を参照する他の設定が行われます。 したがって、1の距離はバウンディングボックスのサイズと同じです。 |
| 広がり角度 | 生成されるレイのangular範囲を調整します。 広がり角度を大きくすると、サーフェスから垂直に離れて配置されていないジオメトリによって、サーフェスが簡単に閉塞されます。 |
| 分布方法 | 光線の分布方法を選択します。 |
| 背面を無視 | 背面を隠線として扱うかどうかを選択します。 |
| セルフオクルージョン | 現在のメッシュのbent normalsに影響を与えるメッシュを選択します。 |
