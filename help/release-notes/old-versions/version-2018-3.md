# バージョン2018.3

**Substance Painter 2018.3**&#x200B;が登場し、多くの新しいワークフローとレンダリング機能が追加されました。

リリース日： *20 November 2018*

## 主な機能

### 2Dビュー書き出し

![](../../assets/export-2d-view.jpg)

**をレンダリングした2Dビュー**&#x200B;をテクスチャとして&#x200B;**書き出し**&#x200B;できるようになりました。 この機能は多くのユーザーからリクエストされており、最終的に利用可能になりました。 書き出しプロセスでは、**2Dビュー**&#x200B;の現在のステートを使用して、通常の書き出し設定（パディング、ファイルフォーマット、ビット深度）でテクスチャをレンダリングします。 つまり、表示モードが&#x200B;**マテリアル**&#x200B;モードではなく&#x200B;**ソロ**&#x200B;に設定されている場合、2Dビューがそのまま書き出されます。

**書き出しウィンドウ**&#x200B;に移動し、「**2Dビュー**」という名前の新しい設定を選択します。\
![](../../assets/2d-view-export-config.png)

独自の&#x200B;**書き出しプリセット**&#x200B;を作成する場合、[書き出し]ウィンドウの[**構成**]タブで、「**2Dビュー**」という名前の新しい&#x200B;**変換されたマップ**&#x200B;も使用できます。

### 改善されたベイク処理された照明フィルター

![](../../assets/baked-lighting.jpg)

**ベイク済み照明環境**&#x200B;フィルターは大幅に改善され、**HDR環境マップ**&#x200B;を適切にサポートするようになりました。\
ビューポートの照明を（2Dビューで表示されるように）複製し、それをベースカラーチャンネルにベイク処理できるようになりました。 新しいフィルターは、**回転**、**環境**&#x200B;マップ&#x200B;**垂直方向**、および&#x200B;**露光量**&#x200B;の変更など、さらに細かい制御を提供します。

![](../../assets/shelf-baked-lighting.png)

### リアルタイム異方性Specular反射

![](../../assets/capture-optim.gif)

この新しいバージョンでは、「**pbr-metal-rough-異方性-angle**」という名前の新しいシェーダを導入します。 このシェーダは、異方的なSpecular反射を作成するために使用できる、「**異方性角度**」と「**異方性レベル**」という名前の2つのチャンネルをサポートしています。 このシェーダは、変換を必要とせずに、そのままIrayに変換されます。

この新しいシェーダに[Shader Window](../../interface/shader-settings/shader-settings.md)からアクセスするには、シェーダボタンをクリックしてミニシェルフを開きます。

![](../../assets/shader-anisotropy.png)

デフォルトのサンプルプロジェクト「**Preview Sphere**」が更新され、その新しいシェーダを活用して、様々なチャンネルの設定方法が示されるようになりました。

>[!NOTE]
>
> **異方性アングル**&#x200B;チャンネル内でグラデーションを使用しているときに、見た目が奇妙な&#x200B;**線の斑点**&#x200B;が現れた場合は、塗りつぶしレイヤーに対してフィルタリングモードを「**最も近い**」に変更してみてください。これにより、シェーダのサンプリングが改善され、問題が解消される可能性があります。

### クリアコートのシェーダを更新

![](../../assets/coated.jpg)

**クリアコート**&#x200B;シェーダ(**pbr-coated**)が改善され、より多くのコントロールとレンダリングの可能性を提供できるようになりました。 また、専用の&#x200B;**MDL**&#x200B;を使用して、**Iray**&#x200B;と互換性を持たせる機会も設けました。

変更のリストは次のとおりです。

* **セカンダリ**&#x200B;粗さ&#x200B;**レイヤーを**&#x200B;制御します（**ユーザー0**&#x200B;チャネル経由）。
* **マスク**&#x200B;をセカンダリレイヤーから（**ユーザー1**&#x200B;チャネル経由）送信します。
* サーフェス画層に適用する動作を選択： **法線のディテールを保持** （オリジナル）または&#x200B;**スムーズサーフェス** （新規、メッシュ法線マップを無視）

便利な方法として、この新しいシェーダをテクスチャリングするための新しいプロジェクトテンプレートも追加しました。名前は&#x200B;**PBR - Metallic Roughness Coated**&#x200B;です。

![](../../assets/shader-coated.png)

### 新規ビューポートのアンチエイリアス

![](../../assets/temporal-anti-aliasing.gif)

Substance Painterのアンチエイリアスのポストプロセスは修正され、「**テンポラルアンチエイリアシング**」(**TAA**)と呼ばれる新しい方式に変更されました。\
この新しい手法は、非常に最小限のコストですべてのケースでより良い結果を提供します。 **TAA**&#x200B;は、複数のフレームにわたって情報を蓄積することで、ディテールを失うことなく、非常に滑らかなエッジを作成します。

後効果ではなくなったため、設定は&#x200B;**ディスプレイ設定**&#x200B;ウィンドウ内で少し移動し、**後効果**&#x200B;セクションの&#x200B;**下**&#x200B;になっています。

この新しいアンチエイリアスを透明度と組み合わせると、新しい可能性も生まれます。 プロジェクトで&#x200B;**Alphaテスト**&#x200B;シェーダーを使用している場合は、「**アルファディザリング**」設定を有効にしてみてください。

![](../../assets/dithering-aa.gif)

新しい&#x200B;**TAA**&#x200B;では、**Specular反射**&#x200B;および&#x200B;**サブサーフェス散乱**&#x200B;サンプルに見られる青いノイズパターンも適切にフィルターされます。

### スパース仮想テクスチャリング(SVT)

![](../../assets/svt-header.jpg)

この新しいバージョンでの大きな変更の1つは、**スパース仮想テクスチャ**&#x200B;または&#x200B;**SVT**&#x200B;の導入です。

この新しいシステムは、Substance Painterの基礎とアプリケーションの動作を変えます。 Substance Painterでは、SVTを使用してビューポートの特定のメモリフットプリントを維持し、**テクスチャのインとアウト**&#x200B;を可能にします。 主な利点は、大きなプロジェクトをより簡単に読み込み、GPUの負荷を減らして&#x200B;**パフォーマンスを向上**&#x200B;できることです。 つまり、サイズが大きくなりすぎると、一部のテクスチャがディスクからアンロードされ、必要に応じて後で取り戻されます)。 これは&#x200B;**揮発性キャッシュ**&#x200B;で、アプリケーションが閉じると削除されます。

このシステムのもう1つの利点は、**ビューポート**&#x200B;内に&#x200B;**ミップマップ**&#x200B;を導入できることです。これにより、テクスチャの品質が向上し、特に生地のパターンで見えるモアレ効果が減少します。

この新しいシステムに関して、メインの環境設定（**編集/設定**）で編集できるコントロールがいくつか公開されました。

![](../../assets/svt-settings.png)

* **キャッシュディレクトリ** ：この設定は、Substance PainterがSVTキャッシュを含む一時ファイルを書き込む場所を制御します。
* **ハードウェアサポートアクセラレーション** ：有効にすると、Substance PainterはGPUによる疎テクスチャのネイティブサポートを使用します（無効にすると、ソフトウェア実装にフォールバックします）

SVTについて詳しくは、ドキュメントページを参照してください： [スパース仮想テクスチャ](../../features/sparse-virtual-textures.md)

>[!NOTE]
>
> Substance Painterを使用しながら最高のパフォーマンスを得るために、**キャッシュディレクトリ**&#x200B;を&#x200B;**ソリッドステートドライブ(SSD)**&#x200B;に設定することをお勧めします。
> 
> これらの設定は、環境変数[環境変数](../../pipeline-and-integration/configuration/environment-variables.md)で上書きできます。

### 新たに改良されたシンメトリツール

![](../../assets/symmetry-offset-optim.gif)

シンメトリツールが修正され、原点をオフセットできるようになりました。 プロジェクトが部分的に対称であったり、中心からずれている場合に、プランを調整できるようになりました。 オフセットは、軸ごとにプロジェクト内に保存されます。

また、この機能に愛情を注ぎ、新しいビジュアルフィードバックを加えました。

* **交差線**&#x200B;が&#x200B;**default**&#x200B;によってメッシュ上に描画され、対称平面の位置を示しています。
* **カーソル**&#x200B;を移動すると、**ミラーポイント**&#x200B;が表示され、ミラーブラシストロークが適用される場所が示されます。

すべての新しいビジュアルは、コンテキストツールバーの新しいシンメトリメニューで微調整できます。

![](../../assets/symmetry-menu.png)

* **ミラーX、ミラーY、ミラーZ** ：対称に使用する方向を定義します
* **オフセット** ：軸ごとのオフセット値を制御します。 Cross Arrowアイコンを使用すると、すべてのオフセットを0にリセットできます。
* **対称平面** : [平面を表示]を使用すると、メッシュを切断する平面を描画できます。 [交差を表示]平面がメッシュを切断する位置にメッシュ上に線を描画します。
* **対称カーソル** :Showカーソルは、対称が適用されている場所に第2ブラシカーソルを描画します。 「ペイント中に非表示」を選択すると、ペイントしていない場合にのみカーソルが表示されます。
* **マニピュレータ** : [マニピュレータを表示]を使用すると、対称平面をオフセットするためにビューポートにマニピュレータが表示されます。 **マニピュレータのサイズ**&#x200B;は、ビューポート内でのコントローラの大きさを制御します。

3平面およびUVマニピュレータと同じ&#x200B;**ショートカット**&#x200B;を使用して、シンメトリマニピュレータの表示/非表示を切り替えることができます。

* **Q** :マニピュレータの表示/非表示
* **Shift** :スナップ移動（個別のオフセット）
* **+ / -** :マニピュレータサイズを変更します

![](../../assets/symmetry-gizmo.gif)

### 改良された三平面マニピュレータ

![](../../assets/trip-rotation-optim.gif)

回転を制御する3本のオリジナル軸に加えて、3平面マニピュレータを制御する際の新しい回転球も追加しました。 球体を使用すると、例えばノイズパターンを投影する場合に、様々な角度をすばやく試すことが簡単になります。

### 8ビットディザのテクスチャの書き出し

![](../../assets/dither-1.jpg)

標準およびHeightマップテクスチャを8ビットモードのファイル形式に書き出す際に、Substance Painterが自動的に&#x200B;**ディザリング**&#x200B;を適用して、**バンディング** **の問題**&#x200B;を減らすことができます。

>[!NOTE]
>
> 書き出しプリセットで標準マップが使用されているが、アルファに含まれている他の要素（RGB=標準、A =粗さなど）が使用されている場合、法線のみがディザされます。

### レイヤースタックの動作の改善

![](../../assets/color-layers.gif)

レイヤースタックとレイヤー管理に、いくつかのワークフローの改善が加えられました。

* **右クリック**&#x200B;メニューを使用してレイヤースタック内の&#x200B;**レイヤー**&#x200B;と&#x200B;**フォルダー**&#x200B;に&#x200B;**カラー**&#x200B;を割り当て、レイヤーを整理します。\
  ただし、Substance Painterレイヤーの色が他のソフトウェアパッケージの色と少し異なる動作をします。
  * フォルダー内のレイヤーは、フォルダーのカラーを継承しますが、グレー表示になります。
  * カラーのあるフォルダー内でカラーが割り当てられていないレイヤーを移動した場合、そのフォルダーのカラーが引き継がれます。
  * レイヤーに専用のカラーがある場合、そのレイヤーはフォルダーによってオーバーライドされません。この元の動作を使用すると、手で割り当てるカラーが多くなりすぎることなく、レイヤースタックのカラー化と整理が簡単になります。

![](../../assets/hide-slider.gif)

* マウスを&#x200B;**クリックしてスライド**&#x200B;することで、複数の&#x200B;**レイヤー**&#x200B;をすばやく&#x200B;**表示および非表示**&#x200B;できます。\
  また、この機会に、非表示のフォルダー内のレイヤーの非表示を解除する動作を少し調整しました。これにより、フォルダーの非表示も解除されます。

![](../../assets/blend-mode_1.gif)

* **矢印**&#x200B;キーボード&#x200B;**ショートカット**&#x200B;を使用して、描画モードをすばやく&#x200B;**切り替え**&#x200B;ます。\
  描画ポップアップメニューを&#x200B;**閉じる**&#x200B;と、**フォーカス**&#x200B;はレイヤーに&#x200B;**残り**&#x200B;表示されます。レイヤーは、以前の同じショートカットで引き続き変更できます。

### フィルターとジェネレーターの新しいSubstance入力

![](../../assets/uv-border-generator.gif)

カスタムフィルターおよびジェネレーター用の新しいSubstance入力が公開されました。 これらの新しいテクスチャ入力により、新しいメッシュ関連情報を使用してより高度なエフェクトを作成することができます。

使用できる新しい入力は次のとおりです。

* メッシュの位置
* メッシュワールド空間法線
* メッシュワールド空間の接線
* メッシュワールド空間のビットマップ
* メッシュテクセルサイズ
* メッシュUVマスク

詳しくは、新しいドキュメント[メッシュベースの入力](../../content/creating-custom-effects/mesh-based-input.md)を参照してください。

例として、現在のテクスチャセットのUV アイランドの境界から白黒のマスクを作成する、「**UV境界距離**」という名前の新しい&#x200B;**マスクジェネレーター**&#x200B;を提供します。

![](../../assets/uv-border.png)

>[!NOTE]
>
> これらの入力は、プロジェクトメッシュに基づくSubstance Painterのエンジンから直接提供され、[ベーカー](../../baking/baking.md)は使用しません。
