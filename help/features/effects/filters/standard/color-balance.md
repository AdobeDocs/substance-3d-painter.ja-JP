## 説明

カラーバランスフィルターでは、ハイライト、中間調、シャドウをわずかに変更できます。

塗りつぶしレイヤーで使用して、微妙なカラー調整を行います。

</td>
</tr>

## パラメーター

### ハイライト

<table>
<tr>
<td><b>シアン&lt;-&gt;赤：</b></td>
<td>カラーをシアンまたはレッド側にシフトします。</td>
</tr>
<tr>
<td><b>マゼンタ&lt;-&gt;グリーン：</b></td>
<td>カラーをマゼンタまたはグリーン側に動かします。</td>
</tr>
<tr>
<td><b>黄&lt;-&gt;青：</b></td>
<td>カラーをイエローまたはブルー側にシフトします。</td>
</tr>
</table>
