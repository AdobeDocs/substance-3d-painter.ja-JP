# 塗りつぶされたパス

![](../../assets/banner_filled_path.jpg)

塗りつぶしパスツールは、均一カラーで塗りつぶされた3Dモデルの表面にシェイプを作成できるパスツールの一種です。

![](../../assets/filled_path_across_gaps.png)

<b>塗りつぶしパス</b>ツールには、パスツールメニューからアクセスできます。

![](../../assets/filled_path_menu.png)

## 設定

パスの塗りつぶしの設定は次のとおりです。

| 設定 | 説明 |
| --- | --- |
| 不透明度 | 塗りつぶされたシェイプの最終的な不透明度を制御します。 |
