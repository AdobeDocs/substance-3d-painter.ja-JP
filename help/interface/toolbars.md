# ツールバー

このページでは、使用可能なすべてのツールバーの概要を簡単に説明します。 それぞれ異なるアクションと設定が含まれています。

以下に、使用可能なすべてのツールバーのリストを示します。

## ツール

![](../assets/tool-toolbar.png){width="450px"}

**[ツール]ツールバー**&#x200B;は、既定ではメインインターフェイスの左上に表示されます。 現在開いているプロジェクトの3Dメッシュにテクスチャを適用するために使用できる[ペイントツール](../painting/painting.md)がすべて一覧表示されます。 これらのツールは、ペイントレイヤーが選択されている場合にのみ使用できます。

一部のツールには、パーティクルペイントを可能にする「物理」という2番目のモードがあります。 パーティクルペイントには、[アセット](assets/assets.md)ウィンドウのパーティクルブラシプリセットをクリックしてアクセスすることもできます。

このツールバーは、メインインターフェイスの左側または右側にのみ垂直にドッキングできます。

## ドック

![](../assets/dock-toolbar.png){width="450px"}

<b>ドックツールバー</b>は、既定ではメインインターフェイスの右上に表示されます。 その目的は、ドックウィンドウにすばやくアクセスして、すばやく開いたり閉じたりできるようにすることです。

ツールバーのボタンの1つをクリックすると、そのボタンの横にDockが表示され、その他のインターフェイスの上にフローティングされます。ボタンを再度クリックすると、そのボタンが閉じます。 ドックがボタンから離れると、通常のフローティングウィンドウになり、インターフェイスにドッキングできるようになります。 閉じた場合、ボタンはDockツールバーで再び使用できるようになります。

![](../assets/ui-dock-collapse-recall-optim.gif){width="450px"}

このツールバーは、メインインターフェイスの左側または右側にのみ垂直にドッキングできます。

## プラグイン

![](../assets/plugins-toolbar.png){width="450px"}

**プラグインツールバー**&#x200B;には、Substance 3D Painterのインストールされている（現在有効になっている）スクリプトプラグインが一覧表示されます。 プラグインとその使用方法の詳細については、[プラグイン](../features/plugins/plugins.md)を参照してください。

## コンテキスト

![](../assets/contextual-toolbar.png){width="450px"}

コンテキストツールバーは、選択した現在のツールまたはその他の変更されているプロパティに応じてコンテンツの一部が変更されるツールバーです。 ツールバーの左側は変更できますが、右側は固定されており、[ビューポート](viewport/viewport.md)の表示を変更するためのショートカットを一覧表示します。

このツールバーには、次のエレメントのプロパティが一覧表示されます。

* [ペインティング](../painting/painting.md)
* [塗りつぶしレイヤー投影のマニピュレータ](../painting/fill-projections/fill-projections.md)

このツールバーは移動できず、常にビューポートの上部に表示されます。
