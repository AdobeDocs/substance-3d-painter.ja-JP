# ドラッグ&amp;ドロップによるリソースの追加

リソースの読み込みは、アプリケーションの外部からインターフェイスの別の領域にファイルをドラッグ&amp;ドロップするだけで簡単に実行できます。

## 「アセット」ウィンドウへのインポート

Painterにリソースを読み込むには、「アセット」ウィンドウにリソースをドラッグ&amp;ドロップします。

「リソースをインポート」ウィンドウが開き、リソースを置く場所（プロジェクト内、プロジェクト間で再利用するディスク上、または一時的に使用するセッション内）を制御できます。 このウィンドウでは、リソースの使用方法を適切に設定することもできます。一部のファイル形式があいまいな場合があるためです。

![リソースをアセットウィンドウにドラッグアンドドロップする方法を示すGIF](../../assets/import_dragdrop_assets_window.gif)

### ビューポートへの読み込み

マテリアルをプロジェクトに直接読み込んで適用するには、ビューポートにドラッグ&amp;ドロップします。 ファイルのドラッグ中は、メッシュがハイライトされ、プロジェクトのどの部分に適用されるかが示されます。

![リソースのビューポートへのドラッグアンドドロップを示すGid](../../assets/import_dragdrop_material_viewport.gif)

SVGファイルをビューポートにドラッグ&amp;ドロップして読み込むこともできます。 これにより、ワープ投影モードと<b>グラフィックからマテリアル</b>を復元する新しいレイヤーが作成され、デカールの作成が容易になります。

![リソースのビューポートへのドラッグアンドドロップを示すGid](../../assets/import_dragdrop_material_svg.gif)

### レイヤースタックへの読み込み

リソースをレイヤーにドラッグ&amp;ドロップすると、ドロップ時にレイヤー（またはエフェクト）が作成されます。 リソースがSubstanceのマテリアルまたはフィルターでない場合は、どのチャンネルにリソースを配置するかを尋ねるメニューが表示されることがあります。

### リソーススロットへのインポート

インターフェイスのリソーススロットの1つにファイルをドラッグ&amp;ドロップ（例えば、塗りつぶしレイヤー内のチャンネルにファイルをドラッグ）すると、リソースが読み込まれ、自動的に適用されます。

![リソーススロットへのリソースのドラッグアンドドロップを示すGid](../../assets/import_dragdrop_slot.gif)
