# バックグラウンドアプリケーションとの競合

バックグラウンドで実行されている一部のアプリケーションが、Substance 3D Painterの動作を妨げ、問題を引き起こす可能性があります。 スパイウェア対策ソフトウェアおよびウイルス対策ソフトウェアは、スローダウンの原因となる可能性のある低レベルのプロセスを分析することがよくあります。そのため、このソフトウェアを無効にすると、Painterの使用中にパフォーマンスが向上します。\
Painterをクラッシュしたり、少なくとも[速度を落としたりすることが可能な既知のアプリケーションの一覧は、こちらから入手できます](../technical-issues/startup-issues/software-conflicts.md)。
