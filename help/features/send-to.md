# 送信先

![バナー画像](../assets/sendto_banner.jpg)

<b>送信先</b>は、プロジェクトから別のアプリケーションにリソースを簡単にエクスポートおよびインポートするための操作です。手動で行う必要はありません。 「送信先」を使用すると、3Dモデルとそのテクスチャを別のレンダリングアプリケーションに書き出したり、Substance 3D DesignerからSubstanceマテリアルを受け取ったりすることができます。

「送信」アクションは、<b>ファイル/送信</b>メニューから使用できます。

現在サポートされている<b>送信先</b>は次のとおりです：

* <b>Photoshop</b>に送信
* <b>Substance 3D Stager</b>に送信
* <b>After Effects</b>に送信

Painterは、次のような他のアプリケーションからリソースを受け取ることもできます。

* <b>Substance 3D Designer</b>
* <b>Substance 3D Sampler</b>

リソースの受け取りについて詳しくは、[専用のドキュメントページ](../content/importing-assets/receiving-assets-from-other-substance-3d-applications.md)を参照してください。

>[!NOTE]
>
> 一部の「送信」ワークフローは、Creative Cloudデスクトップソフトウェアとの技術的な依存関係により、Adobe版のPainterでのみ使用できます。
> 
> また、必要なソフトウェアがインストールされていない場合は、「送信」メニューの一部のアクションを使用できない場合があります。
