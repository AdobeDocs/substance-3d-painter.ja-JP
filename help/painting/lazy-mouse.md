# レイジーマウス

![](../assets/lazy-mouse-example.png)

レイジーマウスは、マウスカーソルと実際のペイント間の距離のオフセットで、より正確なストロークや滑らかなストロークをペイントできます。

[コンテキストツールバー](../interface/toolbars.md)から有効にすることができます。 これにより、すっきりと連続した線を簡単にペイントできます。

## レイジーマウスを有効にする

レイジーマウスを有効または無効にするには、コンテキストツールバーにあるボタンをクリックします。

![](../assets/lazy-mouse-button.png)

有効になると、ビューポートのブラシカーソルの周りにグレーの円が表示されます。

![](../assets/lazy-mouse-radius.png)

## レイジーマウス半径

コンテキストツールバーで、レイジーマウスの距離を変更することができます。 この値は、元のペイントの場所からブラシスタンプがペイントされる半径を定義します。 距離が小さいほど、スタンプのペイントが早くなり、素早く回転できるようになりますが、ペイントされた線のスムージングが減少します。
