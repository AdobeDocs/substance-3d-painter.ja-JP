# ピクセル化

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![ピクセレートアイコン](./Resources/icon_pixelate.png "ピクセレート")

<b>イン：</b>効果/ピクセル、ブロック、濃淡

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

ピクセレートフィルターは、入力を大きなブロックに変換して、ピクセレートされた外観をシミュレートします。

テクスチャレイヤー（カラー）またはマスクで、マテリアル、ノイズ、マスク、シェイプなどを完全にピクセル化するために使用されます。

</td>
</tr>
</table>

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>ピクセル量：</b> | ピクセルサイズの変更による副作用があるピクセル数を調整します。 ピクセル数が多いほど、ピクセルは小さくなります。 |
| <b>Alphaに適用：</b> | フィルターによってアルファチャンネルも変更するかどうかを切り替えます。 |
