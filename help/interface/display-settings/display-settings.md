# 表示設定

![](../../assets/display-settings-2.png){width="320px"}

**ディスプレイの設定**&#x200B;ウィンドウは、環境、カメラ、およびビューポートの設定を再グループ化します。 これらの設定はプロジェクトに対してグローバルであり、ビューポートの外観に影響を与える可能性があります。

## 表示モード

![](../../assets/viewmode.png)

ビューモードは、ビューポートの外観をコントロールします。 ドロップダウンは、次の3つのセクションに分かれています。

| セクション | 説明 |
| --- | --- |
| **照明** | ビューポートで3Dモデルをフルライティング（有効な場合はシャドウも含む）で表示します。 |
| **単一チャンネル** | 「solo mode（ソロモード）」とも呼ばれる。 ビューポートに特定のチャンネルまたはテクスチャのみを含むメッシュを照明なしで表示します。 |
| **メッシュマップ** | ライトを使用せずに、特定のベイク処理されたテクスチャのみを使用して、ビューポートにメッシュを表示します。 |

>[!NOTE]
>
> 表示モードは、[ビューポート](../../interface/viewport/viewport.md)の隅にある<b>ドロップダウン</b>を使用して変更することもできます。 チャンネルやメッシュマップをすばやく切り替えたり、マテリアルモードに戻ったりするために使用できる[ショートカット](../settings/shortcuts.md)もあります。
