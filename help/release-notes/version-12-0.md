# バージョン12.0

<b>Substance 3D Painter 12.0</b>では、レイヤースタックで直接テクスチャの統合を行ったり、ワープ投影用の新しい自動モードを使用したり、後処理エフェクトのセットを改善したり、プロジェクトの作成や設定のワークフローを改善したりすることができます。

リリース日： <b>9 2026年3月</b>

>[!NOTE]
>
> このバージョンでは、<b>統合/共有メモリ</b>を備えた<b>統合GPU</b>のサポートが改善されました。 ビデオメモリの検出が向上し、パフォーマンスが向上し、グラフィックの問題が少なくなることが予想されます。

## 主な機能

### レイヤーの新しい統合

![](../assets/v12_banner_flatten.jpg)

レイヤースタックで右クリックして表示されるコンテキストメニューに、新しい<b>平坦化</b>アクションが追加されました。 複数のレイヤーをグループ化し(<b>Ctrl/Cmd + G</b>)、統合されたコピーを作成して(<b>Ctrl/Cmd + M</b>)、すばやく結合できます。 ソースグループは自動的に無効になり、後で編集するために削除するか、<b>スマートマテリアル</b>として保存するかを選択できます。

レイヤースタックの統合された要素をディスクに直接書き出して、他のアプリケーションですばやく反復させることもできます。 グループ、レイヤー、マスクは、レイヤースタックの右クリックメニューを使用して個別にまたはバッチで書き出すことができます。

* <b>レイヤースタックでテクスチャを直接統合する</b>\
  任意のグループを統合するには、<b>Ctrl/Cmd + M</b>を押すか、右クリックして表示されるコンテキストメニューの<b>グループの統合</b>項目を選択します。 これにより、選択したコンテンツの結合コピーが生成され、ソースグループは自動的に無効になります。削除または復元の決定が行われるまで、元のレイヤーをそのままの状態で保ちます。

  ![](../assets/v12_flatten_menu.jpg)
* <b>テクスチャを統合してディスクに書き出す</b>\
  右クリックメニューにある専用の書き出しアクションは、レイヤー、マスク、またはグループのフラット化された結果をベイクし、ディスクに直接保存します。 これは、テクスチャの書き出しパイプライン全体を経由せずにベイク処理されたコンテンツを他のアプリケーションに転送する場合に便利です。
* <b>バッチ操作</b>\
  複数のレイヤー、グループ、マスクを一度に選択し、1回の操作で個別に統合または書き出すことができるので、レイヤースタックの大部分を1ステップで処理するのが効率的です。

  ![](../assets/v12_flatten_batch.jpg)

>[!NOTE]
>
> レイヤーの統合の詳細については、[専用のドキュメントページ](../interface/layer-stack/flatten-layers.md)を参照してください。

### 投影の新しいワープジオメトリモード

![](../assets/v12_banner_warp_auto.jpg)

デカールは複雑なサーフェスに自動的に適応するようになり、手動調整の必要性が減りました。 ワープ投影がアクティブな間、コンテキストツールバーで「<b>ジオメトリにワープ</b>」トグルを使用できます。

* <b>コンテキストツールバーの新しいパラメーター</b>\
  ワープ投影モードがアクティブな場合は常に、コンテキストツールバーで新しい<b>ジオメトリにワープ</b>の切り替えが使用できます。 現在のプロジェクション設定をリセットすることなく、いつでもオフにすることができます。

  ![](../assets/v12_warp_toolbar.png)
* <b>メッシュサーフェスへの自動ラッピング</b>\
  有効にすると、ワープ投影は基になるメッシュの曲率とトポロジに自動的に追従します。 サーフェス全体に投影をドラッグすると、ジオメトリにスムーズに適合し、複雑な形状や曲線の形状にデカールを配置するときに必要な手動の微調整を大幅に減らすことができます。

  ![](../assets/v12_warp_to_geometry.gif)
* <b>ローカルの変形の保持</b>\
  ワープ投影グリッドの頂点を編集する場合、ワープをジオメトリにモードは、同じ形状が常に投影されるように、事前に定義された変形を維持しようとします。

  ![](../assets/v12_warp_to_geometry_deformed.gif)

>[!NOTE]
>
> ワープ投影の詳細については、[専用のドキュメントページ](../painting/fill-projections/warp-projection.md)を参照してください。

### 新しいPostエフェクト

![](../assets/v12_banner_post_effects2.jpg)

Painter内のレンダリングは、<b>ディスプレイ設定</b>ウィンドウで利用できる新しい後処理エフェクトセットで強化できます。 <b>レンズフレア</b>や<b>粒状フィルム</b>などの新しい機能が追加され、その他の多くの効果に加え、<b>フィールドの深度</b>や<b>グレア</b>効果が向上しました。

新しいエフェクトを使用して得られる結果の例を次に示します。

![](../assets/v12_render_withpost.jpg)

* <b>新しい後処理エフェクト</b>\
  すべての後処理エフェクトは、<b>ディスプレイ設定</b>ウィンドウから個別に有効化および設定できます。 エフェクトは重なり順に適用され、各エフェクトのオン/オフを個別に切り替えることができるため、簡単に組み合わせたり、様々な結果を試したりできます。

  ![](../assets/v12_display_settings_post_effects.png)
* <b>効果の新しいリスト：</b>

  * <b>フィールドの深度</b>：焦点範囲外のオブジェクトをぼかして、カメラのレンズフォーカスをシミュレートします。
  * <b>ブルーム</b> ：画像の明るい領域から発する柔らかい光彩を追加します。
  * <b>グレア</b>：光源の周囲に光の筋を作成します。
  * <b>レンズフレア</b>:カメラ内で明るい光が当たっているときに、レンズの光学反射をシミュレートします。
  * <b>横収差</b>:レンズのレンズのずれによって生じる画像のエッジのカラーフリンジをシミュレートします。
  * <b>周辺光量補正</b>:フレームの角やエッジを暗くして、中心に焦点を当てます。
  * <b>シャープ</b>:エッジのコントラストを上げて、レンダリングされた画像をより鮮明にします。
  * <b>粒状フィルム</b> :アナログフィルムのテクスチャを再現するために、繊細なノイズをオーバーレイします。
  * <b>トーンマッピング</b> : HDR輝度値を表示可能な範囲に再マップして、映画のような外観にします。
  * <b>カラー補正</b> :コントラスト、彩度、明るさ、温度を調整して、全体的なカラーバランスを微調整します。

>[!NOTE]
>
> 新しいエフェクトについて詳しくは、[専用のドキュメント](../features/post-processing/post-processing.md)を参照してください。

### 新しいプロジェクトと設定ウィンドウの改善

![](../assets/v12_banner_project_window.jpg)

新しいプロジェクトウィンドウとプロジェクト設定ダイアログが再設計され、移動しやすくなりました。 パラメータの並べ替えとグループ化によって読みやすさが向上し、メッシュの再読み込みワークフローが改善されて、プロジェクトを繰り返し処理する際の繰り返しステップが減少しました。

* <b>新しいプロジェクトウィンドウの改善</b>\
  新しいプロジェクトウィンドウのパラメーターは、最もよく使用される設定がより目立つように再編成および並べ替えられました。 レイアウト全体がスキャンしやすくなり、新しいプロジェクトの設定に必要な時間が短縮されました。
* <b>プロジェクト設定でメッシュを再読み込みするための新しいワークフロー</b>\
  プロジェクト設定の新しいチェックボックス<b>メッシュを再読み込み</b>では、以前に読み込んだファイルのファイルパスが保存され、自動的に事前入力されるため、プロジェクトメッシュをより簡単に再読み込みできます。

  ![](../assets/v12_project_settings.png)
