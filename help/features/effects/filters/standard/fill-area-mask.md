# 塗りつぶし領域マスク

<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

<b>イン：</b>効果/塗りつぶし、シェイプ、アウトライン、グレースケール

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

塗りつぶし領域マスクフィルターは、アウトラインを塗りつぶされたシェイプに変換します。 実線で囲まれた領域はすべて塗りつぶされます。

クローズドストロークを塗りつぶすペイントレイヤーを追加した後に、マスク（白黒出力）レイヤーに使用されます。

</td>
</tr>
</table>

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>領域の検出：</b> | 塗りつぶす領域を識別する方法を選択します。 |
| <b>領域の検出のしきい値：</b> | 領域検出のしきい値を調整します。 |
| <b>デバッグ領域の検出：</b> | 「領域検出」設定で検出されたアウトラインの表示を切り替えます。 これにより、完全に閉じていない可能性のある領域を特定できます。 |
| <b>UV境界の動作：</b> | 領域の入力中にUV境界を処理する方法を選択します。 |
| <b>UV境界検出のしきい値：</b> | 領域検出プロセスによって塗りつぶされる可能性があるUV領域を無視するために使用する閾値を調整します。 |
