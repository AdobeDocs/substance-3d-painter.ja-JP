</td>

## 説明

3平面詳細フィルターは、3平面詳細ジェネレーターのフィルターバージョンで、投影全体を手動でコントロールします。 これにより、各軸の回転とオフセットの値を制御できます。 ジェネレーターとは異なり、このフィルターはレイヤーコンテンツに対して直接作用しますが、ジェネレーターには描画のためのカスタムマスク入力が必要です。

テクスチャレイヤー上またはマスク内で、3平面描画を行う場合に使用します。

</td>
</tr>
</table>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| <b>ワールド空間法線:</b> | ワールド空間法線マップを使用します。 |
| <b>位置：</b> | ベイク位置マップを使用します。 |

<a name="parameters"></a>

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| <b>投影:</b> | 投影する軸を選択します。 |
| <b>描画モード：</b> | 投影をブレンドする方法を選択します。 |
| <b>ブレンドコントラスト：</b> | 投影のブレンドのコントラストを調整します。 |
| <b>タイリング:</b> | 投影されたテクスチャのタイリングを調整します。 |
| <b>回転X:</b> | X投影の回転角度を調整します。 |
| <b>オフセットX:</b> | X投影のオフセットを調整します。 |
| <b>回転Y:</b> | Y投影の回転角度を調整します。 |
| <b>オフセットY:</b> | Y投影のオフセットを調整します。 |
| <b>回転Z:</b> | Z投影の回転角度を調整します。 |
| <b>オフセットZ:</b> | Z投影のオフセットを調整します。 |

### X 軸

| パラメーター名 | 説明 |
| --- | --- |
| **回転X:** | Xテクスチャ投影の回転角度を調整します。 |
| **オフセットX X:** | X軸に沿ってX軸の投影オフセットを調整します。 |
| **オフセットX Y:** | Y軸に沿ってX軸投影オフセットを調整します。 |

>[!NOTE]
>
> オフセットパラメーターには、タイトルに2つの軸が含まれています。 1つ目は軸を定義し、2つ目はオフセット軸を定義します。 したがって、**オフセットX Y**&#x200B;は特にX軸の投影を見て、その投影を投影のローカルY軸に沿ってオフセットします。
>
>もう1つの考え方は、**オフセットX**&#x200B;がX投影&#x200B;**水平方向**&#x200B;をオフセットし、**オフセットX Y**&#x200B;がX投影&#x200B;**垂直方向**&#x200B;をオフセットすることです。

### Y 軸

| パラメーター名 | 説明 |
| --- | --- |
| **回転X:** | Yテクスチャ投影の回転角度を調整します。 |
| **オフセットY X:** | X軸に沿ってY軸の投影オフセットを調整します。 |
| **オフセットY Y:** | Y軸に沿ってY軸投影オフセットを調整します。 |

>[!NOTE]
>
> オフセットパラメーターには、タイトルに2つの軸が含まれています。 1つ目は軸を定義し、2つ目はオフセット軸を定義します。 したがって、**オフセットY X**&#x200B;は特にY軸の投影を見て、その投影を投影のローカルX軸に沿ってオフセットします。
>
>もう1つの考え方は、**オフセットY X**&#x200B;はY投影&#x200B;**水平方向**&#x200B;をオフセットし、**オフセットY Y**&#x200B;はY投影&#x200B;**垂直方向**&#x200B;をオフセットするというものです。

### Z 軸

| パラメーター名 | 説明 |
| --- | --- |
| **回転X:** | Zテクスチャ投影の回転角度を調整します。 |
| **オフセットZ X:** | X軸に沿ってZ軸の投影オフセットを調整します。 |
| **オフセットZ Y:** | Y軸に沿ってZ軸の投影オフセットを調整します。 |

>[!NOTE]
>
> オフセットパラメーターには、タイトルに2つの軸が含まれています。 1つ目は軸を定義し、2つ目はオフセット軸を定義します。 したがって、**オフセットZ Y**&#x200B;はZ軸上の投影を特に見て、その投影を投影のローカルY軸に沿ってオフセットします。
>
>もう1つの考え方は、**オフセットZ X**&#x200B;はZ投影&#x200B;**水平方向**&#x200B;をオフセットし、**オフセットZ Y**&#x200B;はZ投影&#x200B;**垂直方向**&#x200B;をオフセットするというものです。
