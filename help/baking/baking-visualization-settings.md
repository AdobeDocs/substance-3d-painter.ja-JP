# ベイク処理ビジュアライゼーション設定

![](../assets/viewport-vizu.png)

ベイク処理ビジュアライゼーションは、ベイクモード中のPainterのビューポート内にあるパネルです。 ビューポートでのメッシュの表示に関連する設定を調整できます。

## 一般設定

| 設定 | 説明 |
| --- | --- |
| **ベーキングメッシュを隠す** | 有効にすると、このアイコンはビューポートの高ポリゴンメッシュとケージメッシュを非表示にします。 <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r1-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../assets/hide-baking-meshes.png"/></div> |
| **選択したテクスチャセットのみを表示** | 有効にすると、現在アクティブなテクスチャセットのケージメッシュとハイポリゴンメッシュだけがビューポートに表示されます。 |

### 高精細メッシュ (HP)

| 設定 | 説明 |
| --- | --- |
| <b>メッシュ</b> | 有効な場合は、3Dビューにハイポリゴンメッシュを表示します。 無効にすると、ハイポリゴンメッシュもメモリからアンロードされ、パフォーマンスの向上に役立ちます。 この設定の横にあるカラーオプションを使用して、ビューポート内のメッシュサーフェスのカラーを制御します。 |
| <b>一致するエラー</b> | 有効にすると、ケージメッシュのシェルの外側にあるハイポリゴンメッシュの領域が指定したカラーで表示されます。 この設定は、ベイクプロセス中に欠落し、ディテールや情報が失われる可能性がある領域を特定するのに役立ちます。 この設定の横にあるカラーオプションを使用して、ビューポート内の交差する領域の色をコントロールします。 |

### ケージ

| 設定 | 説明 |
| --- | --- |
| <b>ケージサーフェス</b> | 有効にすると、ケージメッシュサーフェスが3Dビューに表示されます。 ケージのサーフェスは、設定の横にあるカラーボタンによって定義されます。 |
| <b>ケージ表面の不透明度</b> | メッシュの透明度を増減させて、下にあるメッシュのディテールの可視性を管理します。 |
| <b>ケージワイヤーフレーム</b> | 有効にすると、ケージメッシュのワイヤーフレームがビューポートに表示されます。 ワイヤーフレームの色は、この設定の横にある色ボタンで調整できます。 |
| <b>ケージワイヤーフレームの不透明度</b> | ワイヤーフレームの透明度を増減します。 |

### UV シーム

| 設定 | 説明 |
| --- | --- |
| <b>ハードエッジ上のシームがありません</b> | 有効にすると、UVシームではないメッシュのサーフェス上のハードエッジは、設定の横のボタンで定義されたカラーでハイライトされます。 ハイライト表示されたエッジは、ケージとローポリゴンメッシュにのみ表示されます。 2Dビューと3Dビューの両方でエッジを表示できます。 この設定は、後でベイク処理の問題を引き起こす可能性のある、UVアンラップシームのない分割頂点法線を持つエッジの識別に役立ちます。 |
