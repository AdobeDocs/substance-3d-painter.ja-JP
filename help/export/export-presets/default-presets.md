# デフォルト出力テンプレート

以下は、デフォルトで提供される追加の出力テンプレートのリストです。  既定の出力テンプレートは、<b>書き出しウィンドウ</b>の<b>[出力テンプレート]タブ</b>でコピーおよび変更できます。

>[!NOTE]
>
> ここに記載されていない他のソフトウェアもサポートされている場合があります（**Octane**&#x200B;など）。 詳細については、[エコシステムとプラグイン](https://experienceleague.adobe.com/ja/docs/substance-3d/ecosystem/home)を参照してください。

| *プリセット* | *説明* |
| --- | --- |
| <b> Amazon操業所</b> | Amazon Lumberyardで読み込んで使用する名前とパックテクスチャ。 |
| <b>アーノルド(AiStandard) </b> | Arnold(AiStandard シェーダー)用のプリセット。 |
| <b>アーノルドUDIMレガシ(AiStandard)</b> | Arnold UDIMレガシー(AiStandard)のプリセット。 |
| <b>ブレンダー(Principled BSDF)</b> | ブレンダー(Principled BSDF)用のプリセット。 |
| <b>コロナ</b> | コロナレンダラーのプリセット。 |
| <b> CryEngine 3 </b> | Cry エンジン 3で読み込んで使用するテクスチャの名前とパック。 |
| <b>土田2 </b> | ゲームDota 2のプリセット（関連するテンプレートで使用可能）。 |
| <b>キーショット</b> | キーショットレンダラーのプリセット。 |
| <b>キーショット9+</b> | バージョン9以降のキーショットレンダラーのプリセット。 |
| <b>レンズスタジオ</b> | Lens Studioのプリセット（Snapchat用のアセットを作成） |
| <b>Maxwell (メタリックラフネス)</b> | メタリックラフネスワークフローを使用したMaxwellレンダラーのプリセット。 |
| <b>Maxwell (光沢度)</b> | 光沢度ワークフローを使用したMaxwellレンダラーのプリセット。 |
| <b> メッシュマップ </b> | テクスチャセットのベイクされたメッシュマップスロットを個別にエクスポートします（テクスチャセットと同じ解像度でエクスポート）。 |
| <b>PBR以外の光沢度</b> | 非PBR 光沢度ワークフローの名前および書き出しテクスチャ。 |
| <b> PBRメタリックの粗さ</b> | 通常のメタリック/ラフネスPBRワークフローに必要な名前と書き出しテクスチャ。 |
| <b> PBR メタリックラフネス （フォルダまたはPSDグループ） </b> | PBR MetalRoughに似ていますが、追加のフォルダーを作成します。 このプリセットは、PSDファイルフォーマットでの使用に最も適しています。 |
| <b> PBR Specular 光沢度</b> | 通常のSpecular/光沢PBRワークフローに必要なテクスチャの名前を付けて書き出します。 （テクスチャはBaseColor/Metallicワークフローから変換されます）。 |
| <b> PBR 光沢度（メタリックラフネスから変換</b>） | ベースカラー、メタリック、ラフネスの各チャンネルを変換して、Specular/光沢ワークフローと互換性を持たせます。 |
| <b> Redshift </b> | Redshiftレンダラーのプリセット。 |
| <b>Renderman (pxrDisney)</b> | メタリックマップと経度マップを使用したRenderman用のプリセット。 |
| <b>Renderman (pxrSurface)</b> | DiffuseとSpecularマップを使用するRenderman用のプリセット。 |
| <b>Roblox (MaterialVariant)</b> | アルファをサポートしていないアルベドを使用したRobloxのプリセット。 |
| <b>Roblox (SurfaceAppearance)</b> | アルファチャンネルのあるカラーマップを使用したロブロックスのプリセット。 |
| <b>シェード3D </b> | Shade 3Dのプリセット。 |
| <b>Spark AR Studio</b> | Spark AR Studioのプリセット。 |
| <b>Unity HDレンダリングパイプライン（メタリック標準）</b> | メタリックマップと光沢度マップを使用したUnityのHDレンダリングパイプライン用のプリセット。 |
| <b>Unity HDレンダリングパイプライン(Specular)</b> | 追加されたSpecularマップを使用したUnityのHDレンダリングパイプラインのプリセット。 |
| <b>Unityユニバーサルレンダリングパイプライン（メタリック標準）</b> | メタリックマップとSmoothnessマップを使用したUnityのユニバーサルレンダリングパイプライン用のプリセット。 |
| <b>Unityユニバーサルレンダリングパイプライン(Specular)</b> | SpecularマップとSmoothnessマップを備えたUnityのユニバーサルレンダリングパイプライン用のプリセット。 |
| <b>アンリアルエンジン （パック） </b> | Unreal エンジンで使用する名前とパックのテクスチャです。メモリ使用量は最小限に抑えられます。 |
| <b>アンリアルエンジン SSS （パック）</b> | Unreal エンジンで使用する名前とパックのテクスチャです。表面化散乱マップはメモリに置き換えられ、メモリフットプリントは最小限に抑えられます。 |
| <b> Vray Next (メタリックラフネス)</b> | PBRワークフローを使用したVrayレンダラーのプリセット。 |
| <b>次を選択(光沢度)</b> | 非PBRワークフローを使用したVrayレンダラーのプリセット。 |
| <b> Vray UDIMレガシ(メタリックラフネス)</b> | Vrayレンダラーのプリセット（UDIM命名規則）。 |
