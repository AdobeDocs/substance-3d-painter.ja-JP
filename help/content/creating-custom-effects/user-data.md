# ユーザーデータ

このページでは、特定のビヘイビアーを実行するためにSubstanceグラフに追加できるカスタムプロパティ（ユーザーデータ）について説明します。\
通常、ユーザー・データの設定は、グラフの入力ノードまたは出力ノードに適用され、アプリケーションによるデータの解釈を示します。 これにより、既知のコンテキスト（特定のカラースペースのリクエストなど）を使用してグラフの入力を要求したり、アプリケーションが後で余分な変換を適用する必要がある場合に出力がどのように行われたかを示したりできます。

* データの使用の設定は、**キー=値**&#x200B;として定義されています
* 複数の設定はセミコロン( **;** )で区切られます

## カラースペース

**カラースペース**&#x200B;設定を使用すると、特定のカラースペースを含むSubstanceグラフの入力をリクエストしたり、特定の方法で構成された出力を定義したりできます。 例えば、法線マップ出力の形式を指定します。

構文例： **カラースペース=$working**

コンテキストの概要：

* **カラーボタン**: Substanceグラフのプロパティ内のカラーボタンウィジェットです。
* **グラフの入出力**:チャンネルに接続されたグラフの入出力ノード（例： BaseColor）。
* **画像入力**：特定のチャンネルに関連しない、グラフの汎用入力です。

>[!NOTE]
>
> カラーマネジメントの導入により、カラースペースの設定に関連するいくつかの動作が変更されました。
> 
> * 次の表に、バージョン8.1より前の互換性のあるカラースペースの設定を最初に示します。 2番目のセクションは、バージョン8.1以降のみを対象としています。
> * カラースペース設定を使用できるコンテキストに関しては、バージョン8.1ではカラーボタンでカラースペースを定義できます。 以前のバージョンでは、これらは表示スペース(sRGB)にあると想定されていました。
> 
> **snorm**&#x200B;と&#x200B;**unorm**&#x200B;のカラースペース/変換は、GPUテクスチャ形式と混在させてはなりません。用途が異なります。

| カラースペース | コンテキストの可用性 | 説明 |
| --- | --- | --- |
| **自動** | カラーボタングラフの入力/出力画像入力 | デフォルト。 アプリケーションは、入力ノードのプロパティと入力に接続された画像に応じて、実行するカラースペース変換を決定します。 |
| **リニア** | カラーボタングラフの入力/出力画像入力 | 標準sRGB IEC 61966-2-1:1999カラースペース（リニアガンマ/トーンカーブ）。 **従来**&#x200B;カラーマネジメントモードでのみ使用できます。 |
| **srgb** | カラーボタングラフの入力/出力画像入力 | 標準sRGB IEC 61966-2-1:1999カラースペース。 **従来**&#x200B;カラーマネジメントモードでのみ使用できます。 |
| **パススルー** | カラーボタングラフの入力/出力画像入力 | 非推奨。 従来のカラーマネジメントモードでは&#x200B;**linear**&#x200B;として解釈され、OCIO/ACEでは&#x200B;**raw**&#x200B;として解釈されます。 代わりに&#x200B;**raw**&#x200B;に置き換えてください。 |
| **鼻** | グラフの入出力イメージ入力 | Signed normalized。 入力画像を範囲[0, 1]に指定するように要求します。 8ビットの入力画像の場合、これは中央の値が127であることを意味します。 フローティング画像入力の場合、中央は0.5で、クランプは実行されません。 |
| **normalxyzright** | グラフの入出力イメージ入力 | OpenGL 法線マップ形式。 |
| **normalxyzleft** | グラフの入出力イメージ入力 | 法線マップ形式。 |
|  |  |  |
| **形式を変更** | グラフの入出力イメージ入力 | 範囲/クランプなしのフローティング入力。 |
| **データ** | カラーボタングラフの入力/出力画像入力 | unsigned normalizedまたはfloat。 カラー以外の情報 |
| **raw** | カラーボタングラフの入力/出力画像入力 | この設定を使用する場合、カラー変換は適用されません。 |
| **$standardsrgb** | カラーボタングラフの入力/出力画像入力 | 標準sRGB IEC 61966-2-1:1999カラースペース。 |
| **$working** | カラーボタングラフの入力/出力画像入力 | 作業用カラースペースは、カラーマネジメント設定によって異なります。 カラーマネジメントされていないチャンネルおよびモノラルチャンネル（ステンシル、アルファ、マスク）のデータと同じになります |
| **$raw** | カラーボタングラフの入力/出力画像入力 | **raw**&#x200B;のエイリアス。 |
| **$auto** | カラーボタングラフの入力/出力画像入力 | **auto**&#x200B;のエイリアス。 |

## Alphaモード

**アルファ**&#x200B;設定を使用すると、カラー入力またはカラー出力(RGBA)のアルファの結合方法を指定できます。

構文例： **alpha=premultipliated**

| 設定 | 説明 |
| --- | --- |
| ストレート | アルファをストレートとして要求または定義します。 |
| 合成 | アルファを事前に乗算されたものとしてリクエストまたは定義します。 |
| なし | パススルーは、指定されたアルファをそのまま使用します。 |

>[!NOTE]
>
> チャンネル&#x200B;**不透明度**&#x200B;は、デフォルトでは&#x200B;**ストレート**&#x200B;と見なされます。

## 画像入力デフォルトカラー

Substanceグラフの画像入力のデフォルトカラーは黒で、アルファは0に設定されます。 **defaultcolor**&#x200B;設定では、グラフの画像入力が空の場合に別の値を定義できます

カラーの指定には、浮動小数値（範囲[0, 1]）または整数値（範囲[0, 255]）を使用できます。 各コンポーネント値はカンマで区切られ、浮動小数点値は小数点の区切り記号としてドットを使用します。 浮動小数点がポイントを持たない場合は、整数とみなされます。

構文例：

* **defaultcolor=(1.0,0.5,0.0)**
* **defaultcolor=(0,128,255)**

## 画像入力パディング

デフォルトでは、Substanceグラフの画像入力にはパディングがありません。通常、パフォーマンス上の理由から、UV アイランドの外側の領域は均一なカラーで塗りつぶされます。 パディング設定を使用すると、無限の拡張をリクエストできます。これは、例えば継ぎ目を作成しないようにするためにフィルターに使用できます。

構文例： **p**&#x200B;**adding=extend**

## デフォルトで出力を無効にする

サブスタンスをスロット（塗りつぶしレイヤーのツールのマテリアルスロットなど）に追加する場合、メタデータのテキストフィールドを使用して、特定のチャンネルを有効にしないように指定できます。

* 特定の出力ノード（マテリアルなど） : **disable=(true)**
* 汎用の出力ノード（フィルターなど） : **disable=（Height，拡散，Specular）**

サブスタンスをロードする場合、このチャンネルはユーザーインターフェイスで有効にならないため、レイヤースタックには影響しません。 ユーザーはチャネルを有効のままにすることができます。

## 出力を共通のマスク/アルファとして指定する

Substanceグラフの出力は、他の出力で共通のアルファチャンネル/マスクとして使用できます。

これを行うには、次の2つの方法があります。

* ID **channels\_node**&#x200B;の出力Alphaを作成します
* または、次のユーザーデータを特定の出力ノードに追加してください： **IsChannelsAlpha=true**

以下のような条件が適用されることがあります。

* ID **channels\_node**&#x200B;の出力Alphaが存在し、他の出力にuserdataがない場合、このノードがチャンネルマスクとして使用されます。
* 出力にuserdataが含まれている場合、**channels\_node** Alphaが存在しない限り、チャンネルマスクとして使用されます。
* **channels\_node** Alphaとuserdataを持つノードの両方が存在する場合は、**channels\_node**&#x200B;出力Alphaが最初に使用されます。
* 複数のノードがuserdataを持つ場合、アプリケーションによって見つかった最初のノードがチャンネルマスクとして使用されます。 出力が見つかった順序は、Substanceグラフで定義されたものと同じとは保証されません。

>[!NOTE]
>
> この設定は、**マテリアルモード**&#x200B;で使用されているSubstanceグラフにのみ適用されます。 フィルター、ジェネレーター等には該当しません。

## マテリアル出力のデフォルトの描画モードを設定

シェルフからビューポートまたはレイヤスタックにマテリアルをドラッグアンドドロップするときに、Substanceグラフの特定の出力のブレンドモードを定義することができます。

* 特定の出力ノード： **blendingmode=normal**
