# アンビエントオクルージョン

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_ambient_occlusion.webp" alt=""/><br><strong>イン：</strong>マスク、ジェネレーター、グレースケール、ブレンド</td>
    <td style="border: 0;" valign="top"><strong>説明</strong><br>Ambient occlusionジェネレーターは、ベイクされたAmbient occlusionマップに基づいてマスクを作成します。また、マスクにテクスチャまたは微細なディテールをブレンドすることもできます。<br><br>Ambient occlusionジェネレータを使用してレイヤマスクを作成する場合は、Ambient occlusionの出力を反転する必要があります。 初期設定では、ジェネレータは遮蔽された領域を暗い領域、遮蔽されていない領域を明るい領域として出力します。 マスクとして使用した場合、マスクされたレイヤーは、マスクされていない領域でのみ表示されます。 出力を反転すると、マスクされたレイヤーは閉塞領域にのみ表示されます。<br><br>画像の入力には、ベイクされた位置、ambient occlusion、およびワールド空間法線のマップが必要です。 <a href="../../../baking/baking.md">ベイク処理に関する詳細情報</a>。</td>
  </tr>
</table>

## 入力

| 名前を入力 | 説明 |
| --- | --- |
| テクスチャカラー | カスタムテクスチャまたはアンカーポイントを使用します。 |
| マイクロ法線カラー | カスタムの標準テクスチャまたはアンカーポイントを使用します。 |
| マイクロHeightカラー | カスタムテクスチャまたはアンカーポイントを使用します。 |
| Ambient occlusionグレースケール | Ambient occlusionマップを使用します。 |
| ワールド空間法線カラー | ワールド空間法線マップを使用します。 |
| グラデーションカラーを配置 | ベイク処理された位置マップを使用します。 |

## パラメーター

| パラメーター名 | 説明 |
| --- | --- |
| **グローバル反転** | すべてのエフェクトを合成した後で、最終的な結果を反転します。 |
| **グローバルぼかし** | すべての効果を組み合わせた後に、最終的なマスクを均一にスムージングします。 |
| **グローバル残高** | 明るさの調整のように、すべての効果を黒と白で合成した後に、最終的なマスクのバランスをシフトします。 |
| **全体のコントラスト** | すべての効果を組み合わせた後に、最終的なマスクのコントラストを調整します。 |
| **テクスチャを使用** | カスタムテクスチャマップの使用のオンとオフを切り替えます。 |
| **マイクロディテールを使用** | カスタムマイクロ詳細の使用のオン/オフを切り替えます。 |

### アンビエントオクルージョン

| パラメーター名 | 説明 |
| --- | --- |
| **反転** | ambient occlusionと微細なディテールのみを反転します。 |
| **ぼかし** | ambient occlusionとマイクロディテールのみをスムーズにします。 |
| **残高** | ambient occlusionと微細なディテールのみのバランスを調整し、明るさコントロールのように中間点を黒または白にシフトします。 |
| **コントラスト** | ambient occlusionと微細なディテールのみのコントラスト/フォールオフを調整します。 |

### マイクロ詳細

| パラメーター名 | 説明 |
| --- | --- |
| **マイクロHeight** | カスタムマイクロ高さマップの使用のオンとオフを切り替えます。 |
| **マイクロ法線** | カスタムマイクロ法線マップの使用のオンとオフを切り替えます。 |
| **AO半径** | 周囲オクルージョンの半径（範囲）を微調整します。 |
| **AO 深度** | 細かい部分でAmbient occlusionの深度（適用度）を調整します。 |
