# バージョン2017.4

**Substance Painter 2017.4** **レイヤーのインスタンス化**&#x200B;に新しいワークフロー機能が追加され、プロジェクト内の異なるテクスチャセット間でレイヤーを簡単に同期できるようになりました。

リリース日： *23 November 2017*

## 主な機能

### レイヤーのインスタンス化

![](../../assets/instancing.jpg)

**レイヤーのインスタンス化**&#x200B;は、**他のレイヤーおよびテクスチャセット**&#x200B;間で&#x200B;**同期**&#x200B;レイヤー&#x200B;**パラメーター**&#x200B;を維持できるようにする新しいシステムです。 レイヤーインスタンスを作成すると、元のレイヤーが&#x200B;**ソース**&#x200B;になり、インスタンス間のリンクが壊れない限り、インスタンスは&#x200B;**更新されたままになります**。 インスタンス化されたレイヤーを使用すると、数回のクリックで&#x200B;**アセットのテクスチャを作成**&#x200B;して&#x200B;**レイヤーを更新する**&#x200B;ことができます。レイヤーの更新を何度も繰り返す必要はありません。 アセットを簡単にテクスチャ処理するには、**他のテクスチャセット間でフォルダーをインスタンス化**&#x200B;し、スマートマテリアルやその他のレイヤーをその中に配置するだけで、瞬時に&#x200B;**すべての場所に複製**&#x200B;されます。

インスタンスを作成するには、次の2つの方法があります。

* レイヤーをコピーした後、「**インスタンスとしてペースト**」を選択します（またはショートカットCTRL+SHIFT+Vを使用します）
* 1つのレイヤーを選択した後で、「**テクスチャセット間でインスタンス化**」を選択します（またはショートカットCTRL+SHIFT+Dを使用します）

>[!NOTE]
>
> レイヤーのインスタンス化に関連するいくつかの制限があります。
> 
> * ペイントアクションはソースレイヤーにのみ存在し、インスタンス化されたレイヤーはブラシストロークを複製しません。
> * アンカーの参照には、インスタンスと同じレベルのアンカーポイントが必要です。アンカーポイントをインスタンス化されたフォルダーの外側に配置することはできません。配置しない場合は破損します。
> * スマートマテリアルがインスタンス化されたレイヤーと共に保存される場合、ソースレイヤーはスマートマテリアルフォルダーにある必要があります。そうでない場合、インスタンスリンクが壊れます。
> * レイヤースタックの設定によっては、インスタンス化されたレイヤーがサイクルを作成する可能性がありますが、これはサポートされていないため、インスタンスの結果は壊れます。 インスタンスを削除または移動して修正します。

詳細と例については、専用ページを参照してください： [レイヤーのインスタンス化](../../interface/layer-stack/layer-instancing.md)

### Unreal Engine 4をサポートするDCC Live-link

![](../../assets/livelink.jpg)

**live-linkプラグイン**&#x200B;の以前のベータ版は、Substance Painterが&#x200B;**統合**&#x200B;されました。 今回は、プロジェクトの結果を自動的にエンジンに表示できるアンリアルエンジン4をサポートしました。

**Unreal Engine 4** （バージョン&#x200B;**4.18**&#x200B;以降が必要）にSubstanceを接続するには、次の場所からアプリケーションプラグインをダウンロードしてください： <https://www.unrealengine.com/marketplace/substance-plugin>

### 新しいシェルフの内容

![](../../assets/materials-1.jpg)

**20個の新しい手続き型マテリアル**&#x200B;が追加され、さらに&#x200B;**40個の新しい経年劣化マップ**&#x200B;が追加されました（一部は手続き型になっています）。 新しい材料は、**シェルフ**&#x200B;の「**材料**」セクションにあります。たとえば、6つの新しい金属、8つの新しいプラスチック、いくつかの布地、2つの新しい木の表面などです。 新しい経年劣化マップは、**シェルフ**&#x200B;の「**経年劣化**」セクションにあります。

![](../../assets/grunges-1.jpg)

この新しいバージョンのコンテンツのライセンスを当社に許可していただいたClément Feuillet氏とNicolas Longchamps氏に感謝いたします。

### Sketchfab書き出し機能の向上

![](../../assets/sketchfab.jpg)

Sketchfab書き出しを更新し、プロジェクトをドラフトとして公開し、既にアップロードされているプロジェクトを更新する機能を追加しました。 これにより、プロジェクトの反復が大幅に容易になります。

### パフォーマンスの向上

我々はパフォーマンス改善に関する作業を続けた。 この新しいバージョンでは、ビューポートでのOpenGLレンダリングを大幅に修正しました。これにより、処理速度が大幅に向上します。 また、ブラシストロークの計算方法も改善され、メモリ内でより大きなテクスチャの計算が必要なくなりました。 全体的に、より速い結果とより優れたペイント感覚が得られます。
