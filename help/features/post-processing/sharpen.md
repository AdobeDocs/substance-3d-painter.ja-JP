# シャープ

![](../../assets/v12_post_sharpen.jpg)

画像のエッジと細部を強調して、シャープさが強調されます。

| <b>パラメーター</b> | <b>説明</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>金額</b> | シャープ効果の適用度を調整します。 値を大きくすると、エッジのコントラストがより大幅に増加します。 |
| <b>直径</b> | シャープ効果のサイズをピクセル単位で設定します。 値を小さくすると、ディテールがシャープになります。値を大きくすると、エッジがより広くなり、効果がより顕著になります。 |
