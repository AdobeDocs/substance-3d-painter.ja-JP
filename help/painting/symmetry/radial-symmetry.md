# ラジアル対称

放射状の対称では、軸の周囲にストロークまたは塗りつぶしレイヤーコンテンツを放射状に複製します。

![](../../assets/radial-demo.gif)

## マニピュレータを使用して対称軸を配置します

対称表示設定には、3Dビューの上部にあるコンテキストツールバーの<b>対称設定ボタン</b>からアクセスできます。 表示設定では、マニピュレータを有効にしてカスタマイズできます。 3Dビューでマニピュレータハンドルをドラッグして、対称軸の位置を変更します。

![ビューポートにマニピュレータが表示されているラジアルシンメトリー設定パネルのスクリーンショット。](../../assets/RadialSymmetryManip.png){width="600px"}

## ラジアルシンメトリパラメータ

![プロパティパネルの[対称]セクションのスクリーンショット](../../assets/FillSymmetry_1.png){width="300px"}

| *パラメーター* | *説明* |
| --- | --- |
| <b>軸</b> | シンメトリの実行に使用するシーンの軸を定義します。 |
| <b>コピーを反転</b> | U軸またはV軸で交互にコピーを反転します。 これは、テキストのような方向を持つコンテンツで対称性を使用する場合に役立ちます。 |
| <b>軸の位置： X、Y、Z</b> | プロジェクトの軸のオフセットを定義します。 この値は、スライダまたはマニピュレータ（上記を参照）を使用して編集できます。 |
| <b>軸の表示</b> | 有効にすると、対称軸を表す透明な線がビューポートに表示されます。 |
| <b>交差点を表示</b> | 有効にすると、ビューポート内のメッシュ上にポイントが描画され、対称軸がメッシュと交差する位置が示されます。 |
| <b>カーソルを表示（ブラシツール）</b> | 有効にすると、2番目のカーソルがシンメトリの反対側に表示され、ペイントが実行されるタイミングが示されます。 |
| <b>ペイント中は非表示（ブラシツール）</b> | このオプションを有効にすると、ペイントの実行中（マウスクリックを放すまで）に2番目のカーソルが非表示になります。 |
| <b>軸の位置マニピュレータを表示</b> | ビューポートでマニピュレータの表示/非表示を切り替えます。 |
| <b>マニピュレータのサイズ</b> | ビューポートのマニピュレータのサイズを制御します。 |
