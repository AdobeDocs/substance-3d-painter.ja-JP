# カスタムエフェクトの作成

>[!NOTE]
>
> カスタムエフェクトは、デフォルトのシェルフのプロジェクトに読み込むことができます。以下を参照してください： [アセットの読み込み](https://helpx.adobe.com/jp/substance-3d/unlisted/documentation/spdoc/adding-content-to-the-shelf-142213317.html)
